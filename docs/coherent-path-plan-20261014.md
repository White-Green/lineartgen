# DP: coherent local clean-profile choice, 2026-10-14

DO showed that the existing 15,809-parameter model can recover opaque central strokes after focused fitting. Gray secondary strokes, crossing cuts and damaged fill corners remain even on fixed known inputs. This does not establish a capacity limit. DP tests a less restrictive geometric objective before changing the model.

The two arms start from the identical DN `both` raw step 18,000 checkpoint, with fresh Adam and EMA. Both train on the full, unchanged 512 synthetic shapes for 6,000 updates. Batch 4, base learning rate 5e-5 times sqrt(batch)=1e-4, cosine decay to 1e-5, EMA .999, recursion cycling through 1–6 stages, all-stage weights .5**level, RF87 and 16 channels remain unchanged. Seed 2026101405 determines identical sampling, masks and source augmentation for both arms. Source-only conditioning, normalization before the pyramid, and Fourier physical level conditioning remain unchanged; additional Gaussian draws are not used by this model. This is not an optimal-transport or diversity experiment.

Both objectives combine an envelope penalty, a clean profile penalty with coefficient 1, and raw range penalty .05. The pixel envelope permits opacity between the minimum and maximum of nine translated clean 2px stroke candidates. It penalizes outside-support ink and omitted ink where every candidate agrees. It does not alone penalize a gray mixture within the envelope. Profiles use 65 arc samples including endpoints and 129 transverse samples, original-width-dependent radius, and physically downsampled clean targets. Raw output uses the established true linear extension of the robust penalty, avoiding dead gradients from output clipping. Correct saturated black/white remain valid. Only cross sections wholly inside an active region contribute at a scale. Choices aggregate all stages before minimization.

`global` chooses a single candidate for all paths and arc samples. `path` chooses a sequence separately for each path using exact min-plus dynamic programming. Adjacent offset transitions cost .25 * delta_offset^2 / max(arc_spacing,1). A protected gap resets coupling. Exact ties choose one minimizing path through argmin/gather, avoiding gradient averaging. Both objectives have the same clean candidates, envelope, profiles and weights; only the choice coupling differs. Compared with DN, the common objective also changes, so the two-arm contrast isolates coupling, while comparison with DN assesses the entire change.

The nine states are the existing global translations (normal to the first path at its midpoint), not newly invented local-normal translations. Dense sampling and transition regularization do not guarantee topological connectivity between all pixels, and transverse profiles can contain nearby other strokes. No-path black/blank examples are controlled by the envelope. No guaranteed fix for black boundary damage is claimed.

Preflight tests: exact DP agreement with exhaustive paths, tie gradients selecting one path, smooth drift tolerance versus abrupt switches, real raster acceptance of opaque clean and coarse antialiasing, rejection of gray average/missing/cut/outside strokes, finite gradients through wrong saturation, zero protected-region gradients, actual generator updates and exact checkpoint restoration/export. Repeated ROCm training replay uses the previously measured DO envelope atol 5e-6/rtol 1e-4 for full state and scalar metrics; snapshot restore and export remain exact. Failure is recorded and investigated rather than silently changing tolerance mid-run.

Save raw/EMA and optimizer at 0,6,2000,6000. Use raw6000 for the fixed comparison, not the best-looking checkpoint. Reuse the established 256-image standard screen (3 masks,2 Gaussian draws), 64-image stress screen (existing six corruptions,2 masks,2 draws), and eight 512px multi-shape float/uint8 scenes (whole/partial,2 draws,depth6). Compare initial/global/path. Numerical image-to-teacher diagnostics do not select a winner. Inspect native pixels for opaque clean strokes, input adherence, continuous junctions, preservation of faint/wide/partial strokes, and absence of gray halos, spurious cuts and fill damage. Additional declared native views include all six wide probe cases and close parallels. Preserve intentional gaps documented in `scene512-interpretation-20261013.md`.
