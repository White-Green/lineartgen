# 投影graph教師の回転・反転

次の広域学習に備え、既存512例の投影教師へD4回転・反転を適用する補助関数を追加した。HUの実行中の学習には適用していない。CNNの特徴はD4 groupだが現在の9channel headは自由な線形層なので、出力offsetやedgeが自動的に正しく変換されることは保証していない。

存在・log幅・塗りは画像として変換、xy offsetは右向きx/下向きyのベクトルとして符号・軸を変換する。4方向の無向edgeが逆向きになるときは、channelの交換だけでなくedgeの始点を隣cellへ移す。境界でwrapしない。

4テスト通過（1.81s）。全64群合成と全8逆変換の完全一致、元の連続幾何を変換して再生成した教師との事前2e-6一致、描画の回転/反転の事前1e-5一致、境界edge、塗り、ベクトル符号を検証した。lint通過。これはデータ処理の整備であり学習性能改善の主張ではない。

既存512例の投影ラベルも別途 `/tmp/lineart-attraction-training-cache-20261018` に用意した（40.736s、全fine path表現あり、モデル予測0・学習0）。元ソースのgeometryは固定で、元datasetの追加warpはこのcacheに含めていない。使う際にはsourceと教師へ同じ幾何変換を適用する必要がある。
