# CX: 灰色の残留は減ったが、細線の切断が増えた

候補固定の有無×二乗誤差/Charbonnierの4条件を、同じCV初期モデル、512例、
16ch/15,809params、同じ入力系列で各6,000更新比較した。
CW数値commit ee1bd06、CX数値commit 6616422。[CX固定計画](robust-family-plan-20261013.md)。

新規probe whole .5、例ごとの平均:

Charbonnierで断面・余分なink・黒の粒は改善したが、切断は悪化。
旧probeもdynamicの切断率.02982→.04470、stable .02339→.04518。
断面のmissing fractionも増えた。誤接続queryの有効集合は候補で変わるので率だけで選ばない。

16等倍シートを全て確認。old_probe36は元々弱かった並行線の片方がほぼ消失した。
new_probe36は2本を1本の太い帯に融合したまま。old_train24の細い枝も欠損したまま。
一方で細線周辺の粒、黒塗りの白い粒、線端の突起の一部は減少した。
線を消して見た目を整えることは成功ではないので、4条件とも採用しない。

CW/CX合計24,000更新、共通初期値を含む各4,608行、各1,536参照行、計32等倍シート。
入力・初期値・固定候補・全6,000更新のinput digest・1,536初期予測の一致を照合。
CX CPU2テスト合格(8.46秒)、6更新GPU再実行・保存復元・12exports完全一致。
記録は runs/robust-family-20261013/。比較照合は factorial-binding.json。
