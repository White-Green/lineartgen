# HC: 遠方の保護領域による方向制約の不整合を小規模比較する

HBで確認した深さ1の不可能な教師条件を修正し、同じ21890パラメータでwhole/partialの両方に一本の線を出せるか検証する。モデル容量・pixel MSEは変更しない。合成データのみ、本番採用・fresh16確認は行わない。

入力はHBの48px正方形、中心(208,208)、opacity.4、blur1.2、strength.5。全体適用と既存部分マスクの2例を同じbatchで学習する。HB入力配列と完全一致をprepareで検証する。未変更GW初期choiceから独立した2armを作り、フィット済みGX/GY等の重みは使わない。

- global: 画像全体でt>0のときだけ近水平の別軸を許す旧方向制約。
- local: 原軸・別軸の全18位置候補について、各候補にfield<−.25のinkがあり、field<4の支持域全体がt>0内にある場合だけ同じ近水平方針を許す。それ以外は原軸のみ。

両armは全18候補、共通ROI・正規化・costを完全に共有し、最終候補maskだけが異なる。旧GYは部分適用時に別軸fieldも原軸に置換していたため、global armはGYの算術的再現ではない。この比較は方向許容maskの効果を分離するもの。

600更新、全6再帰段数を順番に100回、各段loss重み.5^levelを正規化。B2、accum1、peak1e−4√2、minimum1e−5√2、cosine600、warmup0、clip1、EMA.999、context dropout.5。geometry.1/sign.25/global L4、opening0。候補shift±2pxの9通り、方向は全段で一つ。各stepの入力digest・選択bit・safe率・metric・所要時間を記録する。最初18更新の自前再演でmetricと全state完全一致を要求。0/18/200/400/600の全stateおよび各raw/EMA計20exportを完全一致検証する。途中checkpointは品質選択に使わない。

固定評価: train2とtransfer4（同sourceで部分境界threshold120/170、中心192で標準部分mask、中心128で図形を切る標準mask）、深さ1/3/6、初期/global600/local600で54出力。transfer4は位置・maskだけを変える局所的検証で、形状・style汎化試験とは呼ばない。最後のcut例はsafe=false、両方原軸のみとし、未学習条件での失敗も記録する。保護画素は厳密保持。教師原寸2枚を学習前、出力原寸6枚を学習後に全て実際に確認する。評価は線の連続性、不要な直交線、灰色、端点。数値を使う場合は既存GZの線coverage・3px tube外inkの記述的測定に限り、閾値を後から採用条件にしない。

このguardはHB構成例を修正する保守的な条件であり、mask境界と交差する任意の長い図形について局所的可識別性を証明するものではない。blank escapeを防ぐだけで本番品質を保証しない。両学習例で一本の線が得られれば広いデータ分布での検証へ進む。学習例でも失敗すれば、容量増加と断定せず教師・目的関数・最適化を再分析する。前提・sourceは学習前に固定し、失敗時は記録を保全する。
