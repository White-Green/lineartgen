# EF: 初期fieldと学習率の修正で、灰色帯・欠落が大きく改善

同一group6（16,402重み）の初期field +8/+1、peak LR1e-4/1e-3を2×2で各3,000更新した。loss・モデル構造・既知16形状・D4/rough拡張は共通。320出力と指定8等倍ページを確認した。

**+1、peak1e-3が明確に良い。** 太い下描き0–7から、ほぼ灰色帯や二重枠のない黒い中心線を出した。近接曲線9–11は連続性と幅が揃い、許容する綺麗な端の閉じ方になった。交差12/13は大きな切れが消え、blank14は白、黒塗り15は格子状の白穴が消えた。rough入力でも改善を維持する。ただしrough8の上側曲線の中央に明瞭な切れ、下側にも弱い部分が残る。0付近の微小な薄い点や端の粗さも完全には消えない。少数例への適合が進んだ結果で、汎化・製品採用ではない。

同じ初期白画像でも、内部field+8から背景制約を満たす+1への初期値変更が、今回の最適化に大きく影響した。near/farでは再帰内部状態も変わるため、効果を出力biasの距離だけに限定して説明しない。EEの低い適合度をモデルサイズ不足とみなす根拠は弱まった。通常CNNへの適用はまだ未検証。

初期bias以外の重み一致・全6段の初期field/画像・sqrt(batch)LR・4群の共通入力を追加3テスト（15.40秒）で確認。未変更のEEの5 CPUテストと4 GPU等変性テストも出典を保存。全3,000更新の入力・教師・Gaussianが一致。6更新再実行、全状態復元、32 raw/EMA exportの監査が完了。各形状×段数の提示103–149、各形状×方向70–115。
