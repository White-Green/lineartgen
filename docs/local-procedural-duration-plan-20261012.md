# CM: 小型CNNの合成学習を低い学習率で継続する

CLの2回推論では、合成学習4,000更新で広い条件の未達判定が198/229から111/229へ
減ったが、線に粒状の濃淡が残った。固定した細い曲線などが薄くなる例もある。
CLの全評価と画像レビューを完了してから、その実際のraw10000/model/Adam/EMAを
継承し、最終20000まで10,000更新を追加する。32回評価を見て条件を選ばない。

モデル15,809パラメータ、depth1–6、2回rollout、u=1/.5、.1 AD image loss、
batch4、最細段lossから全再帰への勾配、source/noise/progress条件は同じ。
新しいloss・共有ノイズ・モデル幅は加えない。中間checkpointやEMAで選別しない。
まだモデル容量不足か、学習量・最適化不足かを確定しておらず、追加学習の品質を調べる。

data seed2026101111を保ち、既存CLのdata index0–3999に続く4000–13999を使う。
40,000枚の教師を同じBL手続き的分布から生成し、新しいcropやline形状を得る。
実下描きペアやnative corpusでの学習は行わない。下描き・部分マスクの設定も同じ。
Gaussianは既存geometry seed2026101093の対応するdata indexで生成する。
optimizer step10000–19999とdata index4000–13999を明示的に対応させ、再帰深さは
双方の剰余が一致する。開始6更新はdepth5/6/1/2/3/4。

基礎LR5e-5×sqrt(batch4)=peak1e-4を保ち、warmupなし、cosine horizon20000、
minimum1e-5にする。復元したoptimizer count10000で実際の開始LRは5.5e-5、
count20000で1e-5となる。LRをリセットして1e-4へ戻さない。
Adam/EMA状態は完全に継承する。期間とスケジュールを共に変える継続実験であり、
学習率だけの因果効果とは呼ばない。

状態10000/10006/15000/20000、8raw/EMA exports、初期全状態一致、6実更新の
完全再現、全保存復元・export一致を確認する。学習前にCLの固定38パネル×2回数の
76clipped出力とE/R16出力を完全再現する。各data indexの教師ハッシュ、個数、
入力ハッシュ、更新時間を記録する。最初6batchと以降100batch毎、合計105batchの
教師はCPUで先に独立生成してハッシュを固定し、実学習の記録と照合する。

最終raw20000を2回推論（主）/32回推論（副）の各1566開発条件で評価する。
E/R、CL10000、CM20000の各6264行、合計12528行。44 corpus identitiesは
合成劣化評価の教師にだけ使い、独立seedや封印条件の確認とは呼ばない。
CLとCMに各229の既存品質基準を適用し、緩和しない。
各回数でE/R/CLの4698指標行と114固定パネル出力を完全再現する。
各6枚、合計12枚の固定raw画像をネイティブ解像度で確認する。
alpha<.1の表示除去は使わない。finite・保護画素完全一致も必要。

配布モデル、Krita plugin、runtime defaults、採用判断は変更しない。
BGRA API/ONNX/Krita GUIと独立確認は、十分な品質の候補が得られた後に行う。
