# EP: 異なる濃さの独立筆跡を合成して学ぶ

EOの8bit拡張だけではscene1の近接線の途切れもscene7の弱い交差線の消失も改善しなかった。ENの幅拡張・merged geometryを保ち、単独筆跡だけでは不足する複数筆跡の共存を検証する。EKは同じrough条件のmin合成で僅かな改善に留まった。ここでは濃さ・ぼかし・変位が独立した筆跡を透明度合成する。これは学習分布の一括変更であり、compositionと濃度差それぞれの因果効果を分離した実験とはしない。

EI group6 raw18kからmixed群を6,000更新し、完了済みEN merge6kを対照として再利用する。16,402パラメータ、同一初期値、optimizer/EMA reset、seed2026101502、batch4、基準LR1e-4×sqrt4=peak2e-4、cosine最小2e-5、warmup0、再帰1–6段、全段loss.5^levelを維持する。EOの8bit化はこの群に加えない。

主筆跡がstraight/thin/bezier/corner/taper/wideの288形状のとき確率.5で同じ288形状から独立の筆跡を追加する。主筆跡、元rough、D4、mask、Gaussianの乱数はENと一致する。追加有無と相手は独立キー[seed,step,item,0x4F564552]で選ぶ。相手のroughとwidthは既存関数のitem+4キーを使用する。両方の元形状・位置・長さを変えず、wideの幅拡張も従来の25%元幅/75%loguniform4–32pxを用いる。

入力の白背景輝度u=(source+1)/2をu_primary*u_secondaryで合成し、交差する透明な黒い筆跡の重なりを作る。線の平均画像ではない。教師は各筆跡の不透明geometry fieldのminで作る幾何的和集合であり、灰色画像の平均を教師にしない。主筆跡のnormalを使う9個の位置候補では合成形状全体を同時に動かす。

parallel/junction/crossing/gapとblank/fillは追加対象にしない。merged候補を持つparallelは常にENと同じ入力・候補であり、全更新で候補許可フラグ一致を検証する。追加のないbatchは入力・教師・候補payload全体がENと完全一致することを確認する。追加例の教師変更は意図的である。部分編集の保護領域は合成後の入力を保持する。縮小後Gaussian、loss、モデルは変更しない。

事前に透明度合成の交差/非交差、抽選独立性、除外群を試験し、実データで全6段の非変更例一致、教師和集合、方向/mask一致、保護領域、Gaussian残差を確認する。4例の合成入力と不透明教師を等倍で見る。モデル/lossはENとソースhash一致を検証して試験を継承し、実学習の6step再現・全状態復元・8export照合を行う。

学習は3,000更新ずつ2区間。最終rawをENと同じ9,516出力・事前固定34ページおよびscene1/7追加等倍で比較する。初期/対照予測一致を確認する。交差・近接線の連続性と不透明さ、太い線・基本線・fill・部分編集の退行を重視する。画像MSEやRMSで採用を決めない。予約済み新規確認と製品は変更しない。
