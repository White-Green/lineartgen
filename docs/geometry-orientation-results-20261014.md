# EB: 太線の失敗は向きに強く依存する

EAの2つの最終重みを固定し、既存の8入力を回転・反転した。90度刻みの回転と左右反転の8通りを使い、出力を元の座標へ戻して128出力、16ページを確認した。補間・学習・出力平均は行っていない。コード`7d9790b`、変換の逆写像/ピラミッド整合テストとRuff通過。

太線59では、元の向きと180度で黒帯になるのに、90/270度では細い中心線になる。61も反転の有無で黒帯から細線へ大きく変わる。62は対照モデルで、元の向きの断片が反転0/180度でほぼ連続した細線になる。一方58は8通りすべてで幅むらや二重線が残り、regional版62もすべて不十分だった。回転・反転だけで全問題が解けるわけではないが、単なる画素位置の微小差を超えた向き依存を確認した。

通常の近接曲線36は多くの向きで滑らかな一本にまとまり、37は途切れる位置が向きで変わる。正方形56の角の穴も方向を持つが、対称な同一形状を変換した結果なので独立した8形状の評価とは扱わない。Regional版の穴は対照より小さい。

評価2.78秒。無変換16出力はEA保存結果と完全一致、重み不変、全出力有限。回転前後の出力RMS差は最大でcontrol0.226/regions0.364。ただしこれは向きへの感度であり、線画品質や正解画像誤差の評価ではない。

次はEA regionsを共通初期値として、同じregional lossのままD4データ拡張あり/なしを比較する。回転に合わせて入力、マスク、Gaussian、幾何ターゲットと許容移動方向をすべて整合させる。推論時の向き選択や平均には頼らず、単一推論での線画品質を評価する。製品採用なし。予約済み新規確認とKritaは変更しない。
