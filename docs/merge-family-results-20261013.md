# DL: 近接線の統合候補を加えた結果

一本へ統合する清書候補は実際に選ばれるようになったが、太い灰色帯の解消には届かなかった。
scene5の長い曲線の副線は少し減った。old/new_probe36、new_probe37/39/40、512px scene2には灰色帯が残る。
交点の切れやsharp入力の灰色直線も残り、製品には採用しない。

数値コード `e3186cc`、branch `experiment/merge-family-20261013`。
run `runs/merge-family-20261013`。DK normalized raw18000からcontrol/mergeを各6,000更新した。
両群15,809パラメータ・同一入力・同一optimizer/LR。合成のみ、Krita・配布は変更していない。
再帰1–6、各段loss、sqrt(batch)スケーリングも維持した。
入力の支持がある近接二経路について、9位置の一本線を追加し、元の二本線候補はすべて残した。
24,000学習項目中1,163項目で統合候補が許可された。

標準4,608行、劣化4,608行、512px128出力を生成した。
標準8枚・劣化8枚・512px6枚に加え、全parallel probe12例の3枚も実際に等倍確認した（計25枚）。
出力の二値化・コントラスト調整なし。保護領域は入力と完全一致。
薄い入力での黒い線・黒ベタというDKの改善は保たれ、明瞭に離れた二本線も概ね保持する。
一方、一本への整理を許した例でも灰色が残るため、線の本数を固定していたことだけでは説明できない。
従来数値指標は本数固定なので、正当な統合を誤り扱いする場合があり、採否の根拠にはしない。
