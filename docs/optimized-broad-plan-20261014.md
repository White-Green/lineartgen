# EI: 改善した初期化と学習率による512合成形状の小型モデル比較

EHでは16形状の最適化改善が広い入力へ十分転移しなかった。モデルを大きくする前に、同じ改善条件を既存512形状とwhole01/whole05/partial05へ適用する。通常16ch（16,064重み）、D4 group2（2,022）、D4 group6（16,402）を新規初期化し、各18,000更新する。これらは独立した比較モデルで、入れ子学習の比較ではない。

EGと同じmodel seed2026101432、head kernel0 / bias.125（physical field+1）、全段白画像を初期値とする。全群でregional censored distance + boundary gradient.1 + near/far RMS sign.25、同一データ・Gaussian・マスク・拡張、batch4、再帰1–6循環、全段lossの重み.5^levelを維持。base LR5e-4×sqrt4=peak1e-3、50 warmup、cosine minimum1e-4、Adam/clip1/EMA.999。seed2026101440。容量・対称性・特徴数・計算量は同一ではなく、この比較だけで対称性の因果効果や最小容量を断定しない。

学習はECの既存512形状・geometry cacheをハッシュ固定して読み取り専用再利用する。25%既定source、75%opacity.2–.8 / blur.6–2.4 / warp0–1.5のrough拡張、全群同じ一様D4を使用。geometryと法線、Gaussian、全段入力・マスクも同じ変換にする。形状×段数・方向・マスクの提示を検証する。別のfresh形状は生成しない。

EGで長いdriverセッションが最終保存後に143終了した理由は未確定。今回は4,500更新ごとに正常終了させ、保存した全学習状態から次区間を再開する。学習率は18,000更新全体の同じscheduleで、optimizer/EMA/stepをリセットしない。保存は0/6/4500/9000/13500/18000、36 raw/EMA exportを全状態checkpointと照合する。6更新再現、6段初期出力一致、全更新入力一致も確認。途中画像を見て終了点を選ばない。

最終raw18000の3群とEC d4 raw12000（学習履歴の異なる参照）を、固定済み標準256入力×3mask×2draw、stress64入力×6劣化×2mask×2draw、512px8場面×2mask×2draw×float/uint8で評価する。合計12,544出力。標準12・stress10・512px6の計28等倍ページを全確認。標準/stress depth3、512 depth6。評価seed2026101441、512は従来の2026101319。Gaussianを利用しないsource-onlyモデルなので2drawの一致は頑健性の新しい証拠ではない。

画素MSEで選ばない。滑らかな融合・端の接続を許容し、入力に沿う濃い連続線、局所的な線幅・曲率の一貫性、余分な灰色帯・破片・塗り穴の有無を判定。partialの保護領域は完全一致を必須とし、適用境界の切れや増殖も確認。場面1/7の意図的な大きい切れは誤判定しない。EC参照出力が既存保存物と一致することも監査する。legacy数値指標は診断のみで採用判定にしない。

追加テストは512全形状のsampling coverage、6段での全3群入力・Gaussian・マスク一致とD4逆変換、実3構成のfield+1初期値を確認。数値モデル・loss・D4処理の検証済みテストはソースハッシュ付きで継承する。新しいevaluatorは既存評価処理を4モデルへ適合し、全予測に有限値・範囲・保護領域検査を入れる。

全開発評価の実画像確認後に次を判断。改善が不十分なら欠陥を限定して診断し、十分なら既に予約した未評価入力へ進む。この試験だけでは製品採用しない。Kritaと本番モデルは変更しない。
