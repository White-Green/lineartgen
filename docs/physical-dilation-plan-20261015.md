# EX: physical dilation の学習比較（2026-10-15）

EW の固定重み診断で軽減した副線が、同じ構造での学習後も改善するかを検証する。

EQ mixed raw18k を起点に6,000更新。対照は完了済み ET dropout raw6k を再利用する。パラメータ16,402個、重み初期値、学習入力・元教師・結合教師・候補の許可条件（cap8）、各例の再帰辺dropout p=.5、乱数、バッチ4、学習率sqrt(batch)によるpeak2e-4から2e-5への減衰、clip1、EMA.999を一致させる。深さ1〜6を循環し、各段lossの重み .5**level も保持する。

唯一の変更は各畳み込みの dilation を max(1, base // 2**level) とすること。元の1/4/16が最も粗い段では1/1/1になる。重みの共有方式、D4群、FiLM、head、出力の面積被覆レンダリング、再帰のmean/clip/nearest、入力正規化は同じ。EV の support-only 変更は使用しない。

深さ1の関数と勾配、EWの手動physical推論との深さ1〜6の一致、全入力・教師・maskのハッシュ、ET対照の最初6更新の全状態再現を先に検証する。新規モデルを独立した research_model タグで保存し、従来ローダーは拒否する。学習後は保存全状態とraw/EMAの一致を確認する。0/6/1000/2000/3000/4000/5000/6000で保存し、1,000更新ずつ同一optimizerを継続する。中断は終了コード・ログ・不完全journalを保全してから扱う。

既知の標準・roughストレス・float/uint8 512px場面・幅スイープを評価する。合計9,516出力、34枚の等倍比較ページ。対照出力は ET dropout と配列一致を確認する。数値lossだけで採用せず、黒く滑らかな主線、副線や灰色帯、接続・意図した隙間・細い分岐・部分maskを目視で評価する。probe37、wide61/62、scene1/7を含めて悪化も記録する。

予約済み新規確認入力はまだ使わない。Krita・本番モデル・CI artifactの変更はしない。この比較は固定済み既知データでの構造診断であり、汎化確認ではない。
