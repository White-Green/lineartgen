# ES: subpixel位置の保持だけでは副線は消えず、倍率2は悪化した

固定重みで5通りの再帰条件を比較した。新しい空間位置の保持（head展開→2×2平均）はlegacyと見た目がほぼ同じで、mixedのwide61/62の副線は残った。条件を2倍すると副線が濃くなり、三本線の枠状になった。mergeのwide62だけは小さな線片が減ったが、全体の改善ではない。zeroは副線を除く一方で端の膨らみが増え、短い曲線37の断片やscene7の弱い交差線の途切れは残る。

scene1の黒く連続した融合線は全条件で維持された。mixedの分岐も接続を保った。mergeの分岐切れは全条件で残った。以上はfloat/uint8で同様だった。既存モデルを異なる条件分布に置く介入であり、この結果だけで別の受け渡し方式を再学習する価値を否定しない。

180出力・20等倍ページをすべて実際に確認した。legacyの36出力はER depth6と、zeroの36出力はER depth1と完全一致。モデル不変・有限値・範囲・hashを確認。新しい演算の平面距離/中心位置およびD4可換性のCPUテスト2件（1.25秒）とRuffが成功。固定コード03a2a29、GPU評価16.116秒、終了0。学習・採用・予約fresh評価は行っていない。
