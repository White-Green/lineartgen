# GY: 一貫した許容軸選択の通常学習比較

GXでは学習12例への適合は改善したが転移と長い線・塗りの保持は失敗した。時間方向の軸切替は両条件0回だったため、その抑制が原因とはしない。本比較は近い曖昧例に共通した方向を割り当てる方針を、通常線・塗りを含む広い合成データに持ち込む。画像MSE最小化やモデルの大型化を目的としない。

初期値はGWの未変更choice初期値、21890パラメータ。GXの適合済み重みもGWの学習済み重みも新条件の初期値には使わない。GWと完全に同じ6000バッチ（3750従来、1500GL長線・塗り、750GV曖昧形状）、各サンプル・候補・部分マスク・ノイズ・context dropoutをdigestで照合する。全6段、各段0.5**levelの正規化loss、B4、LR基本1e-4×sqrt(4)=2e-4からcosine6000で2e-5、warmupなし、clip1、EMA.999、opening0、geometry.1を保つ。

変更は許容候補の最終選択マスクだけ。GWの18候補の距離・符号・勾配costと共通正規化を保持し、全体適用で別軸が許される例だけ、水平に近い一本線の9位置候補に限定する。45度同率は画像座標で正の傾き。同じ候補を全段まとめて選び、画素や段ごとに方向を混ぜない。方向に好みのある選択であり、回転不変性や確率的生成ではない。

部分適用と非該当例は元の教師を維持する。別軸のないバッチはGWのfamily_partsをそのまま使い、merged候補の取り扱いも変えない。選択マスクは候補cost計算の最後にだけ適用し、ROIや正規化を絞らない。実際の選択ビットを全更新で記録し、事前に計算した許容方向と照合する。

対照は完了済みGW choiceのraw6000を固定して再評価する。新規学習はconsistentの1条件だけであり、対照を再学習したとは主張しない。同じ初期値・データ・scheduleを照合し、元のGW objectiveで36更新と保存済み全状態を再現する。異プロセスの浮動小数演算には事前にatol1e-6/rtol2e-5を許すが、新条件自身の36更新、保存復元、入力digest、最終の参照画像比較には完全一致を要求する。再実行が必要なら元の失敗を保全し、未保存状態の完全復元とは主張しない。

保存は0/6/36/1000/2000/3000/4000/5000/6000、raw/EMA18個と全学習状態。品質判定は最終raw6000だけ。評価はGWと同じ標準・強い劣化・512px・太さ掃引9516出力、FU/GK/GO/全成分206出力、固定58枚をすべて実際に見る。参照initialとwinnerはGW保存出力と完全一致させる。全成分は診断だけで選び直さない。必要な中心切り出し・alpha分布は補助記録として区別する。

候補に進める条件は、短く太い例の一本化が広い幅・角度で改善し、普通の曲線・交差・隙間・細線・塗り・部分適用を壊さず、灰色の周辺片・余分な線・端の模様が許容できること。記述的なlossやcoverageだけでは採用しない。広い条件が通った後にのみ独立確認の計画を固定する。fresh16、Krita、本番exportは本比較では変更しない。
