# DC: 追加Gaussianの除去は粒状感を減らすが、灰色の帯は残る

数値ソース `5e4e68a`。DB augmented raw6000から、noisy/source_onlyを各6,000更新。
同一15,809パラメータ、同じ可変下描き・全入力tensor・複数許容清書loss。
**製品未採用。** Source-onlyは黒面内部の粒と輪郭のざらつきを明確に減らす。
しかし薄い細線の灰色、強いぼかしの滑らかな灰色帯、薄い黒面の輪郭リングが残る。
追加ノイズが粒の原因の一つであったことは支持されるが、灰色全体の解決ではない。

計画した標準8枚＋stress8枚を等倍で確認。512px複数形状・8bit入力も6枚確認。
512pxの太い曲線は滑らかになる一方、中空の輪郭や横の灰色帯が残る（scene1/2/5）。
細い交差枝はまだ弱い（7）。標準old_train24の枝も完全には整わない。
近接線が一本になることは入力の曖昧さを考慮するが、その周囲の灰色は望む清書ではない。
