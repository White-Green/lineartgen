# Candidate after the convergence check: connection-specific supervision

This is a research note, **not a queued training experiment**. The4,000-update continuation must finish first. At fresh800, all eight gap draws still connect at25% opacity despite better F1 and ink retention. The output-space audit confirms a correcting gradient exists in the gap; it does not establish a model-parameter optimization failure or prove that more training cannot fix it.

The existing implementation in `training/cldice.py` is a grayscale adaptation of soft skeleton coverage. It replaces product intersections by minimum-style deficits; its documentation explicitly disclaims the original topology guarantee. Its previous10k comparison was rejected for thin-line loss/cuts. The original [clDice paper](https://openaccess.thecvf.com/content/CVPR2021/html/Shit_clDice_-_A_Novel_Topology-Preserving_Loss_Function_for_Tubular_Structure_CVPR_2021_paper.html) measures skeleton/mask overlap and develops a differentiable surrogate; that result is not a guarantee for our modified grayscale objective.

[Topology-Preserving Deep Image Segmentation](https://proceedings.neurips.cc/paper/2019/hash/2d95666e2649fcfc6e3af75e09f5adb9-Abstract.html) instead supervises topology through Betti-number information. Matching component/hole counts does not, by itself, specify which particular strokes should be connected; that limitation is our interpretation for this line-editing task, not a result from our experiments with that paper's implementation.

The more directly relevant precedent is [MALIS](https://proceedings.neurips.cc/paper_files/paper/2009/file/68d30a9594728bc39aa24be94b319d21-Paper.pdf), which learns maximin affinities to supervise pixel-pair connectivity of thresholded affinity graphs. The key quantity is the strongest path's weakest affinity. It provides a way to focus supervision on merge/split decisions rather than treating every local edge independently.

An experimental adaptation here could use opacity as a vertex capacity, with8-neighbor edge capacity `min(alpha_u, alpha_v)`. For two known stroke anchor neighborhoods, define `c(a,b)` as the maximum, over connecting paths, of the minimum opacity along that path. Compare this with **the antialiased teacher's own capacity**, not a blanket target of one. A missing intended connection has too small a capacity; a false gray bridge between disconnected strokes has positive capacity where the teacher has zero. Average penalties per declared connection query rather than diluting one gap among all image pixels. This would be our adaptation, not a reproduction of the original binary affinity-graph loss.

Before any training, an oracle must distinguish an intact antialiased thin line, a real cut, a correct intentional gap, and an inserted faint bridge. Equality to the teacher must give zero loss and gradient; lower-opacity valid teachers must not be forced black. A JAX implementation would also need verified gradients at bottleneck ties, protected-mask handling without teacher leakage at inference, and an explicit finite propagation limit. A local patch can miss a connection that travels outside it; a whole-image graph can be expensive. Width, spurs and antialiasing still need separate pixel/profile constraints. No coefficient or model is selected by this note, and no fresh confirmation is used.

The immediate low-cost oracle below measures capacities on already seen targets and stored outputs using thresholded connected components. It adds no training objective or inference operation. Its role is to test whether the proposed quantity actually exposes the observed gray-bridge failure before implementation is considered.

The measurement oracle in `runs/connectivity-capacity-oracle-20261009/` passed six controls: intact thin line, intentional gap, a transverse cut, and inserted bridges at10%/25%/50% opacity. It uses16 bisection steps over thresholded8-connected components, resolving capacity to1/65,536. The teacher thin line's capacity is.812744, while the intended gap's is zero. For the eight observed fresh-noise draws, mean gap capacity is.427185 at800 and.401815 at1,600; every draw remains positively connected. Mean thin capacity is.925316/.868105, so this particular thin-line failure is not insufficient connectivity: width/opacity fidelity remains separate.

This validates only a measurement on these controls and stored outputs. A query loss could reduce a false connection by damaging a true stroke elsewhere along its path, or match a target capacity at the wrong location. Query placement/patch boundaries, ordinary target fidelity and explicit retention safeguards would all matter. The current oracle has no JAX backward implementation and has not trained a model; it is not a successful alternative loss experiment.
