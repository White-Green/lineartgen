# EC: 回転・反転の学習だけでは太線の欠陥は解消しなかった

EA regional raw18000から、拡張なしとD4拡張ありを各12,000更新した。同じ16,064パラメータ、regional loss、512合成形状、粗さの拡張、再帰1–6段、各段loss、sqrt(batch)学習率で比較。数値実装`bc22432`。D4は入力だけでなく全段の教師・マスク・Gaussian・幾何場・許容変位の方向を一緒に変換する。10テストとRuff通過。

固定したraw12000の9,408出力を保存し、事前指定28ページを等倍で確認した。D4版は太線59/61の黒い帯を多少細くするが、灰色の側線や端の棒状断片は残る。58/62はどちらも分断や枠状の残骸が出る。rough58/63ではD4版の中央線が対照より弱くなる。通常の直線・曲線・枝・交点は両条件とも概ね保持され、512px場面はほぼ同等。強くぼかした短い近接線36の欠落や、小さな黒ベタの角の穴も解消しない。

したがって、この追加学習は全体の採用基準を満たさない。画素誤差の順位や、教師の二本線との完全一致は判断基準にしていない。滑らかな一本への融合は許容している。

12,000更新すべてで逆変換後の入力・教師・マスク・Gaussianは完全一致。実際に提示された向きは11,998更新で異なる。全形状に全6段数で3–30回、全8方向で1–24回の提示がある（段数と方向の全組み合わせを保証するものではない）。初期6段数の関数、先頭6更新の再実行、全状態復元、16 raw/EMA exportが一致した。参照DN出力3,072件の再利用一致、保護領域保持、Gaussian draw間の同一性も確認。

学習4,209.18秒、標準143.72秒、劣化90.57秒、512px8.50秒。最後600更新の平均はcontrol0.12953秒、D4 0.13067秒。重み変化RMSは0.01268/0.01298。512px float/uint8出力差RMS平均/最大はcontrol0.001431/0.004151、D4 0.001436/0.004042。これらは整合性・動作の記録であり、画質改善の証明ではない。

次はEBと同じ既知8例の向き診断を、今回の固定した両モデルで再実行する。EC計画では広い品質改善があった場合の確認を想定したが、今回は改善が限定的なので、残る向き依存を切り分ける開発診断として別計画を固定する。checkpoint選択・推論時の方向選択・平均化は行わない。新規確認データ、Krita、製品モデルは未変更。
