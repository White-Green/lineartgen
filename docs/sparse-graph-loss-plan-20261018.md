# HS: graph分類の余分な頂点/辺を背景平均で薄めない

HRでは正解の存在を高recallで拾う一方、余分な頂点/辺が多く、太り・穴・誤接続になった。パラメータを増やさず、22725の同じGraphCNN・不透明decodeで分類の正規化だけを比較する。HR最終raw1200を両条件の共通初期値とし、fresh AdamW/EMA、各1200更新、base1e−4×sqrt(B4)=2e−4→2e−5 cosine。HRと同じ10形状・同じ1200バッチ・深さ1〜6（各200）・全段.5^level平均・opacity/blur・whole/partialを使う。全入力hashをHRのsamplingと照合する。

対照はHRと同じ正負それぞれの個数で平均したBCE。候補は頂点と辺だけ、全cellのBCE合計を画像毎の Npositive + .001*Ncells で割る（eps1e−6）。背景を減らす重みを後から選ばない。.001は空画像でも分母を有限にし、空/非空を同一式で扱う事前固定のfloor。塗りのBCE、occupied cellの座標/幅Huber、各項の係数は変えない。loss全体のスケールとclip頻度が変わるので、一因子の正規化比較であって有効step長が一致すると主張しない。
