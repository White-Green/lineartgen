# HV: 投影モデルの誤差分解（実行前計画）

HUの太い帯・交差の膨らみを、存在誤検出、座標の散らばり、幅、辺に分ける。学習0、推論0、保存済みHU raw1200 depth3のheadのみ。両条件balanced/count、probe12/24/36/37/59とscene1/2/7の8例。全16原寸ページを確認する。

各ページ6列を2行3列に配置：raw、存在/塗りを教師へ置換、さらに位置のみ置換、存在/塗りと幅のみ置換、存在/塗りと位置/幅を置換、全教師。存在を置換した各条件でも予測辺を残し、全教師との差で辺の影響を確認する。rawは保存画像と完全一致、全教師はHU保存oracleと完全一致を要求。位置/幅の誤差は正解anchor上で測る。画像誤差は補助情報で、採用基準にはしない。

教師を使うため、改善しても学習成功・汎化成功とは呼ばない。全教師でも崩れるなら表現か実装を調べる。存在だけで解消するなら分類を、位置で解消するなら投影の収束を、幅だけなら幅予測を次の候補とする。結果を見て追加試験を選ぶ。fresh16、学習データ、本番、Kritaは変更しない。
