# IE: 線幅分布を連続的に補うR1学習

IDで中間幅の二重線と、太い入力の枠・塗りが残った。元の512教師は通常幅約5px以下とwide16〜32pxに分かれる。構造・loss・表現力を変えず、この幅の空白を補う対照比較を行う。HY6000 R1 rawを共通初期値にし、新しいoptimizer/EMAで両3000更新、B4、再帰1〜6各500、全段重み0.5^level、sqrt(4)でpeak LR2e-4、cosine最終2e-5。R1・count BCE・位置/幅Huber・fill BCE・接続lossは同一。

controlはHYの512合成記録のみ。expandedは各itemを25%の確率で新1024記録へ置き換える。共通itemは同じ入力・教師、D4、追加blurσ0〜1、opacity倍率.65〜1、部分適用25%。置換抽選・indexもseedで固定し、未置換時の一致を検証する。新例はbar幅4〜16px512件、16〜48px256件、48〜96px128件、塗り128件。各元画像はσ1.2/opacity.4で合成し、追加styleはcontrolと同じ。これにより劣化分布も一緒に拡大する比較は避ける。

新bar長さはmax(32,1.05×幅)〜208px、角度は軸方向25%、±3度近傍25%、任意50%、位置も変える。長軸を一貫して教師とし、完全正方形のH/V矛盾は作らない。教師は幅2pxの丸端線（端中心を矩形端から1px内側）で、barの塗りを要求しない。塗りは128〜208pxの軸平行矩形、境界を整数に揃え、線と混同しないよう教師fillを保つ。4倍source描画、halo32、6段R1教師を事前作成。新教師のpath欠落0、最細oracleと直接描画のatol/rtol各1e-4を検証。元512の既存level5欠落は保全。

学習前に新データの各binと角度・端・塗りの12原寸ページを確認。6更新自己再演完全一致、跨プロセス先頭6更新atol/rtol各1e-5、保存0/6/600/1500/3000のfullstateとraw/EMA復元完全一致を要求する。最終rawのみを評価し、HY標準25×深さ1/3/6＋部分8と、IDで固定した2360条件を同じ条件で比較する。原寸比較と幅・接続・隙間・塗り・保護保持で判断し、MSEは選択に使わない。

合成のみ、予約fresh16・本番・Krita・exportは未変更。成功したときだけ独立確認計画に進む。失敗しても容量不足と即断しない。IC曲線モデル学習は未開始のまま。

学習前データ監査の訂正: 初回cacheはindex25で直接描画atol/rtol各1e-4に失敗（4画素、最大0.0270948）した。端を射影するアンカーがない場合、既存R1表現は端を僅かに短縮する。この例は0.01572pxで、内部は同一直線。失敗cache・log・recipeを残す。retry1では全barについて単一連結・孤立点0、アンカーの直線からの偏差<1e-4px、端短縮≤sqrt(.5)+1e-4px、端から3px外は旧atol/rtol各1e-4を要求し、元の厳密一致成否と最大差も保存する。端短縮の許容は既存表現の格子誤差に限定し、内部の断線や位置ずれは許容しない。学習結果を見て緩和したものではない。

新規データ実装はscripts/attraction_width_data.py、研究driverはscripts/attraction_width_study.pyとする。98b1470で既存continuous_width_data.py/test_continuous_width.pyと名前が衝突したため、両既存ファイルを親0f00661の内容に戻し、新実装を別名へ移した。過去研究のコードを変更しない。

retry1の1024教師監査は成功。全6段でpath欠落0、細段barは単一連結・孤立点0。旧画素一致基準を外れた33例の差は端近傍に限定され、最大端短縮0.1322632px、最大画素差0.2293963（端のアンチエイリアス）。端以外と塗りは元基準を満たす。データseed2026101814、学習サンプリングseed2026101815。新旧教師は学習入力と同じitem/D4変換に対応し、置換しないitemはsource・noisy・mask・全段教師が完全一致することを全更新で検証する。復元/最適化は既存の同一R1実装を使用。IDの527記録・2360条件を凍結入力からコピーし、再生成による比較差を防ぐ。
