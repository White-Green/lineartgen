# DN: 清書量によるloss正規化と縮小段情報の2×2比較

DMのthinwideは一部の灰色副線を減らしたが、太い下描きが消え、blackの角も悪化した。
太線から細線への教師変更だけでは目的を満たさなかった。次の二つを独立に切り分ける。

1. 元の太いink量を分母にして細線の消失コストを小さく扱っている可能性。
2. 同じ局所入力でも縮小段により清書の被覆率が異なる場合に、段情報が不足する可能性。

全群、DMと同じRF87・16ch・3block・15,809パラメータ、全stroke2pxの候補を使う。
入力濃度の正規化、source-only、1–6段、各段loss重み.5**level、sqrt(batch)のLRを維持する。

| 群 | 段情報 | 正規化のink | 学習 |
|---|---|---|---|
| initial（対照） | なし | 元線画 | 完了したDM thinwide18,000更新を再利用 |
| level | 既存Fourier FiLMにlevel/5 | 元線画 | 新規18,000更新 |
| balanced | なし | 許容清書候補の平均 | 新規18,000更新 |
| both | 既存Fourier FiLMにlevel/5 | 許容清書候補の平均 | 新規18,000更新 |

段情報ありの群は、one-passで常に1だったprogressの9次元Fourier特徴を物理的level/5へ置き換える。
最細段を0とし、再帰深さによって番号をずらさない。既存のFiLM重みを使い、追加パラメータはない。
初期FiLMとheadが0なので、全6深さで全群の初期関数も一致する。
DEの追加scalar FiLM・warm start6,000更新とは条件が異なる。今回の効果は未確認。

balancedは画素・経路断面lossの分母だけを変更する。全候補のinkを平均して、候補間で共通の分母を使う。
予測や選ばれた候補に依存する分母ではなく、線幅を小さく選ぶ報酬を新設しない。
blank/blackは同じ教師を維持し、保護領域はlossから除外する。
linear Charbonnier+.25経路断面+.05範囲loss、全段共通の一候補選択、元のsource生成を維持。

DMと同じ512形状、seed1334/model1336/eval1335、batch4、初期Adam/EMA、
peak1e-4→cosine1e-5を使用し、新しい初期値から学習する。
各群の入力/候補/幾何は同一、正規化tensorだけ該当群で異なる。
level群の全18,000入力をDM thinwide journalと照合。対照の最初6更新も再現する。
新規群の最初6更新を再実行(atol1e-7/rtol1e-5)、0/6/6000/18000の状態保存と24 raw/EMA exportを完全復元比較する。

CPUで同容量・初期関数一致・段情報への応答・真の勾配・実更新/再開・保存/読込・JAX/NumPy sampler整合を検証。
旧none/constant/level構成の動作を保持する。既存と同様、未検証ONNX exportは拒否する。
正規化の構成例では白紙へのlossが太線入力だけ過小にならないこと、保護領域・blank・blackを確認する。

評価は標準/劣化それぞれ6,144行、同じ等倍16枚に全parallel/wide24probeの6枚とwide劣化18条件の5枚を追加する。
512px8sceneの全群192出力（2mask×2draw×2encoding）を確認し、等倍6枚を読む。
灰色帯だけでなく、線そのものの消失、交点、幅の一貫性、blackの角/周辺を重視する。
意図的gapと保護領域の薄さは失敗と区別する。固定太線参照へのMSEを採否基準にしない。
改善した場合も、使い回しているprobeだけで最終性能を主張せず、新しい合成例での確認を別途行う。
合成のみ。Krita・配布・output thresholdは変更しない。
