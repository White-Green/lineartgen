# 10k不合格時の条件付き追試

STE neighborの10k結果を見る前に、次の追試を固定した。
現在の候補が最終条件を満たした場合は、先に別seedと新しい合成入力の確認へ進む。

2kの直接比較では、hard neighborはにじみをより減らし、STE neighborは強いblurでの
細線欠落をより減らした。共通100k起点・同じ学習入力を使った両モデルの重みを
`(1−α) × hard + α × STE` で補間し、両方の性質を保てる領域があるか調べる。
αは0.25、0.5、0.75の3点に固定する。モデルを1個にまとめるので、推論の演算数や
パラメータ数を増やさない。出力画像を混ぜる実験ではない。

[Model soups](https://arxiv.org/abs/2203.05482) はfine-tuningした重みの平均を扱う参考研究だが、
今回の線画や異なる学習勾配での改善を保証しない。この2モデルが補間に適した領域にあるかは未確認。

まず両モデルの2k重みで3点を評価し、既存screenと目視を通った点のみ、
主halo改善の合計順で最大2点、同じαの10k重みを評価する。
結果を見てαや採用基準を調整しない。EMAとrawも同じαを使う。
α=0/1の重み・出力の完全一致、設定差がforwardを変えないこと、GPU評価入力の一致を検証する。
追加学習や独立した対照再学習とは数えず、別fine-tuning seedでは両端を再学習して同じ補間を使う。

計画と2k両端の重みhashは `runs/paper-guard-20261007-continuation/planned-parameter-blends.json`。
10kの両端は作成後、補間評価の前にhashを固定する。新しい合成条件の確認も引き続き必要。
