# CL: 小型CNNへ太さ・下描き・部分適用を含む合成例を学習させる

CJの完了後に、その15,809パラメータ local CNN の実際のmodel/Adam/EMA状態6000から
10000まで4,000更新を継続する。CJを実行中に計画した。CJの途中出力で条件は選ばない。
モデルの選択理由はCIの細線・分岐の改善と小さい計算量。
CJの4組の教師には太線の内部がなく、適用強度も全画素.5だけだった。
太線のグレーや部分適用の点状の跡は学習範囲を広げて確認する必要がある。

継続するモデル・loss・ノイズ生成・2回rollout・段間勾配はCJと同じ。
width16、3 residual blocks、Fourier FiLM、最細段loss、.1 AD image loss。
外側の再帰深さ1–6、batch4、基礎LR5e-5×sqrt4=1e-4を維持し、定数LR・warmupなし。
Adam/EMAをリセットしない。旧decay horizon1200も保持し、peak=minなので定数のまま。
新しい共有ノイズ案CKや新しいlossは混ぜない。局所CNNの幅の入れ子化は未実装のまま。

変えるのは学習データの分布。既存BLの合成教師・下描き・マスク設定をそのまま使う。
data seed2026101111、data index0–3999とoptimizer step6000–9999を明示して対応させる。
16,000教師をすべて手続き的に生成し、native corpusは学習に使わない。
9種類の線形状、1–4群、線幅loguniform .6–6、細線.6–1.8、5%の白紙、4倍AA。
geometry選択率.9、残りはpaper/black/ellipse/polygon/16–128pxの太いストローク。
teacher contrast1.1の後、確率.8でtone/blur/strokesを等確率に適用。
通常opacity.25–1、sigma0–2、変位2、強劣化opacity.2–.45、sigma1.5–2.5、変位3。
強劣化率.5、膨張radius2/blend1、3本の重ね描き。従来の強度・部分マスク・identity設定。
画像と強度を先に縮小し、その後各段独立のGaussianを加える。
Gaussianは従来geometry seed2026101093のdata indexで生成、u=1/.5だけを学習に使用。

これは追加学習前後の品質診断であり、データ変更と更新数増加を単独で分離する
因果比較ではない。E/Rも異なる学習履歴の品質基準であり、同条件のアーキテクチャ比較
とは呼ばない。CJ/CL共に原始的な例だけで汎化や最小モデルサイズを確定しない。

状態6000/6006/8000/10000、8 raw/EMA exports、初期全状態一致、6実更新の完全再現、
全保存復元、全export一致を確認。開始前にCJ localの2/32回推論50出力とE/Rの16出力を

入力ハッシュ・深さ・更新時間を記録する。中間出力やEMAで最良checkpointを選ばない。

両方でE、R、CJ6000 local、CL10000 localを評価し、各6264行、合計12528行。
