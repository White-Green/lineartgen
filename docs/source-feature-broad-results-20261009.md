# 元画像特徴の広域・反復診断 — 2026-10-09

元画像特徴の改善は、単純な図形だけでなく実線画を人工的にぼかした入力にも見られた。一方、重ね描きの太さ、近接平行線・隙間の分離、反復推論には課題が残る。採用や配布モデルの置換はしていない。

配布中100k EMAと、元画像特徴のpixel/region/structure raw4kを比較した。モデルの初期値・学習履歴が異なるため、配布モデルとの差は観測比較であり、単一要因の因果比較ではない。region/structure対pixelは同一初期値・学習列の対照比較。

**反復の制約**: source-only特徴のN回推論と、強度/Nでの1回推論を228組比較した。最大差は1.192093e-6。元の入力だけで特徴と出力基準を作るため、途中の生成状態を次の反復が利用しない。1/2/5回の画像が改善して見える場合も強度条件が変わった効果であり、反復的な精緻化とは言えない。Gaussian seedへの非依存と合わせ、配布前に推論方式の扱いを決める必要がある。今回samplerやKritaは変更していない。

全1,562開発入力+4白紙、4モデル、うち38入力の1/2/5回、合計6,568条件。全条件で有限かつ保護画素の誤差0。9枚の事前固定画像と補助2枚を目視した。当初のpartialクロップは線がなく評価に使えないため、その制約を記録。教師のマスク境界近傍のインクだけで選んだ717/727の補助画像を追加し確認した。予測を使ってクロップを選んでいない。白紙の最悪出力も確認し、配布中は最大opacity.885、pixel .041、region .180、structure .249。pixelはruntimeのalphaしきい値で微小残留が消えるが、連続値では完全白ではない。
