# CW: 再帰深さ・ノイズで清書候補を変えない比較

CV探索で120例中106例は深さ1/3/6で選択候補が変わった。ノイズ4draw間の変化は10例。
この揺れが欠損・融合・濃度むらを生むという仮説を、データ/モデル固定で検証する。
揺れが悪いと断定せず、固定による恣意的な位置選択や初期モデルの偏りも検証対象にする。

## 固定する条件

CV expanded raw8000を共通初期値とし、16ch/15,809params、同じ512訓練例を使用。
両条件fresh Adam/EMA、batch4、各6,000更新。base5e-5*sqrt(batch)=1e-4からcosine1e-5。
深さ1..6、各段0.5**level、画像を縮小後に.25*strengthの独立Gaussianを加える。
whole .1/.5・partial .5、同じサンプル/ノイズ、交互更新。seed2026101310。
共通CT geometry/rangeguardとCU family_costsを使用し、正規化も全27候補共通のまま。

- dynamic: 全画像・全段のcostを集計してから27候補の最小を選ぶ（現状）。
- stable: 学習前の共通モデルが各入力に選んだ候補を、全更新・全深さ・全ノイズで固定する。

固定候補の選択は訓練512入力だけに対し、追加Gaussianなし・深さ3・whole .5で行う。
27候補の全画像/全段costのargminを保存する。input sourceは通常の粗い下描きのまま。
固定候補を1枚に絞って分母を計算し直すことはしない。推論に候補や正解は渡さない。
固定候補が元のcenterと異なっても許容される清書であり、centerへの一致は成功条件ではない。

## 評価と判断

CVと同じold/new_train・old/new_probe各64例、3masks×2新ノイズ(seed2026101311)。
最終raw6000と初期値のみを比較し、4,608モデル行・1,536参照行・16等倍シートを保存。
成功には許容断面の形、線の連続、近接線の分離、端点、白紙/黒の品質改善が必要。
特にold_train24の枝欠損、old/new_probe36の線消失/融合を画像で確認する。
全体平均や教師MSEだけで成功としない。保護域は完全一致。既存corner数値probeの前半偏りに注意。
候補固定だけで改善しなければ、lossの誤差の形や局所情報と全体候補の整合を次に切り分ける。

既知opacity.4・同じ有限形状族の合成診断。独立確認seed/封印データ・Krita・配布は変更しない。
計画・数値ソース・データ・候補を学習前に固定。0/6/6000を保存し12raw/EMA exportを照合。
全6段の初期一致、6更新GPU再実行atol1e-7/rtol1e-5、保存復元完全一致を確認する。
単体テストは候補固定の意味・候補並べ替え/保護域・実更新と復元を確認する。
