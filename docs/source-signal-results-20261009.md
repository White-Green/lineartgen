# 元の下描きを特徴入力にした比較の結果

4,000更新で、細線の安定性・にじみ・幅の再現に明確な改善が出た。
ただし**濃度と偽接続の基準を満たさず、製品にはまだ採用しない**。
実画像は最終8枚、旧対照との比較2枚、白紙の最大誤差位置1枚を等倍で確認した。

| 指標 | noisy特徴/source基準の対照 | source特徴/source基準 |

| TRAIN blur 平均halo | .083582 | .031929 |
| PROBE blur 平均halo | .067068 | .028251 |

haloはTRAIN61.80%、PROBE57.88%減少。4ケースの平均F1はTRAIN.791910→
.924215、PROBE.654113→.840507。ただしfitting基準を全て満たす条件は
両モデルとも各split0/32。候補の8drawは全て同じ出力なので、32条件を
32個の独立な成功/失敗例と解釈しない。実質4形状/各splitである。

以前の非reset procedural pixelモデルに対しても、halo56.48%/52.46%減、
ほかの保持基準を満たし、残る失敗はPROBE gapの偽接続1項目だった。
これは初回1,000評価前に固定した補助比較であり、初期化や出力基準まで
異なるため純粋な特徴入力の因果比較とは区別する。

画像上、太い灰色帯・ノイズ状の枝が大きく減り、細線とカーブが滑らかに
つながる。元々切れているgapまでつながる問題と、弱い線の濃度不足は残る。
白紙の大きな架空輪郭は消えたが、全24白紙条件のraw確認では最大opacity
.040913が左下端の1画素付近に残る（当該条件平均1.24407e-6）。完全な白と
断定しない。部分編集の保護領域最大差は0。

変更はCNNの画像入力を追加Gaussian入り画像から元の下描きにすること。
出力は両群source+sqrt(t)F。モデル130,605パラメータ・同じ初期重み・loss・
新規16,000例・再帰1–6・段loss0・sqrt(batch)LR・4,000更新を共通にした。
Gaussian自体は従来どおり縮小後に生成するが、候補は特徴抽出に使わない。
入力下描き自体に含まれるノイズはそのまま扱う。候補の乱数seed不変性は
実学習モデルの8形状×8drawでも完全一致を確認した。

対照の6更新全状態再実行、0/1,000/4,000の64 primary出力、1,000/4,000の
456 broad出力と指標は元のsource-anchor対照と一致。候補の6更新再実行、
両段階の全状態復元とraw/EMA計4exportも一致。最終は912 broad条件、
128 primary条件。機能テスト27件に保護領域・反復・ONNX/BGRAを含むが、
実Krita GUI品質評価ではない。中間目視はPROBE blur.5の1枚のみ。
