# EN: 入力から分離しにくい近接線に一本の清書を許す

EMは太い単線の灰色・二重化を改善したが、既知512px scene1の近接線を部分的に消した。幅拡張で単線への圧力が増す一方、分離が曖昧な入力にも2本だけを要求している影響を検証する。元の2本を必ず1本へ置換せず、完全な清書の選択肢を増やす。

EI group6 raw18,000からmerge群を6,000更新。比較対象は完了済みEM width群で再学習しない。モデル16,402パラメータ、初期重み、optimizer/EMA reset、sampling seed2026101502、全入力・幅拡張・rough・D4・mask・GaussianキーをEMと同一にする。batch4、基準LR1e-4×sqrt4=peak2e-4、cosine最小2e-5、warmup0。再帰1–6段と全段loss.5^levelを保つ。3,000更新ずつの2区間。checkpoint0/6/3000/6000のraw/EMA8export、最終rawだけで比較する。

DLで用いた入力支持の判定を再利用する。parallelの2path、対応点の中央値距離が8px以下、17断面のうち有効8以上、断面中央の帯の濃さが断面最大の.6以上となる位置が75%以上のときだけ、平均pathの不透明2px線も許す。判定は各stepのrough画像からD4前に行う。離れた線・分離して見える線・他の種類・空白・ベタに候補を増やさない。これは入力からの曖昧さの近似判定であり、実絵一般への妥当性は未確認。

元のgeometryとmerged geometryにそれぞれ同じ9平行移動を用意する。各family内は従来regional lossと同一の正規化で計算し、全再帰段を合算してから画像ごとに低いfamilyを選ぶ。画素単位・段単位で混ぜず、出力や教師の平均も取らない。family間のROIを合併して元のlossの重みを変えることはしない。mergedのink面積が少ないことだけで有利にならないよう各family内のinside/outside正規化を保持する。非許可batchは従来のfield_partsを直接呼ぶ。損失値が近い場合の優先は元のfamily。

事前テストは、元/mergedの両方の不透明解が選べること、灰色の中間解より低lossになること、入力支持がない場合の元loss/勾配一致、全段で一つのfamilyを選ぶこと、合成metadataと原データの不変性、全6段の入力・D4・field一致。実モデルのGPU更新とcheckpoint復元も確認する。候補選択率を全step記録し、候補が選ばれない場合を有効な反証として残す。

評価はEMと同じ標準4,608・stress4,608・512px192・固定幅摂動108、計9,516出力・34事前固定ページ。初期/EM widthの再評価予測は保存値との一致を確認する。scene1/7はfloat/uint8の追加等倍ページで確認する。太い単線の改善維持、近接線の灰色・消失、他の形状の退行を目視で判定する。MSEだけで選ばず滑らかな融合や黒い太線を許す。予約済み新規確認、Krita、製品モデルは変更しない。

学習前の実装確認: 最初のCPUテストはconditional JIT側とeager側の1.49e-8の差で完全一致assertが失敗した。双方を同じJIT条件に揃え、lossと勾配の完全一致を確認した（許容誤差を緩めていない）。3テスト4.00秒、Ruff通過。27訓練形状にmerged fieldを作成、8px以内のfloat16誤差上限.001953125。全6段で候補許可例を含むbatchの元入力・教師・D4がEMと完全一致した。実GPUの非許可loss/勾配照合には既存ROCm監査のatol5e-6/rtol1e-4を事前に用いる。中間解テストは距離場の平均を検査したもので、学習済みモデルの画質改善を保証しない。
