# 線画品質の実験状況（CIまで）

小さい解像度から大きい解像度へ進む再帰は保ち、各段の内部で画像を縮小しない
16チャンネルのCNNを試した。同じ初期出力・データ・1,200更新の比較では、
15,809パラメータのCNNが134,688パラメータのU-Netより細線と分岐をよく復元した。
GPUの1更新は平均0.72秒対1.12秒だった。ただし、モデルの最小サイズや一般的な
線画での性能を確定したわけではない。

まだ採用しない。太線の内部がグレーになること、平行線の間の薄い接続、
部分適用の境界の点状の跡が残る。短い切れ目自体は数値上開いているが、
幅・位置がずれる。2回推論の固定例88基準では、小型CNN43件、U-Net61件が未達。
10枚の比較シートを目視し、25件のテストと保存復元・既存出力の再現を確認した。

次は同じ2モデルを6,000更新まで継続し、固定例の残る誤差が学習時間で減るかを調べる。
その後、太さ・形・部分適用を含む多様な合成条件での学習が必要になる。
Kritaプラグインと配布モデルは変更していない。
