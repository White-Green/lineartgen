# 目的と評価の見直し：入力に沿う自然な線画を生成する

2026-10-13、ユーザーの指摘を受けた方針変更。新しい学習はまだ実行していない。
CRの16/32ch比較と既存の数値結果はそのまま保存する。CR後に提案した両サイズの
単純な学習延長は優先計画から外す。凍結した数値コード・事前計画は変更しない。

## 目的の訂正

目指すのは、ノイズ付き下描きの内容に沿う、線画として自然な画像。
同じ入力に複数の自然な清書があり得る。教師にある一本の線の位置・太さを画素単位で
再現することや、MSE/L1/F1を限界まで改善することを主目的にしない。
自然で入力に適合する一つの解が得られればよく、入力ごとの多様性自体も必須ではない。

CRは実装の健全性・限定した復元問題の学習可能性を調べる診断として記録する。
そこから「次は幅または学習時間を増やす」と製品品質の改善方針を導いたのは不十分だった。
教師に対するhaloや切れ率も、許容される別の線位置・形を欠陥と数える可能性がある。
画素誤差だけでなく、従来の採否判定全体を見直す。

正確にはCRはinterval L1で、guideから教師を復元できる可逆な入力だった。
したがってCRで残ったグレーの原因を条件付き平均やMSEと断定しない。
L1への変更だけでも、線画の構造を保証する学習にはならない。

曖昧な入力での画素回帰の問題は単純な例でも確認できる。64x64白地に黒い縦線が
x=20または22に等確率で存在する場合、どちらか一本を選ぶ期待MSEは0.015625、
二本をopacity 0.5で重ねた平均は0.0078125になる。中央x=21への自然な清書も許容する
問題なら、その期待MSEは0.03125で、グレーの平均より悪い。普通のL1では一本の選択と
グレーの平均が同点0.015625であり、白紙まで同点になる。この数値は0..1の単純な
二画像の例で、実際のtone-balanced interval L1を再現した値ではない。
一般の復元でも画素的な一致と自然さは同一の目的ではない。
[Blau & Michaeli, The Perception-Distortion Tradeoff](https://arxiv.org/abs/1711.06077)。

## 学習を分けて考える

目的は「線画としての自然さ」を改善しつつ、「入力内容からの逸脱」を許容範囲に収めること。
概念的には L_lineart(output) + lambda * max(0, d_shape(output,input)-tolerance)。
これは方針を表す式で、d_shapeや許容幅の実装・係数はまだ確定していない。

- 自然さ：滑らかな線の軌跡、連続的な太さ、自然な先端・交差・分岐、紙面と線の断面。
  同じ入力に対する別の適切な清書も高く評価し、灰色の混合や不自然な線の残骸を下げる。
- 入力追従：線群の大まかな位置・向き・配置と、明確に読み取れる接続関係を保つ。
  重ね描きの全ストロークを一対一で再現する制約にはしない。
  許容帯内の中心線・方向の対応、線群の被覆、許容帯外への追加を組み合わせる。
  一方向の距離だけでは白紙へ退化するため、必要な線群の脱落も別に検出する。
- 保護：noise strength=0の画素は厳密に保存。安定したseedでの挙動も確認する。

全画素を白黒へ押し込めるlossは使わない。アンチエイリアス、サブピクセル細線、
縮小段の線は正当にグレーになる。悪いのは線の形状に対応しない幅広い中間濃度や、
複数の候補の平均として残る裾である。各再帰段ではその解像度に正しく縮小したcleanの
分布を参照し、低解像度の正当な灰色を欠陥扱いしない。

## 次に行う最小の検証

1. **評価の向きを先に確認する。** 同じ合成入力に対して、位置・幅・滑らかさが少し違う
   複数の許容清書と、グレーの平均・太いにじみ・不要な切れ/橋・白紙・無関係な綺麗な線画を
   用意する。許容する形の範囲は結果を見る前に固定する。
   「許容清書群を低誤差の平均より好む」「無関係な線画や白紙を落とす」を確認する。
   明確な欠陥の検出と、曖昧な位置・幅の自由度を区別する。
2. **モデルサイズを固定した小規模な学習比較。** まず16chの自己再帰CNNを共通にし、
   従来の対応画像lossを対照、線画の分布を学ぶloss＋許容幅のある入力追従を候補とする。
   最初の実装候補は、出力だけを見る線画判別器と入力追従項を分けたadversarial学習。
   線の局所断面と大きな接続を両方見る。単に既存判別器の係数を増やす実験にはしない。
   強い最終画像MSE/L1で結果を再び唯一の教師に固定しない。画素回帰をwarmup等に
   使う場合も独立した対照を置き、その有無と目的を明示する。
3. **生成された画像で判断する。** 自然さ、許容範囲内の入力追従、不要な線の追加・脱落、
   部分適用と白紙を分けて評価し、等倍画像を比較する。
   原教師へのMSEやF1が悪化しても、それだけで落とさない。判別器スコアだけでも採用しない。
   全体画素スコアで失われる細線・先端・交差の実例を確認する。

本格的な長時間学習や幅の探索は、この評価が目的に合うと確認してから行う。
最初の確認は小さな評価仕様のテストに留める。判別器単体の長期学習と教師方向の
勾配検査を何度も繰り返す流れには戻さず、候補lossによる生成器の実更新と画像の
変化を早く見る。評価器自身のスコア最適化を新たな目的にしない。
入力は当面すべて合成。自然な曖昧さを含む重ね描き・ブラー・減光を扱い、可逆な入力だけに
制限しない。曖昧さを許す分、教師画像一枚との厳密一致を合格条件にしない。

線画cleanupで生成器と判別器を共同学習し、同じ推論構造で改善した先行例はある。
これは今回の構成で成功する保証ではなく、検討候補の根拠である。
[Simo-Serra et al., Mastering Sketching](https://esslab.jp/publications/SimoSerraTOG2018.pdf)。

## 既存判別器の失敗から引き継ぐこと

[人工欠陥の診断](critic-defect-probe-20261007.md)や
[固定生成器の診断](../../jax-fixed-generator-critic-20261010/docs/fixed-generator-critic-results-20261010.md)
では、識別精度が上がっても切断・誤接続を直す方向にならなかった。
したがって「GANを付ければよい」で済ませない。切断・橋・消失の失敗は今後も確認する。
ただし「勾配が唯一の教師画像へ向く率」は新しい目的の必要条件にはしない。
許容される別の線画へ向かっている場合まで不合格にするためである。
候補の実更新が許容される線画へ改善するかを確認し、教師方向の内積だけで採否を決めない。
過去の不採用結果は撤回せず、その目的に対する限定した結果として残す。

条件付きFlow Matchingも分布学習の候補だが、以前の時刻bridge実験を無条件に再試行しない。
ベクトル場の二乗誤差は、最終画像を一枚へ回帰するMSEと意味が異なる。適切に学習した場を
積分する生成法ではMSEを含んでいても、出力が画像の平均になる必要はない。
[Lipman et al., Flow Matching](https://arxiv.org/abs/2210.02747)。
純ノイズ強度1からの運用は要求しない。入力画像・マスクへの条件付けを保つ。

自己再帰、1〜6段での学習、各段の学習信号、sqrt(batch)のLRは維持する。
各段lossの中身と最終出力の合格条件を上記の目的に合わせる。
Kritaの利用形式・保護領域・入出力仕様を保ったまま検討する。
