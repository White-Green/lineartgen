# 線画らしさとlossの再設計案（2026-10-06）

設計の記録。実装と比較の進捗は[実験記録](lineart-loss-experiment-20261006.md)を参照。
配布モデルは変更していない。合成下描きだけを使い、Kritaの入出力、
縮小後のノイズ付加、学習再帰段数、段間loss重み、sqrt(batch)によるLRを維持する。
今回の目的は、線の周囲に灰色が残る症状を含め、線画の構造を学習目標へ反映すること。
lossの不足は有力な仮説だが、入力からの情報欠落、容量、最適化、学習・運用の分布差も
原因になり得る。lossだけで解決できると断定しない。

**現行実装と過去の結果**

- `src/lineartgen/training/losses.py` は濃淡の出現量で重みを付けたMSE、
  ノイズ強度による重み、identity、Sobel勾配誤差、contrastを使う。
  配布モデルの係数はidentity=.1、edge=.1、contrast=.01。
- ink量を `a=(1-image)/2` とするとcontrastは `4*a*(1-a)`。
  白紙も、正しい黒線も、誤接続した黒線も、この項では0になる。
  正しいアンチエイリアスや縮小された細線には正の罰則がかかる。
  灰色の位置・広がり・接続関係を指定する項ではない。
- 境界距離場lossは線幅を改善したが切断増加を伴った。
  [元実験](boundary-loss-experiment-20260914.md)と
  [半係数の追試](boundary-half-experiment-20260915.md)を参照。
- 灰色用に変更した中心線lossは背景を改善する一方、細線の消失を増やした。
  [実験記録](cldice-loss-experiment-20260915.md)。原論文のsoft-clDiceそのものではなく、
  この結果をclDice全般の否定や最大モデルでの実測結果とは扱わない。
- 設定のscale_loss_multiplier=0なので直接lossは最上位解像度だけにかかる。
  下位段には再帰を通じて勾配が流れる。この重み付けを変更しない。

**線画として必要な性質**

線画を「細い曲線の集合を、幅・濃度・端点・交点を持たせて画素へ描画したもの」と捉える。
平面的な黒ベタ、ハッチング、角、意図的な隙間も有効な教師として許す。
各画素の白黒だけでなく、次の性質と入力への忠実さを同時に扱う。

| 性質 | 望ましい状態 | 単純化したlossの失敗 |
| --- | --- | --- |
| 背景 | 線の近くにも遠くにも余分な色がない | 全体平均では細いhaloが薄まり、背景だけを優先すると線が消える |
| 線の断面 | 教師に沿った芯・幅・狭い濃淡遷移 | 全画素の二値化は細線とアンチエイリアスを壊す |
| 線に沿う変化 | 位置・太さ・濃さが整い、意図した入り抜きも残る | 一律な平滑化や幅一定の罰則は角・先端・強弱を失わせる |
| 接続と分離 | 同じ線は続き、別の線と隙間は分離する | 切断だけを減らすと線を太らせ、誤接続が増える |
| 局所形状 | 点、端点、曲線、角、分岐がclean線画の形を持つ | 画素ヒストグラムだけではランダムな白黒配置と区別できない |
| 内容保持 | 下描きの意図・教師の位置・保護線を保持する | 線画らしい別の絵でもよい、という目的にしてはいけない |

灰色は一律に誤りではない。教師のアンチエイリアス、サブピクセル幅の線、縮小段の
面積被覆による濃淡、意図的な薄い線は保持する。まず現在のclean教師の濃淡を正解とする。
線の周囲に広く残る余分な灰色と、線そのものに必要な濃淡を分離する。

**評価の見落としを確認した人工例**

現行 `protected_metrics` のF1は正規化画像<0、すなわちink不透明度>.5で判定する。
runtimeは不透明度<.1だけを除去するため、約.1〜.5の余分なinkは表示されてもF1で
線として数えられない。既存MAEは反応するが、広い白背景との平均では小さくなり得る。

2026-10-06に既存評価関数と `to_bgra` で以下を確認した。学習モデルの測定ではなく、
評価指標の挙動を切り分けるための人工的な反例。

- 512×512の白地に3px幅の黒い縦線を置く。
- 正解線を変えず、その両側へ4px幅、不透明度.25の灰色を足す。
- F1=1.0、正規化画像のMAE=.0078125。
- runtime出力のhalo alphaは64/255となり、表示に残る。

今後は教師の線近傍の余分なink量、線の外側へ広がった距離、断面の幅・ピーク・裾を測る。
全画面の灰色率を減らすだけでは、白紙化や黒ベタ化を成功扱いしてしまう。

**候補1：教師に基づく領域別の誤差と線断面の誤差**

予測inkをa、教師inkをa*、編集領域をMとする。まず既存の画素再現・identity・edgeを
基礎として残し、無条件contrastを外す条件を対照として独立に置く。

教師から、線の領域、線のすぐ外側の背景B、遠い背景を作り、それぞれ別に正規化する。
例としてhaloへの損失は次の形を候補とする。

```
L_halo = mean_{i in M ∩ B} relu(a_i - a*_i)
```

Bは教師inkの支持領域からの距離と教師濃度で決める。教師の灰色画素を白と決めつけず、
差分を罰する。近傍半径や支持領域の閾値は検証対象であり、固定の最適値を主張しない。
空白画像では通常の背景領域を使い、空の領域はloss0とする。線の領域にも教師との誤差を
別正規化して与え、薄い線を消してhaloだけを改善する解を防ぐ。

これは新しい意味の教師を導入する魔法の項ではなく、広い背景平均に埋もれていた
線周囲の誤差と細線の誤差へ学習を配分し直す案。既存tone_weightsは全体のink/paperを
重み付けしており、線近傍の背景を独立した領域として扱っていない。

次に線を横切る濃度断面を扱う。教師の中心線c(s)と法線n(s)から、
`q(s,u)=a(c(s)+u*n(s))` をbilinear samplingし、教師のq*と比較する。

```
L_profile = mean_s [ mean_u rho(q-q*)
                  + eta * mean_u rho(Delta_u q-Delta_u q*) ]
```

rhoはL1または滑らかな近似を候補にする。芯・端・周囲の裾が平均で消えないように区分する。
線に沿った変化も、ゼロへ抑えるのではなく教師の変化との差として扱う。
幅、中心、濃度の指標も並記するが、断面の総量や二次モーメントだけでは別の形が同点になるため、
それだけをlossにしない。教師にない余分な線には背景誤差を併用する。

まず幾何合成で正確なパス・幅・法線を使う。現在のgeometry生成器は内部にpaths/widthsを
持つが、外へ返すmetadataは種類と本数なので、教師用の情報を取り出す拡張が必要。
実線画由来では教師の方向推定に信頼度を付ける。交点・角・端点・黒ベタで法線を無理に
一意に決めず、その領域は画素lossや後述の局所判別器へ任せる。既存Sobel lossと比較し、
断面に沿う集計・領域正規化に追加の価値があるか確認する。

**候補2：線画専用の小さな判別器による学習されたloss**

手書きの数式で端点・線幅・交点・にじみを全て指定する代わりに、clean線画の局所構造を
判別器Dへ学習させる。Dは学習時だけ用い、生成CNNの推論サイズとONNX/BGRA契約を維持する。

[Mastering Sketching](https://arxiv.org/html/1703.08966v1)には、MSEに判別器の損失を加え、
同じ推論ネットワークで線画のぼけを改善した先例がある。論文のDは出力画像だけを見ており、
以下の条件付きpatch版は本プロジェクト向けの提案であって、その論文の再現ではない。
同論文でも教師への再現lossを弱くし過ぎると入力との対応が崩れる。

- 実データ由来のclean線画と幾何生成線画を正例、現在のモデル出力を負例とする。
- 線・端点・交点を含むpatchと背景patchを層別抽出する。同じ教師座標で正負のpatchを比較し、
  白いpatchの多さだけで判別できる構成を避ける。
- 例として16〜64px程度の局所範囲と広い範囲を比較する。画素単独では線の構造を扱えない。
- 条件付きの場合は同じノイズ入力・強度・maskと、教師または予測を組にする。
  忠実さを守る画素lossは継続する。条件付けだけで内容保持が保証されるわけではない。
- アンチエイリアスを含む連続値を使う。教師だけ二値化する等、判別器が簡単な処理差に
  逃げる設定を避ける。BGRA化の閾値は学習時には通さない。
- Dに使う教師はtraining splitだけ。係数は勾配とdevelopmentの画質の両方で調整する。
  初期の勾配norm合わせだけで線幅・消失・誤接続の均衡が取れるとは扱わない。
- 学習の不安定さ、余分な黒線、偽の細部が増え得る。実画像・幾何形状・白紙・薄い線・
  mask境界の固定画像を並べ、指標と見た目の両方で対照と比較する。

固定した線画品質ネットワークを、cleanと人工的なhalo・切断・誤接続等の対で事前学習する
案もある。ただし人工欠陥だけへの過適合と、ネットワークの弱点を生成側が利用する問題が
あるため、これを完成した品質尺度とはみなさない。

入れ子のモデルでDを共用すると、大サイズの出力がD更新を通じて小サイズのlossにも
間接的に影響する。まず最大モデル単体でlossを比較する。その後のS/M/L比較では、
Dをサイズごとに分けるか、事前学習後に固定した同一Dを使うかを明示する。
大モデル出力を小モデルの入力・教師として混ぜないという条件を維持する。

**接続性の扱い**

線の接続と、白い隙間の接続・分離を同時に監視する。線をつなぐ項だけでは線の肥大化や
橋渡しが有利になり得る。合成図形の既知パスでは、線に沿う被覆の不足と、別線間の
本来白い通路へのinkの侵入を別々に教師化できる。

[clDice](https://openaccess.thecvf.com/content/CVPR2021/html/Shit_clDice_-_A_Novel_Topology-Preserving_Loss_Function_for_Tubular_Structure_CVPR_2021_paper.html)
は有力な関連手法だが、原論文の二値構造の議論を灰色・有限反復・部分maskへそのまま
適用しない。過去に失敗した変更版の係数を上げるだけの再試験は優先しない。
foreground/backgroundの形状を扱う場合も、意図的な端点・隙間と画像端を教師に従って扱う。
判別器の局所的な評価だけでも大域的な接続の正しさは保証されない。

**平均化と不確定性への注意**

入力から正しい線位置が一意に決まらない場合、通常のMSEに最適な条件付き平均は
複数の線位置を薄く重ねた画像になり得る。今回の濃淡依存重み付きMSEは厳密には
重み付き平均を最適化するため、単純な条件付き平均の式とは区別する。
L1へ変えるだけでも、灰色の代わりに細い線を消す解が生じ得る。
「画像らしい分布」と「特定の教師との画素誤差」を同時に評価する必要がある。
[Perception–Distortionの研究](https://openaccess.thecvf.com/content_cvpr_2018/papers/Blau_The_Perception-Distortion_Tradeoff_CVPR_2018_paper.pdf)
はこの区別の参考であり、現在の学習が理論的限界に到達した証拠ではない。

画像上の細線と線幅の変更だけでは、消えた二本線の意図を必ず復元できるわけではない。
教師の品質、合成破壊の程度、実運用のStrengthも同時に層別評価する。

**比較の進め方**

まず最大モデルの同一checkpointから、同じ合成データ列・noise・mask・再帰段数を使う。
短い追加学習による比較と、ゼロからの学習効果は区別する。2kは動作・劣化監視、10kは
初期比較の目安とし、このstep数だけで十分な学習と判断しない。

| 条件 | 変更 | 切り分けること |
| --- | --- | --- |
| A | 現行loss | 現在の対照 |
| B | Aから無条件contrastを外す | 既存の二値化圧力の効用・副作用 |
| C | B＋線領域/近傍背景の別正規化 | haloを直接抑え、細線も残せるか |
| D | B＋線断面loss | 太さ・位置・濃淡遷移を構造として教える効果 |
| E | B＋小さな線画判別器 | 手設計で拾えない局所的な線画らしさ |

有効な条件が見つかってから組合せを試す。最初から全項を足さない。
接続性の専用lossは、この比較で残った誤接続・切断に対して別途比較する。

主評価は線近傍の余分なink量と広がり、細線の被覆・消失、断面、誤接続を併記する。
不透明度10/25/50/75%など複数閾値で見る一方、学習は連続値のまま行う。
低解像度の細線に一律の閾値条件を要求しない。背景だけ改善・線だけ太くなる条件は採用しない。
runtimeのdenoise 1/2/5回と部分編集でも、にじみや誤接続が蓄積しないか確認する。

固定の比較画像を、学習途中から通常倍率・拡大・Krita相当の白背景合成で確認する。
以前のfinal testは既に観察済みなので以後は診断用。採用確認では新規の合成条件と生成seedを
事前固定し、元画像についての未見性は別に明示する。

各補助lossは従来と同じ段間重みの内側へ追加する。縮小段の教師は縮小後の正当な濃淡を
維持し、保護画素は固定した文脈として参照する。保護画素へ勾配を流さず、編集領域側の
境界も評価する。線幅・近傍距離は解像度に合わせ、全段で同じ物理幅と決めつけない。
