# DB: 下描きの劣化幅を広げると対応範囲は改善するが、粒状感は残る

**製品未採用。** 数値ソース `f9f8c6d`。DA linear の同一raw6,000から、
固定劣化／可変劣化を各6,000更新。16ch・15,809パラメータ。
可変側は25%従来条件、75%opacity .2–.8、blur .6–2.4、局所sin変形0–1.5px。
同じclean候補・再帰段数・Gaussianで比較。geometry補助項だけ既知の学習opacityを正規化し、
モデルにはopacityの正解を渡していない。

標準4分割と新しい64形状×6劣化を合わせ、9,216モデル出力を評価。
計画した36枚の等倍シートをすべて目視した。さらに512px・複数形状・8bit入力を128出力、6枚確認。
暗い入力では可変側の線幅が抑えられ、薄い／ぼけた入力では欠損や周辺の点状灰色が減る。
一方、薄い細線はまだ灰色でざらつき、黒い面の内部が荒れる。これを清書としての合格とはしない。

目視で特に残る問題：

- faintの細線6・taper48は薄く粒状。黒面56は輪郭だけ濃く、内部が灰色の模様になる。
- base/sharp/softの黒面は固定側より可変側に白粒が増える。roughでは内部の模様が粗くなる。
- 標準セットのold_train24の小さな枝、近接線の欠落・融合は解決していない。
- 512pxでも太い曲線に中空の輪郭や灰色が残る。8bit化とfloatとの差は目視では小さい。

次は固定モデルへの追加Gaussianの介入で粒状感の原因を切り分ける。
入力下描きそのものは変えず、縮小後に別途加えるGaussianだけを変える診断とする。
再学習／製品採用の結論とは分ける。Krita・配布・封印データは変更していない。
