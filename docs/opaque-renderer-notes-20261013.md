# 描画表現を制約する場合の注意（研究メモ）

DEの比較学習中に、将来の強い形状priorの候補を再確認した。
まだ学習実験として選定・実装していない。DEの目的や採否条件を変更するものではない。

[Differentiable Drawing and Sketching, v2](https://arxiv.org/html/2103.16194v2)は、
点・線分・曲線までの距離から微分可能なラスタを構成し、描画パラメータを学習する。
同論文3.1の指数関数による緩和は距離とともに濃度が減る。
そのため、この方法をそのまま導入しても不透明な芯と狭いAA境界が保証されるわけではない。
これは論文の欠点一般を述べるものではなく、今回の灰色帯を抑える目的との相違である。

本タスクで試すなら、中心経路・幅から不透明な領域を定義し、その画素被覆率を描画する
方式を候補とする。出力濃度の自由度を減らせる一方、幅を狭めれば薄い線は依然として
描ける。線の存在、端点、分岐、近接線、塗りをどう表すかも必要で、距離を出力するだけでは
正しい位相や線の連続性は保証されない。

最初の検証は学習ではなく、正しい幾何から細線・入り抜き・交点・意図的gap・黒ベタを
全縮小段で再描画できるかのoracle検証とする。縮小段の正当な灰色と最細段の不要な灰色を
分ける。過去のcoverage-distance表現は被覆率を保つ画素表現であり、不透明stroke renderer
の検証済み実装ではない。

## 距離場を使う場合の注意（DI学習中の検討、未実装）

[Gropp et al., Implicit Geometric Regularization](https://arxiv.org/abs/2002.10099)は、
点群上の境界条件と空間勾配のノルムを1に近づける項から、暗黙的な形状を学習する。
この結果は今回の画像入力CNNや線画cleanupでの有効性を直接示すものではない。

距離場に名前を変えて単にclip/sigmoidで濃度へ変換しても、灰色の平坦な領域を排除できるとは限らない。
形状として整合した距離場を学習する制約と、画素が覆われる面積を扱う描画処理が別途必要になる。
特に2pxの線を32分の1へ縮小した段では、正当な被覆率はサブピクセルになる。
その段まで一律に不透明化する処理は、既存の再帰段の意味と整合しない。
単純な最終thresholdや、全段への二値化lossは次の実装として採用していない。
この節は実装条件の整理であり、新たな実験の完了・開始を示すものではない。
