# ES: 再帰する幾何fieldの渡し方を固定重みで診断する

ERではwide61の副線がdepth2から現れ、37の短い曲線断片やscene7の弱い交差線の途切れはdepth1でも残った。粗いheadの16値を平均してnearest拡大する現在の経路ではsubpixel位置が落ちる。また物理的な距離として次の段へ渡すなら2倍になるが、現在は学習された潜在条件なので、現状を単位のバグと断定しない。

ERと同じ3固定モデル（EI参照、EQ merge/mixed raw18k）、6既知入力（probe37/58/61/62、scene1/7）、float/uint8、全域強度.5、depth6を使用する。変更は条件の渡し方だけ。legacyは平均→clip→nearestで現行通り、scaledは平均後2倍してclip→nearest、subpixelは4×headを展開し2×2平均して次段のpixel位置に整列→clip、subpixel_scaledは同じ処理を2倍してclip、zeroは全段からの条件を零とする。計180出力。legacy36出力はER depth6と、zero36出力はER depth1と完全一致が必要。予約fresh入力は使わない。

新しい演算について斜めの平面距離の中心位置と物理単位（絶対誤差1e-7）、D4可換性（2e-7）をCPUで検証する。全条件で同じ最終ラスタライズ、モデル不変、有限値、範囲、入力/モデル/コードhashを確認する。粗い段の値を別の分布へ変える固定重み介入なので、不成功を再学習後の可能性の否定に使わない。全段loss・学習深度・学習率の設計は変更しない。

256pxは5条件列×3モデル行、4例×2入力精度の8等倍ページ。512pxは5条件を3列×2行（最後空白）、2例×3モデル×2精度の12等倍ページ。全20ページを実際に見る。余分な線・接続・濃さと既存成功の維持を観察し、MSEで品質順位をつけない。学習・採用・製品変更はしない。
