# DR: learn a subpixel geometry field, 2026-10-14

DQ established that known capsule geometry can be rendered with narrow coverage boundaries, intact crossings and valid coarse-scale mass. DR tests whether the existing small recursive CNN can learn a geometric intermediate representation from rough synthetic inputs. This is a representation/training change, not another adjustment to raster MSE.

## Representation and recursive computation

Keep the16-channel RF87 backbone and existing nine-feature Fourier physical-level conditioning. Replace its17-parameter scalar residual head with a272-parameter head predicting16 signed geometry samples per pixel (a4x4 subpixel grid). Total parameters16,064 versus15,809. Decode finest-stage fields with the validated fixed subpixel coverage rule and spatial averaging. Protect t=0 source pixels exactly. No learned opacity multiplier, final threshold, contrast rescaling or deployment change is added.

Internal recursion now passes the clipped mean normalized geometry field, rather than a raster image. This semantic change is explicit. The initial coarsest insert is zero. Source normalization still occurs before the input pyramid; external Gaussian draws are generated after downsampling but are ignored by source-only features. Geometry fields are predicted and supervised at every1–6 training stage. Finest output retains the same image shape/range and partial-mask protection, but the current production runtime cannot load these research weights. Metadata format2 deliberately prevents accidental loading by the old raster loader.

The field is the minimum of capsule signed functions and rectangle signed functions. It describes the correct zero set but is not necessarily the exact Euclidean signed distance everywhere inside overlaps or outside rectangle corners. Do not call it an exact SDF. Arbitrary learned fields can still form gray plateaus, wrong widths or incorrect topology; geometric supervision is intended to discourage these, not mathematically rule them out.

## Data and objective

Use the same512 synthetic shapes and source augmentation as preceding comparisons. Generate central peak-width2px geometry fields on a quarter-pixel grid with4px padding. Preserve relative taper; black guards use rectangles. Cache float16 fields and require maximum absolute storage error within8px of a boundary <=.0021px. Nine allowed global translations use the prior first-path normal and offsets−2..2 by.5. Sample the cached field at physical stage coordinates, then divide by2**level; do not average a signed field as if it were opacity.

Preflight exposed an out-of-cache boundary error; padding fixes it. Bilinear interpolation of an absolute-distance medial cusp has a known half-cell error bound (.125 finest px for the analytic straight-line test). The test checks that bound and exact agreement away from the cusp across all six scales, instead of claiming analytic equality at a cusp. Preserve all failed and passing test logs.

For each candidate, supervise raw field values clipped only on the target side to±8 current-stage pixels, using robust absolute residual in distance/8. Weight the union of the candidates' |distance|<4 band by1 and remaining active pixels by.01, with one common denominator. Add coefficient.1 robust spatial-gradient discrepancy, in current-stage physical units, inside the common band. Gradient edges require both neighboring subpixels active. Choose ONE candidate for the complete sample across all stages and both components via argmin/gather. Retain stage weights .5**level. There is no image-to-teacher squared-error objective. Constant gray fields and wrong saturated-white fields must receive nonzero geometric gradients in tests.
