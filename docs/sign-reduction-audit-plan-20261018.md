# HK: 残存欠陥に対する符号loss勾配の診断

HJ18000更新後も薄い断片・灰色肩・弱い接続が残る。学習時間をさらに延ばす前に、global L4のε=.01による勾配の減衰と、遠方の大きな誤りによる局所勾配の縮小を切り分ける。学習・field最適化は行わず、HJ raw18000の重みを固定する。HJの厳密geometry検証の失敗を合格に変更しない。

既知の10条件を事前固定する：probe37全体/部分、oldtrain36全体、scene2全体、scene7全体/部分、80px棒、87.5px棒、62px棒、fill。256pxは深さ3、512pxは深さ6。位置候補±2px/9個を全段共通で選び、元のdistance/geometry/sign項を維持する。平行線は現在のsource support条件でmerge可否を選ぶ。sceneは保存済みgeometry、棒/塗りは既存の解析形状。出力と選択された教師を全10原寸ページで見る。教師は診断にだけ用い、forward入力には入らない。

変更なしの損失に対して全段field勾配を計算する。各near/far・inside/outside領域の4次moment、最大違反、違反数、ε=.0001へ変えた場合の勾配比を記録する。候補と出力を固定した同じ点で、既存4×4領域集約の勾配も計算する。候補の再選択、CNNの更新、汎化の予測とは区別する。現行式を使ったJAX微分と解析勾配の一致、候補間共有分母、疎な小違反、別tileの大きな違反、空領域をCPUテストする。

最終段では全許容候補から1pxより外側かつalpha>.01のsubpixelを域外、そこからalpha<.99を薄い域外と定義する。正当なAA/位置ずれと混同しないため厳しい条件とし、対象が0なら未検出として報告する。選択教師の内部距離>.25pxでalpha<.99も別に記録する。sign/distance/geometryの勾配量、修正方向、ε・局所化の反実仮想勾配量を比較する。損失の小ささや指標だけでは採用しない。

保存済みHJ出力とfused inference/fieldを露出した描画は事前atol/rtol各1e−5、実誤差と非完全一致を記録する。保護領域とモデルstateは完全一致。sourceと教師のファイルをhashで結び、実行前にcodeと条件を固定する。計算不一致があれば失敗を保存し、閾値を事後緩和しない。新しい教師画像を見てからモデル条件を変更しない。

これは既知の失敗例を調べるmechanism診断であり、改善モデルの実験ではない。全6段の学習・各段loss・sqrt(batch)は変更しない。fresh16、本番、Kritaは対象外。結果でεがほぼ効いていなければεだけの学習比較は行わず、局所勾配など別の根拠を検討する。
