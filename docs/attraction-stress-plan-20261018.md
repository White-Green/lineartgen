# ID: 固定したHYモデルの広域ストレス評価

HY R1の標準25例での改善が入力条件を変えても保たれるかを調べる。重みはHY6000 rawのR4/R1に固定し、学習・checkpoint選択・decode閾値調整はしない。22725パラメータ、投影範囲4/1px、投影先距離2px+1e-5、4倍不透明描画をそのまま使う。halo32も維持する。

既存のHI stress64形状×6劣化（base、faint、dark、sharp、soft、rough）を全体/部分の深さ3で評価する。rough64はuint8でも全体を評価。ELの6太線×6幅係数は全体の深さ1/3/6と部分の深さ3。既存512pxの8場面は全体/部分、float/uint8、深さ3/6。GKの太さ40/62/80px、長さ128/160/192px、15度回転、塗り160/208pxとGOの87.5px線/160px塗りも深さ1/3/6＋部分で確認する。HY既知25例は強度.25/.75の全体/部分を追加する。計527入力記録、2360モデル出力。重複する元形状を独立例に数えない。

57原寸ページを事前固定。rough全64を含み、明度・ぼけの選択例、幅掃引の全例、全512場面、GK/GO全例、部分適用、強度変更を見る。暗く連続した線・滑らかな幅・隙間・塗り・保護領域保持を判断し、MSEで順位を付けない。曖昧な元線の本数一致は要求せず、明瞭な線の消失、余分な輪や帯、切れ、灰色の塊を記録する。小さい閉領域や局所的な粗さも残存欠陥として扱う。

開始前にHY既存37/62/scene7の深さ3出力とheadをatol/rtol各1e-5で照合し、ダミー教師と真教師でhead完全一致を検証する。全条件で有限範囲・保護画素完全一致、評価前後の重み不変を検証。GaussianをCNNが参照しないため乱数drawの反復を省き、Gaussian頑健性を主張しない。縮小後ノイズ付加は既存pipelineのまま。

この評価は既知の開発用合成例だけを使用し、予約fresh16には触れない。広い条件が通ったときだけ別計画で独立確認する。本番・Krita・export・pushは変更しない。IC曲線モデル試験はHYの標準改善を踏まえて未開始のまま保留する。
