# DQ: opaque geometry rendering prerequisite

DP's new profile objectives admitted clean free-pixel solutions but did not repair the trained CNN's gray bands, cuts or fill corners. Before implementing another learned representation, this bounded experiment tests a differentiable opaque geometry renderer. It does not train a predictor or constitute a product candidate.

Representation: continuous polyline segments with endpoint widths, united as variable-radius capsules; rectangles represent the present synthetic black-fill guard. Opacity is fixed. Four subpixel samples per dimension and a transition no wider than one subpixel approximate pixel coverage. Union is applied before pixel averaging so overlapping strokes do not accumulate opacity. Round caps differ from the legacy polygon's flat caps; small endpoint differences are allowed. Variable-width capsules are an approximation for rapidly changing width. This rectangle primitive does not establish arbitrary fill representation.

The full-resolution rendered image is box-downsampled to all six recursion scales. Coarse line coverage is legitimately gray; no thresholding or opacity sharpening is applied there. Protected source values are composited exactly using the existing zero-noise mask. Tests cover opaque interiors, blank/black, connected crossings, separated parallels/gaps, taper, mass across scales, repeated-stroke union, finite-difference geometry gradients and protected values.

Frozen oracle cases: DN/DP new_probe indices0,6,12,18,24,30,36,38,42,48,54,56,58,59,62,63, plus the same eight established512 multi-shape scenes. All paths use peak width2px, retaining relative taper. Probe images compare4x and8x supersampling; require relative ink-mass difference below1.5%. All levels must preserve mass within numerical precision. View all eight native pages and the labeled coarse-scale display; the latter is enlarged with nearest-neighbor solely for visibility. Keep all outputs, hashes and failures. No reserved fresh-confirmation inputs are used.

A gradient-check preflight initially failed with float32 central differences at step1e-3: the finite difference crosses narrow coverage kinks. The refined test uses float64 and shrinking steps to verify convergence of the local derivative, rather than relaxing its tolerance. Preserve both logs.

Passing these tests means the representation can draw known synthetic geometry and supply local derivatives. It does not show that a network can infer topology, choose stroke count, fit distant geometry from pixel loss, or avoid width-collapse artifacts. A learned geometry predictor needs explicit existence/connectivity and position supervision or another justified geometry objective; merely renaming a pixel head as a distance field is insufficient.

Related primary work: [Yan et al., Deep Sketch Vectorization via Implicit Surface Extraction, SIGGRAPH2024](https://cragl.cs.gmu.edu/sketchvector/) separates distance-field prediction, line reconstruction and topology handling. That supports investigating geometry as an explicit representation, not a claim that this small capsule prototype reproduces their method or results. Our immediate experiment is only the rendering prerequisite; model and training design will be chosen after it passes.
