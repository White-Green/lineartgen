# EE: D4を構造に組み込んだ小型幾何モデルの学習可能性

EDでデータ拡張後も同じ太い下描きの方向によって黒帯・細線・断片が切り替わった。次はgroup convolutionにより90度回転と反転への対応をモデルに組み込む。原理は[Cohen & Welling, 2016](https://proceedings.mlr.press/v48/cohenc16.html)。本実験での品質向上は未確認。

通常の16ch local CNN（16,064パラメータ）、D4の各方向に2特徴のモデル（2×8=16特徴、2,022パラメータ）、6特徴のモデル（6×8=48特徴、16,402パラメータ）の3群を新規初期値から比較する。3群とも3ブロック・dilation1/4/16・RF87・物理段数のFourier FiLM・4×4 subpixel signed field・同じcoverage描画と再帰状態を使用する。group版は入力lifting、方向間group convolution、方向で共有するFiLM、局所subpixel座標も回す出力headを使う。最終画像8枚の選択や後処理平均ではない。group6版は重みを共有するが中間特徴が多いため、パラメータ数が近くても計算量は同等ではない。group2版は中間特徴数をplainと揃え、重みを大幅に減らす比較となる。どちらも対照との違いを等変性だけの純粋な効果とは断定しない。実測して記録する。

まずDYで使用した既知16形状（wide8、近接曲線4、cross2、blank1、fill1）で学習できるかを調べる。少数例への適合は汎化・製品採用の証拠としない。3群に同じD4変換、25%base/75%roughの入力劣化、whole.5を提示する。regional geometry lossは共通。再帰1–6段を巡回し全段lossを.5**levelで集約。batch4、baseLR5e-5×sqrt4=1e-4、cosine minimum1e-5、EMA.999、Adamは新規。学習seed2026101433、モデルseed2026101432。各6,000更新、保存0/6/2000/6000、raw6000のみを画像比較に使う。

初期のパラメータ配列は形状も分布も異なるが、ゼロhead重み＋一定biasで初期関数を一致させる。全6段の初期関数、6更新再実行、全状態復元、24 raw/EMA export、全6,000回の入力・教師・Gaussian一致を監査する。先頭再実行の許容誤差は既存のatol5e-6/rtol1e-4を維持。group層・subpixel headは非ゼロ重みで8方向の等変性を確認し、全6段の再帰fieldでも検証する。実更新で非ゼロ勾配・loss低下・保存復元・保護領域維持・製品loaderによる拒否を確認。実サイズGPU更新の時間とメモリも事前に測る。

評価は同じ16形状の元入力/rough、whole/partial.5、depth3/6。EC D4 raw12000を履歴参照として並べるが、これは同条件の対照ではない。計512出力、指定16等倍ページを確認する。見るものは濃く連続した線、滑らかな曲線、余分な灰色帯・端の断片・穴の有無。教師画像との画素MSEや、等変性の小さな数値だけでは成功としない。綺麗な融合・閉じた端は許容する。

少数例で改善した場合に、別計画で既知の広い開発入力への転移と全512形状学習を検討する。予約済み新規確認データ、Krita、製品モデルは変更しない。
