# DR: 幾何場の学習結果 — 不採用

16,064パラメータの自己再帰CNNを、既存backboneからの初期化と新規初期化の2条件で各6,000更新した。画素濃度を直接回帰する代わりに、4×4サブピクセルの符号付き幾何場を予測し、距離と空間勾配を教師にした。段数1–6、各段loss、sqrt(batch)による学習率スケーリングを保持。数値実装は`cdbd8f3`。

9,408出力を評価し、事前指定した等倍28ページを実際に確認した。両条件とも交点・枝・近接線の内部を大きく消し、太い下描きからの中心線も多く消えた。単純な線でも中央が極端に細くなり、端点だけが残る例がある。黒ベタは内部を黒く保つ一方、角の白い穴が増えた。灰色領域が減っても、線の消失による白さなので改善とは判断しない。学習形状にも同様の欠陥があり、新規形状への汎化だけの問題ではない。

学習lossの最初/最後600更新平均はwarm .16405→.06174、fresh .24288→.06041。これは最適化が進んだ記録で、品質スコアではない。最後600更新の1更新平均はwarm .11581秒、fresh .11482秒。学習全体1,784.11秒、標準評価145.07秒、劣化評価90.16秒、512px評価8.93秒。

4テスト・Ruff通過、最初6更新の再現、16個のraw/EMA書き出し、全状態の復元、全6,000更新の入力一致を検証。DN参照の3,072予測は前実験と完全一致。Gaussian draw違いの予測も標準2,304組・劣化2,304組・512px96組で一致する(source-only設定)。t=0は完全保持。512px float/uint8間の出力RMSはwarm平均.003047/最大.009096、fresh平均.003113/最大.007164で、両入力形式に同種の欠陥がある。

正しい幾何情報を描くDQは成立したが、DRの小型CNNと現在の幾何lossは、線内部の負領域・幅・接続を十分に学べていない。これだけで容量不足、距離場一般の失敗、学習延長の無効を結論づけない。次はDSで同じ予測場の描画だけを比較し、その後、線内部の存在を明示するlossと同期間の継続学習対照を検討する。予約済みの新規確認データは未評価。Kritaと製品モデルは変更しない。
