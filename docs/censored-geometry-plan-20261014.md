# DW: boundary-censored geometry supervision

DV learned narrow centers from wide strokes at unchanged capacity, but endpoints, close curves and fill corners still fail. Its local gradients for wide strokes and fills oppose each other. That is not evidence of infeasibility. The current objective also fits arbitrary distance magnitudes in already opaque regions, including a nonzero distance objective on entirely blank images. Test removal of that unnecessary constraint before changing model size.

Compare unchanged DT balanced supervision (control) with a boundary-censored objective. In each stage's physical pixel units, fit the signed distance exactly only for targets strictly between -1 and +1. For targets at least +1 require prediction >=+1, and targets at most -1 require prediction <=-1, using one-sided robust residuals with the same division by8 and robust scale. Keep all target signs and wrong-side gradients, without clipping the prediction. Keep balanced inside/outside sign supervision unchanged. Match spatial gradients only on adjacent subpixels whose candidate target distances are both within that band. Normalize each gradient axis by the maximum valid mass among candidate translations; this denominator is shared. Keep the original common spatial ROI/weights for distance and sign, all-stage .5**level weighting and one global candidate choice across components/stages. This changes both unnecessary distance and derivative constraints, not rendering or a final raster threshold.
