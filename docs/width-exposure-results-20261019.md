# IJ: 太い線の学習頻度を増やした比較

同じ22,725パラメータ・IG hardnegative初期値から、追加データ25%と50%を各6,000更新した。継続学習により極太線の端と塗りの縁は両群で改善したが、50%化だけで中間幅の二重線や近接曲線の閉ループは解消しない。採用基準は未達。画像MSEで選別せず、原寸92ページをすべて確認した。

[原寸比較92ページ](../runs/width-exposure-20261019/review.html)、[完了記録](../runs/width-exposure-20261019/completion.json)、[学習監査](../runs/width-exposure-20261019/training-audit.json)。これは既知の開発用合成例であり、独立した汎化確認ではない。本番重み・Krita・未見DN16は未変更。

## 条件と検証

実装926773d。幅6のD4 CNNとgraph head、R1、fill陰性上位1%のlossを両群で共通にした。B4、再帰1–6段各1,000更新、全段loss重み0.5^level、base LR 1e-4×sqrt(4)=2e-4から2e-5へcosine減衰。optimizer/EMAを新規開始した。従来512例と追加1,024例、D4・blur・opacity・部分適用を共通の系列から採った。

24,000件中18,037件は両群で入力・教師がbyte単位一致、残る5,963件は従来例から追加例へ置換された。全batchが同一という比較ではない。全更新の抽選・処方・hashを再照合した。全metrics有限、自己12更新は完全一致。別プロセスの同じROCm GPU上の先頭12組はbit一致0、最大絶対差0.000297546、atol/rtol各1e-5内。CPU/GPU比較ではない。全状態5保存、raw/EMA20保存の復元は完全一致。

10テスト成功（5.45秒）、lint/diff検査成功。prepare 5.36秒、preflight 81.95秒、train 3,985.95秒、標準評価80.46秒、広範囲評価205.36秒、fit評価20.52秒、finalize 1.49秒、全工程exit 0。末尾600更新のモデル更新平均は25%群0.2682秒、50%群0.2677秒。clip発動は5,996/5,999更新。

## 実画像の結果

- 初期IGで荒れていた塗り56/896の縁は両群で滑らかになり、黒い内部も保持した。これは50%固有の効果ではない。
- 80/87.5pxの太線は一本のまま。約95pxの学習例769は両群で大きな端の切れ・側方小片が減った。25% d3の方がまとまって見え、50% d1の微小点やd3/d6下端の細かな崩れは残る。
- width60×0.5の小片は50%群で減少。一方、58×0.5、61×0.25、62×0.25は両群で中空または二重線状。63×0.5も太さ・ぎざつきが残る。
- standard36/38、scene1/5の近接曲線の端が閉じる問題、rough41の下端の小片は両群で残った。明瞭な二本37は分離を維持した。
- 通常線、交差、明示的な隙間、塗り、保護画素は概ね維持。scene3の隙間は開いている。強ぼかしの分岐には細かな突起が残る。

標準166、広範囲2,360、fit24の計2,550予測を保存。31+57+4の新規原寸ページを全確認し、教師12ページは検証済みのものを再利用した。各ページの観察は各nativeディレクトリのobservations.jsonに保存。

[IL補助集計](../../jax-raster-topology-audit-20261019/docs/raster-topology-audit-results-20261019.md)では、幅掃引108画像中alpha>=.25で穴を含む画像がIG初期11、25%群10、50%群5へ減った。しかし細い斜めの白い帯は4近傍では1画素の穴に分割される。50%群の「2px以上の穴がある画像0」は、原寸で見える二重線の解消を意味しない。穴数だけを品質点数にしない。

頻度増を無条件の改善策とはせず、この比較を完了する。次は準備済みICの連続曲線表現が少数例に適合できるかを検証する。ICはパラメータ数・教師・初期値が違い、IJへの一要因比較ではない。まず再現性の失敗を解決してから本学習へ進む。
