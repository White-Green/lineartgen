# 軽量な線画生成モデルをKritaで試す

Windows x64、Python 3.13を内蔵するKrita用。ZIPをKritaのPythonプラグインインポーターで読み込み、再起動する。下描きをカラーラベル1、描き途中の線画を2に設定する。試用時の基準はStrength 0.5、Lineart passes 6、Seed 0。[プラグインの配布ビルド](https://github.com/White-Green/diffusion_drawing/actions?query=branch%3Arewrite%2Fcompact-latent-preview-20261125)

## 変更した処理と学習

前段は11月21日配布の1ch線画VAEと条件付き潜在拡散の重みを使用する。後段では下描き上の経路距離探索6枚を省き、15入力と基本画像から計算する9枚の近傍特徴を使う。表示候補のある画素を集め、24→24→16→1のMLPをONNX Runtimeで実行する。連結成分を行方向の連続区間から求める実装を前後段で共有する。拡散の各段・マスク合成・クリッピングは以前と同じ。後段パラメータは4,475個から1,017個になった。

3,200更新の経路探索なしモデルから始め、保存済みの倍率別線画への合成編集、迷い線を含む二択、両方が必要な線、閉路などを拡充した。訓練は1,324編集、1,266,718画素サンプル、バッチ512で追加100,000更新。開発220編集で追加40k、60k、80k、100kを比較し、選択対・必要線の保持・境界・画素誤差の組み合わせで60kを選んだ。配布重みは**通算63,200更新**。生成案の濃度を最低保証する補正は選ばれなかった。重みおよびONNX資産のSHA-256はモデルのマニフェストに記録している。

## 配布候補の確認

同じ凍結前段、同じ入力・ノイズで旧版と比較した合成368編集。未知形状の一筆二択、閉路、広域の分岐・交差、保存済み原画24枚×6倍率への編集を含む。細部の二本課題は既存の評価形状を新しい倍率で測った。

| 指標 | 11月21日版 | 軽量版 |
|---|---:|---:|
| なぞった側を入れ替えた両方で成功 | 28/48対 | 23/48対 |
| 必要な二本をともに保持 | 39/104 | 56/104 |
| 一筆二択で不要線が残る割合 | 19.9% | 23.8% |
| 編集境界で必要な線が接続 | 99.0% | 99.2% |
| 出力アルファの全画素MSE（0〜1） | 0.001787 | 0.001280 |
| 保護画素の違反 | 0 | 0 |

Linux、Ryzen AI MAX+ 395、CPU 1スレッドで画面と同じBGRA入出力の推論を交互に4回測定した中央値。短い一筆を描いた512×512で **894→535ms**、保存済み原画の編集を並べた1024×1024で **4.60→2.45秒**。ホスト側のレイヤー読み書き、初期化、Windows DirectMLの時間は含まない。

エクスポート後は別の220編集・28,966,912画素で学習側の参照と照合した。16画素にアルファ1階調の差があり、保護画素は完全に一致した。全6段で独立したJAX参照を照合し、1024²のタイル境界も確認した。意図的な二本の保持は向上したが、一筆だけで意図する方を選べないケースが増えた。手描きのラフでの主観評価は未実施。
