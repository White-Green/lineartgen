# CY: 線ごとの断面を均等に扱い、細い・短い枝の消失を防ぐ比較

CXでは画面の粒は減る一方、細線の切断が増えた。画素面積による評価が細い/短い枝を
軽視するという仮説を検証する。モデルやデータ数を変えず、各経路の断面項を追加する。

## 条件

両条件はCX dynamic Charbonnier raw6000を初期値にする。16ch/15,809params、同じ512例、
fresh Adam/EMA、batch4、各6,000更新、LR base5e-5*sqrt(4)=1e-4→cosine1e-5。
深さ1..6、各段0.5**level、縮小後Gaussian、3masksを維持。seed2026101312。

- baseline: CXのdynamic Charbonnier family＋CT geometry/rangeguardを継続。
- profile: 同じlossに、係数.25の経路別断面誤差を足す。

各経路の弧長5～95%を17点等間隔で取り、法線方向129点のopacity断面をbilinearで読む。
半径max(10,1.5*width+6)px。各段ではpixel centerに合わせて座標を変換し、正解も同じbox縮小。
断面誤差はCharbonnier eps.05。断面の全27候補平均ink量で正規化（floor .25px/scale）。
経路内の有効17点を平均し、その後経路を等重みで平均する。短い・細い経路も同じ一票にする。
断面全体が操作対象でない場合は除外。白/黒など経路なしの追加lossは0。
画素costと断面costを足し、全段・全経路を集計後に一つの候補を選ぶ。断面ごとの別候補は不可。
推論は既存の画像I/Oのまま。経路情報・27候補は学習lossにのみ渡す。

## 評価

同じ4split×64例、3masks×2noise(seed2026101313)、最終raw6000＋初期値で4,608行。
既存指標に加え、弧長に沿う全経路probeによる断面・接続をfull_として併記する。
接続は隣接17点と端間、経路間query。既存cornerの前半偏りを補う。旧値を上書きしない。
16等倍シートで枝・近接線・細線・角・線端・白紙・黒・部分保護を確認する。
主対象はold_train24の細い枝、old_probe36の消えた線、new_probe36の融合。
断面平均のみの改善や、線を太らせて接続率だけ上げる結果は成功としない。
評価後に候補・係数・終了stepを選び直さない。次の条件は別の実験にする。

計画/数値コード/データを凍結、最初6更新GPU再実行atol1e-7/rtol1e-5、保存復元/12export完全一致。
CPUでは全経路coverage、許容候補/段間一貫性、保護、薄太経路の均等重み、実更新を検証する。
固定opacity.4・有限27候補の診断であり、普遍的な線画lossの完成ではない。
Krita・配布・独立確認seed・封印データは未変更。
