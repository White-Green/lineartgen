# 線画品質の現在地（CT・CU完了）

**16chのまま、候補を平均せず一つの清書を選ぶ学習で、灰色の帯を細い濃い線へ改善できた。**
許容清書27通りを用意できる合成課題で、mean/minimum各4,000更新を比較した。
画像でも差を確認し、未見乱数形状の強度.5の許容断面距離は.5612→.2138へ低下した。
容量増加を優先せず、複数解を平均させない学習目的の拡張へ進む根拠になった。

ただし細い分岐の消失、端点の乱れ、白紙への残留ノイズが残り、採用はしていない。
候補集合は学習時のみ使用し、推論は通常のモデル出力。固定opacityと有限形状族の診断なので、
実際の下描きでの成功ではない。先行CTの線画判別器は相対的改善に留まった。

方針変更後に計5条件各4,000更新、4,608モデル評価行、20枚の等倍シートを確認。
Krita・配布・独立確認・封印データは変更していない。今回の実験ジョブは全て終了。
