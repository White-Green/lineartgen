# 線画品質の現在地（CR完了・目的を見直し）

**方針を訂正した。** 目的は入力に沿った自然な線画であり、一つの教師画像への厳密な
一致ではない。CRの数値改善は限定した復元診断の結果として残す。
次に提案していた両サイズの学習延長は優先計画から外し、
[許容清書を複数認める評価と、線画の分布を学ぶ方針](lineart-objective-reset-20261013.md)へ移る。
新方針の学習はまだ開始していない。

線の芯・幅・接続の情報を残した合成入力で、独立した16/32chの自己再帰CNNを各6,000更新
比較した。32chは訓練例と未見形状の両方で改善し、未見の強度0.5でF1は0.9477→0.9637、
濃度不足は5.99%→3.89%、線幅誤差は0.122→0.096pxになった。
小さなモデルにも容量を増やす効果はある。ただし16chの限界や32chの必要性の証明ではない。

細線の欠損と白紙への薄いノイズが残り、強度0.5でのhalo平均はほぼ同じだった。
両モデルとも診断基準は未達。12枚の等倍シートを確認し、再現性・復元・全評価の監査を完了した。
採用はしていない。

今回の入力は可逆性を確認した易しい診断であり、実際の下描きでの性能や最小モデルサイズを
確定していない。特に、複数の自然な清書のどれかを出すという今回再確認した目的への
適合性を、この数値比較だけでは判断できない。
