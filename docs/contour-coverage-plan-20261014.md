# DS: zero-set area rendering, frozen before learned DR outputs are inspected

DR trains two geometry-field models using a fixed distance-to-coverage transfer. A nearly constant predicted field near zero could still become an extended gray patch. This independent auxiliary study changes only the renderer: construct a continuous piecewise-linear field and integrate the area of its nonpositive set. No learned opacity and no threshold on the final raster are used. Constant positive/negative fields become white/black even when their magnitude is small. Fine oscillating signs can still produce broad gray or stippled regions, and incorrect geometry can erase, split or join lines. These remain failures.

The four samples per native pixel are retained. Interpolated halfway points split the grid along native pixel boundaries. Each subcell is split into two triangles; exact linear zero-set area in each triangle is averaged into pixels. Outside the outermost sample center, constant boundary extension is used. Exact zero is classified as inside. Quarter-pixel sampling can miss very narrow stroke tips; an oracle comparison must expose this limitation. Positive field rescaling must preserve results within float precision.

Preflight: analytic triangle fractions/derivative, half-plane pixel coverage, field-scale invariance, constant near-zero fields, crossing/parallel/gap topology. Run the same 24 known-geometry cases as DQ: 16 established probe shapes and eight established512 scenes. Compare DQ's fixed transfer to contour coverage, record mass and pixel changes without treating raster agreement as quality, verify six-scale box-pyramid mass conservation and protected-input equality, and inspect all eight native oracle pages. This is a rendering prerequisite only.

If the oracle is structurally sound, evaluate the fixed raw step6000 warm and fresh DR models, regardless of which looks better. Bind both checkpoints before evaluation. Use the exact same24 source images, whole and partial0.5 noise masks, float and uint8 source encodings, one Gaussian draw with seed2026101410, depth6 and image scale1.0. Compare fixed transfer and contour area on each predicted field:384 rendered outputs. Inspect16 native pages showing both models and both renderers with uint8 inputs, and record float/uint8 differences. Save the latent fields as well as raster images. No parameter updates or checkpoint selection are allowed in DS. This bounded auxiliary screen does not substitute for DR's larger frozen evaluation, and does not touch the reserved fresh confirmation.

Adoption requires preserved faint/thin/wide lines, crossings, intentional gaps, filled regions and protected areas together with reduced unwanted gray. Whiter output obtained by erasing lines is not improvement. If the renderer exposes fragmented geometry, report that failure explicitly. Production runtime and Krita remain unchanged.
