# HA: 同時勾配の平均と衝突成分の投影

GZではfocusの例・訪問数・LRをGXに揃えても、背景更新を挟むと一部の直交片が再発した。次は2種類の勾配を同じモデル状態で計算し、単純平均と衝突成分の除去を比較する。モデル容量、教師、入力、計算量、スケジュールを両条件で揃える。GZとの差は更新単位・有効batch・scheduleも含むため、HA内の2条件が主比較である。

[原論文](https://arxiv.org/abs/2001.06782)と[著者実装](https://github.com/tianheyu927/PCGrad/blob/master/PCGrad_tf.py)を参照した2-task PCGrad。元の勾配f,bの内積dが負なら、f'=f-d/max(||b||²,1e-12)b、b'=b-d/max(||f||²,1e-12)fとし、(f'+b')/2を使う。非負なら(f+b)/2。著者実装の和に対して、本比較は両条件とも平均で集約する。完全反対向きなら0になり得る。非凸lossやAdamの実際の更新で両損失が必ず減るとは主張しない。投影後の更新は一般に表示する平均lossそのものの勾配ではない。

初期値は未変更のGZ/GX/GW初期値、各21890パラメータ。学習済み特化重みは使わない。GZのfocus1200とbackground1200を同じ順序で対にし、全2400入力digestを照合する。双方B4、1対を有効B8として1更新、各1200更新。全6段均等、各段0.5**level正規化loss、focusはGX consistent、backgroundはGY consistent、opening0・geometry.1。batch8のsqrt scalingでpeak1e-4*sqrt(8)、minimum1e-5*sqrt(8)、cosine1200、warmup0、clip1、EMA.999。clipは集約後に1回。衝突dot/cosine、各勾配norm、集約後勾配と各元勾配の内積、投影発生率を全更新で記録する。

保存0/18/400/800/1200、各raw/EMA計20個と全状態。初期モデル・全6段出力の完全一致、有限勾配、自身の18更新・全状態完全再現、保存と復元を確認する。投影のCPUテストは衝突例、非衝突、ゼロ、完全逆向き、平均勾配と平均lossの微分の一致を含む。差があればログを保全し、条件を後から緩めない。

最終raw1200のみ評価する。GZと同じGX学習12・転移8・アンカー4、GK8、GO2を深さ1/3/6、512pxシーン8を全体/部分・float/uint8で評価する。新268出力と保存対照118出力。深さ1/6の形状18ページ、シーン全体8＋部分1/3/5/7の4ページ、計30原寸ページをすべて見る。保存対照を再推論しない。GYは厳密な初期参照の一致検証で失敗した事実を維持する。

主判断は平均条件より直交片を減らし、主線の連続性・端・通常曲線・隙間・塗りを保てるか。改善しても少数例への適合と広い汎化を区別し、この比較だけで採用しない。MSEを採否に使わない。fresh16、Krita、本番exportは変更しない。
