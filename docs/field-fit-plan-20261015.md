# FD: 小さいCNNで既知の修復対象を学習できるか

FCでは現在のlossのまま直接fieldを更新すると欠陥が修復した。同じ2形状の教師を幅6・16,402パラメータのCNNに提示し、表現能力と最適化の切り分けを続ける。既知例を使ったfitting診断であり、汎化や採用の検証ではない。

- 初期モデルはEZ supported通算24k raw。学習はFCのscene7と統合probe37の全域強度0.5のみ、batch1。各形状を6更新続け、その中で深さ1〜6を一巡し、次の形状に交代する。各形状100回×全6深さ=600更新、合計1,200更新。
- FCと同じ9移動候補、全段0.5^level、censored field +0.1 gradient +0.25 L4 sign。形状の教師は固定し、全学習例をその教師で学習する。context dropout 0.5は従来通り、seed2026101505と更新番号。CNNの全重みを学習し、再帰段の結合も通常通り残す。
- optimizer新規、base LR2e-4×sqrt(batch1)=2e-4、cosineで2e-5まで。clip1、EMA0.999。元の2形状に対する入出力は同じ。Gaussian noisy引数を使わないモデルの診断であり、ノイズ耐性の試験ではない。
- 保存0/12/400/800/1200。最初の12更新（両形状・全深さ）をmetrics/optimizer/weights/EMAまで再現し、各保存点の復元、raw/EMA exportを照合する。学習区間400ごとに実終了コードと時間を記録。
- 評価はFCと同じ2形状×全域/部分の4条件。initial/400/800/1200のrawを並べ、原寸全体4枚・切り出し4枚を確認。最終1200を指定結果とし中間点やEMAを選別しない。probe37部分は全形状が保護される対照。
- 一般化の評価・未使用16例・Krita採用/exportは行わない。小モデルで修復できれば、次は未知の合成形状を追加してデータの接続・相対線幅の範囲を調べる。できなくても全ての小モデルが不可能という結論にはしない。
