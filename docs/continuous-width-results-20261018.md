# 連続した下描き幅の追加学習（IE、2026-10-18）

追加データで多数の太い下描きが連続した細線に改善した。ただし採用基準は未達。80/87.5pxの評価用矩形と学習に4回使った95.19pxの矩形で、中央線の周囲に太い枠が残る。中間幅の閉じた細長いループも残り、rough-41の近接線の下端は対照より太く結合した。

モデルはHYのR1・22,725パラメータを共通初期値として固定。同じloss・optimizer・拡張・部分処理で、旧512例だけの対照と、4–96pxの矩形/塗り1024例を25%混ぜる群を各3000更新した。B4、再帰1–6段を各500更新、各段loss、sqrt(batch)によるピークLR 2e-4を維持。追加群では実際に3096/12000件が新データ、963/1024例が出現した。未置換8904件の入力と教師は対照と完全一致を検証。

目視では59/63の幅2倍、61の幅1.5–2倍、62の幅1.5倍などで太い帯や断片が一本の線になった。62の幅2倍は矩形の別の軸を選んだ線になったが、曖昧な下描きでは軸の選択自体を不正解としない。一部の孤立片は問題として残る。通常の線、明示的な切れ目、不透明な塗りはおおむね維持し、保護画素は全条件で完全一致。scene-3の隙間はfloat/uint8/部分処理すべてで保持した。

未解決の太い枠にはfill出力が多数含まれる（80px:4644、87.5px:8843、学習95.19px:10507画素、d3）。一方、中間幅58×0.5のループにはfillがない。次は重み固定でfillを除いた描画とloss勾配を診断し、塗り誤判定と線の接続誤りを個別に調べる。これだけでモデル容量不足とは結論しない。

検証は標準166条件、既存の広範囲評価2360条件、事前指定した学習入力診断24条件、合計2550出力。等倍の標準31枚・広範囲57枚・教師12枚・学習入力4枚・隙間の切り出し1枚をすべて目視し所見を保存。既知の評価を繰り返した実験であり独立な最終評価ではない。学習と評価の一致は従来の空白/塗りのみ、新データとの一致は0。未使用のDNデータは未評価。
