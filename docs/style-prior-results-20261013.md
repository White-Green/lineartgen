# DF: 固定清書スタイルと学習された線画prior

清書とぼけた平均線を見分ける判別器は学習できたが、出力の明瞭な改善には届かなかった。
DD canonicalからcontrol/priorを各6,000更新し、9,216評価行と128の512px出力を生成。
事前指定の標準8枚・劣化8枚・512px6枚、計22枚を実際に等倍で確認した。製品未採用。

固定2px清書候補のglobal選択lossに、prior側だけ出力のみを見る15,497パラメータの判別器を追加。
端点・中央・path間最近点付近のpatchを重点抽出し、保護領域を含むpatchは除外した。
係数.2、500step ramp。深さ1–6、各段loss、sqrt(batch)のLRは保持した。
source-onlyのため追加独立Gaussianには依存しない。確率的生成/OTの多様性を維持できたとは主張しない。
