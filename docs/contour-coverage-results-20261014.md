# DS: 幾何場の輪郭面積による描画 — 描画単体は成立、学習出力は不採用

DRの予測場に対する固定の濃度変換を、符号が負の領域を不透明な図形として描く方法と比較した。三角形内の線形補間から画素内の被覆面積を求める。最終画像の二値化ではなく、潜在幾何情報からの描画である。定数の正/負の場は、その絶対値が小さくても白/黒になる。ただし符号が細かく振動すれば、依然として画素内平均は灰色になりうる。

数値実装`bb1ac47`。3テストとRuff通過。DQと同じ24個の既知形状を描き、8ページを等倍確認した。細線・交点・平行線・意図した隙間・黒ベタは保たれ、従来描画との総インク量差は最大0.780%。極細の入り抜き先端ではわずかな被覆が減る。6段階の縮小時のインク量、t=0保持も検証。これは描画器の前提条件の確認であり、学習モデルの性能ではない。

DRのwarm/fresh raw6000を固定し、同じ24入力×全体/部分×float/uint8×2モデル×2描画方式の384出力を比較。16ページを等倍確認した。輪郭面積に変えても、消えた交点・近接線・太い入力の中心線は戻らない。一部の弱い細線はさらに切れた。黒ベタの白い穴も残る。したがって、描画側の濃度変換だけの変更では解決しない。

float/uint8出力差も保存した。ただしDQ由来の512px入力は既に量子化済みなので、この部分の再量子化は新たな頑健性検証ではない。未量子化512pxとの比較はDRにある。DSの512px fixed出力はDRの同じuint8入力の出力と照合する。

最初のoracle実行は、CPU/GPUの丸め差2.92e-6を同一デバイス用の2e-6等価性検査に通そうとして停止した。失敗したrunを保存し、同一CPU上の幾何描画との等価性検査を同じ許容値で実施した。以前のGPU出力との差は別途記録し、全24例の最大は1.1921e-5。描画方式や学習条件をこの失敗に合わせて変更したものではない。

次に検証すべき対象は、幾何場を平均的に近づけるだけでなく、線内部の負領域を確保する学習信号である。線内部/外部を別々に正規化した符号マージンlossを、同じ初期モデルからの継続学習対照と比較する。容量増加での改善とは区別する。製品採用・Krita変更なし、予約済み新規確認データ未使用。
