# FB: 同じ初期出力から幅6・12を比較

既知の合成データによる比較では、幅12への拡張は残っている線の途切れ・端点の膨らみ・短い余分な線を明確には改善しなかった。研究用の基準はEZ supportedの24k rawを維持する。Krita採用、export、未使用16例による確認は行っていない。

## 条件

- 数値コード固定: `f054fd3`。計画: [widened-geometry-plan-20261015.md](widened-geometry-plan-20261015.md)。run: `runs/widened-geometry-20261015`。
- EZ supported raw6k（通算24k）を幅6の16,402パラメータと幅12の63,892パラメータに展開。追加チャンネルから元チャンネルおよびheadへの初期出力重みをゼロにして初期関数を保持。両方の全パラメータを更新する独立比較であり、学習後も小モデルが独立する入れ子モデルではない。
- 各3,000更新、双方optimizer新規。親データstep24000–26999、batch4、seed2026101440、sqrt(batch)込みpeak LR 2e-4→2e-5。物理スケールに合わせたdilation、再帰深さ1〜6、全段lossの重み0.5^level、context dropout 0.5、L4符号ペナルティ、入力で支持される統合線teacherは共通。
- 最終rawを事前指定。EMAや中間snapshotからの選択はしない。

## 実際の出力確認

9,516出力を生成し、原寸34ページと追加切り出し5枚を実際に確認した。観察と画像hashは `diagnostics/review-observations.json`、`diagnostics/details/`、`diagnostics/decision.json` に保存。

- 普通の線、分岐、意図された隙間、塗り、部分編集での保護領域は維持。
- probe61の余分な平行線、62やrough58の大きな点状残留が減った以前の改善を維持。
- probe37の主要な曲線は黒く連続するが、左下の短い別線が残る。scene7の細い縦線は下側の曲線との交差直前・直後で途切れる。双方の幅とfloat/uint8で残存。
- scene1の分岐と短い突起は残るが、主曲線の先端の小さな鉤も残る。幅12での明確な改善はない。
- FAのfresh24kで増えたscene2の横の薄い線やold_train36中央の強い痕跡は今回の比較では目立たない。
- 訓練範囲を超える太さでは枠状・棒状・塊状・中心線欠落が引き続き発生する。

追加チャンネルが固定された実験ではない。幅12の63,892パラメータ全てが初期値から変化し、追加head入力6チャンネルの重みL2はそれぞれ0.0212〜0.0393、合計0.07179。追加チャンネルから元チャンネルへの重みも非ゼロになった。全パラメータ変化RMSは幅6=0.004742、幅12=0.009472。これは更新の確認であり、画像品質の指標ではない。3kのwarm拡張だけから、幅12や別の初期化・学習時間の効果を否定はできない。
