# DT: balanced signed-geometry supervision

DR learned distance/gradient fields but erased many line interiors, including training shapes. DS showed that opaque contour rendering preserves correct known geometry yet cannot recover the missing learned negative regions. DT tests explicit inside/outside supervision at unchanged capacity, against a matched continued-training control. This does not assume model size is the cause, and does not use teacher-image MSE.

Initialize BOTH arms from the complete DR warm raw6000 model, including its geometry head. Preserve16,064 parameters, RF87, nine-feature physical-level conditioning, source normalization and recursive geometry state. Fresh Adam/EMA for both.6,000 additional updates per arm, batch4, base LR5e-5×sqrt4=1e-4, cosine minimum1e-5, EMA.999. Identical512-shape data/cache,25%base/75%rough augmentation, input/noise/mask draws,1–6 stage cycle and.5**level stage weights. Seed2026101411, evaluation2026101412. Save0,6,2000,6000; report raw6000, not an image-selected checkpoint. Reuse the exact DR geometry cache and record hashes.

`control` retains DR's original distance +.1 spatial-gradient objective, using the unchanged original function. `balanced` adds coefficient.25 sign-margin loss. At every supervised stage, define inside as target geometry<0 and outside as>0. For each sample and candidate, use margin=min(abs(target distance),.25 current-stage px). Interior penalty is relu(margin+prediction); exterior is relu(margin-prediction), in physical pixels. Weight using the existing common candidate-band/active mask. Normalize each class separately, using the maximum class weight mass across the nine candidates as a shared denominator, with minimum1. Average the two class penalties. Empty classes contribute zero. True target geometry has zero penalty. One global candidate is selected for the whole sample across all scales and components, including sign loss; no separate pixel or stage choices.

The shared denominator limits candidate-position normalization bias, although a partly protected line can legitimately have different visible interior mass among allowed translations. Very coarse subpixel grids can contain no inside sample for a thin line; this term does not invent one. Existing distance/gradient loss remains at those stages. No final raster threshold or thickness postprocessing is introduced. Decode with DR's fixed transfer for this controlled training comparison; DS's contour decoder remains an independent experiment.
