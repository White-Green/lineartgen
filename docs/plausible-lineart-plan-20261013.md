# CS: 複数の清書を許す小規模な生成器比較

学習前に固定する。新しい品質目的のpilotであり採用試験ではない。生成画像を評価する。
判別器だけを長期学習する段階は設けない。合成データのみ。Krita・配布・封印確認を変更しない。

## 比較する条件

3条件とも同じ16ch local CNN（15,809パラメータ）。CR raw6000を共通初期重みとし、
Adam/EMAを新規作成する。事前の画素学習があることを明示し、ゼロからの分布学習とは呼ばない。

| 条件 | 生成器の学習目的 |
|---|---|
| pixel | CRと同じinterval L1、tone power .5、noise floor .05、identity .1、他auxなし |
| tolerant | 入力から求める許容幅付きの形状・線量lossと、範囲外preclipの弱い罰則 |
| prior | tolerantと同じ項＋出力だけを見る線画判別器のnon-saturating logistic loss |

3条件とも4,000更新、batch4、base LR 5e-5 * sqrt(4)=1e-4、cosineで1e-5へ。
clip1/AdamW decay1e-4/EMA .999。深さ1..6を循環し、各段lossは0.5**levelで正規化。
同じ画像・選択教師・strength・ノイズを各条件へ渡し、更新順を循環する。
各モデルの出力・重みの混入なし。one-passの空間自己再帰、progress=1。
ソースとマスクを縮小してから各解像度に独立Gaussianを0.25*strength倍で加える。
noise強度1を必要としない。whole .1/.5、partial .5を等確率に選ぶ。

## 曖昧さを明示した合成課題

256px、train/probe各64例。9形状族（直線、細線、Bezier、角、分岐、交差、平行、gap、taper）
を各6例、白紙2、黒矩形2、太線6。非定数60形状は分割間でhashが異なる。
白紙と黒矩形は共有する定数で、未見形状とは数えない。

各形状の最初の線の中央法線方向へ、全体を-2..+2px（0.5刻み）ずらし、幅を0.8/1/1.2倍
した27通りを許容する。線は4倍解像度の黒いpolygonからLanczosでAAして描画する。
追加のコントラスト補正や二値化はしない。白紙/黒は27通りとも同じ定数。
入力は幅1倍で±2pxの2画像を平均し、sigma1.2のGaussian blurとopacity0.4を適用。
毎更新の対応教師は27通りから一様に選ぶが、入力は教師選択と独立で常に同じ。
この人工的な曖昧さでは、特定の対応教師を復元するための情報は入力にない。

opacity0.4はこの診断の既知定数で、入力追従lossにも使用する。未知の濃度の実際の
下描きにそのまま使えることは主張しない。有限の許容形状族があらゆる自然な清書を
網羅するとも主張しない。probeは新しい乱数例であり、未見の形状族ではない。

データseed2026101301、選択2026101302、判別器初期化2026101303、学習ノイズ2026101304、
評価ノイズ2026101305。独立確認seed20261005は使わない。

## 入力追従と線画prior

入力opacityを0.4で除した線量場と出力opacityを、物理sigma4px（各段最小.5px）で平滑化。
入力場の局所最大値の50%を許容差とし、範囲外だけ罰する。局所最大半径は物理2px、
各段最小1px。編集領域の総線量は入力補正線量の75〜125%、部分適用では50〜150%を
許容する。いずれも入力線量と小さい紙面floorで正規化。保護領域は比較用の共通入力場へ
置き換え、出力の保護領域を動かす圧力をかけない。
範囲外のpreclipには0.05*mean(relu(abs(raw)-1))。この項も教師画像には依存しない。
灰色の平均も入力追従だけなら許容されるため、tolerant条件を置いてpriorの効果を分ける。

判別器は出力opacityと物理解像度の定数チャンネルだけを受け取る。source/選択教師との
画素対応を条件入力にしない。4層stride2 Conv（8/16/32/32）と3x3 head。
各段のネイティブcrop（最大64px、source由来ink2/paper1/active1）と、画像全体を
最大64pxへbox縮小したviewを等重みで使う。保護領域・編集境界を含むcropは重み0。
部分適用の全体viewも重み0。各段のrealはその段へ正しく縮小されたcleanなので、
低解像度やサブピクセル細線の正当な灰色を一律に否定する学習ではない。

DはGの更新直前に1回更新。logistic real/fake＋R1 gamma1、Adam LR1e-4、beta0/.99、clip1。
Gのprior係数は最初の250更新で0.05へ線形増加し固定する。D単体warmupなし。
学習中に係数やlossを切り替えない。幅探索も行わない。

## 評価を先に確認する

小さな直線の仕様テストで、左右/中央/未登録のsubpixel位置・幅の自然な清書を許容し、
灰色の平均、白紙、無関係な線、切断を区別する。これは判別器の事前採用審査ではない。
教師方向への勾配内積や分類正答率を生成器実験の開始条件にしない。

主な診断は、法線方向のopacity断面と許容clean断面族の最小L1差（線量で正規化）、
必要な断面の消失、許容線域外のインク、入力形状からの逸脱、接続の切れ/橋、白紙・黒。
断面ごとに異なる位置・幅を選べる。接続は別に測る。接続問い合わせの座標系は、
画像内の断面の平均誤差が最小の許容形状に合わせる。単一教師へ固定しない。
接続はopacity .1/.25の2閾値で測り、濃度の適切さは断面の項で測る。
事前の仕様テストで、旧評価のopacity .625閾値が未登録の自然なAA細線を切断扱いする
誤判定を見つけたため分離した。学習後の結果に合わせた閾値変更ではない。
部分適用で保護域に触れる断面・接続は評価対象外とし、対象数を報告する。

参考許容値は断面誤差.25、消失0、入力追従違反.2、許容域外線量割合.02、
有効な切れ/橋0、白紙最大opacity.05、黒内部平均.95以上。単一の教師へのMSE/F1や
判別器スコアは採否条件に使わない。参考値の未達数だけでも採否を決めず、
許容形状の参照値・失敗の大きさ・生成画像を併記する。

## 実行・監査・画像確認

full stateとraw/EMAを0/6/1000/4000で保存、24 exports。初期出力を全6段で比較、
最初の6実更新を独立に再現してG/D/両Adam/EMAを照合。全保存状態からexportを照合する。
数値ソース・設定・入力・checkpoint・出力をhashで固定する。
評価するモデルは初期値と各条件の最終raw4000のみ。checkpoint選択は行わない。

深さ3、128例 x 3マスク x 2新規ノイズ x 4モデル=3,072行。
source/灰色平均/許容left/center/rightの参照は128 x 3 x 5=1,920行。
全出力を保存し、train/probe、whole .5/partial .5の各3群、計12枚の等倍シートを確認。
固定indexは0/6/12/18、24/30/36/42、48/54/56/58。表示後の二値化・濃度補正なし。

線画らしさが改善しても入力を無視する、綺麗でも線が消える、灰色が黒い二重線へ変わる、
といった失敗は成功扱いしない。訓練例とprobeの両方を示す。
このpilotを通っても、実際の下描き・未知濃度・512px・Kritaの確認は別に必要。
