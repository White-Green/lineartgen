# 線画loss比較：追加2kの中間結果

その後、全条件の追加10kと評価を完了した。[最終結果](lineart-loss-results-20261006.md)を参照。
以下は2k時点での記録。

領域別lossで線周囲の余分な灰色が減った。一方で、教師ink量の不足と閾値で測る切断率が
増えており、**この時点での採用は保留**。線断面lossにも同じ方向の副作用がある。
判別器を追加した条件は、今回の設定・2k時点では対照との差が小さい。
予定どおり全5条件を追加10kまで継続し、最終的な比較はその後に行う。

[実験条件と手順](lineart-loss-experiment-20261006.md)。以下は同じ100k EMAから同じ系列で
**追加2k学習した条件同士**の比較で、配布済み100kモデルとの差をそのまま示す表ではない。
下描きはすべて合成、学習seedは1つ。primaryはEMA、推論は再帰3段・denoise1回。

## 灰色の減少と線への影響

強いstrokes劣化での結果。灰色は線外6px以内の背景に残る余剰不透明度。
全画面の灰色画素率ではない。小さいほどよい。

| 条件 | 実線画由来のhalo | 幾何線画のhalo | 幾何線画のink不足 | 幾何線画の切断率 |
| --- | ---: | ---: | ---: | ---: |
| 現行loss | .14708 | .21278 | 21.74% | 19.79% |
| contrast除去 | .14729 | .21297 | 21.72% | 19.79% |
| 領域別loss | .12544 | .18010 | 23.03% | 23.07% |
| 線断面loss | .14191 | .19610 | 22.70% | 22.34% |
| 判別器 | .14732 | .21300 | 21.68% | 19.79% |

領域別lossはcontrast除去に対してhaloが実線画由来で14.8%、幾何で15.4%減少。
同時に幾何の切断率は+3.28ポイント、教師ink不足は+1.32ポイント。
線断面lossはhaloがそれぞれ3.7%・7.9%減る一方、切断率は+2.55ポイント。

ink不足は教師のink量に対する不足の割合で、消えた線の本数ではない。
切断率は不透明度37.5/50/62.5%の閾値で接続を調べた各ケースの平均。
線が薄くなって閾値を下回る影響も含み、全てが表示上の白い切れ目とは限らない。

実線画由来のhaloは60条件中46条件で定義され、元画像は12個。
幾何haloは128条件・32形状群、接続は全体編集64条件・32形状群。
元画像/形状群単位のbootstrapでは、領域別lossの幾何halo差は
−.03288（95%区間 −.03621〜−.02928）、切断率差は+3.28ポイント
（+.99〜+6.15ポイント）。学習seedの不確実性や多数の探索比較の補正は含まない。

強いblurでも領域別lossは背景を改善するが、幾何の消失断面率が
25.22%→27.01%、ink不足が54.96%→56.87%へ増えた。
背景だけを見て成功とすることはできない。

## 白紙と判別器

白紙のstrength .5、denoise5回では、領域別lossの表示ink率は平均.126%、
現行lossは.212%。8条件中の最大表示画素数は521対895。
背景の汚れを減らす方向はここでも確認できるが、これを線画復元の成功とは扱わない。

判別器条件は、2kログのreal/fake平均sigmoidが.5207/.5159、lossが1.3836。
このbatchでは分離が小さい。判別器の更新回数2,000と全状態の有限値は確認済みで、
未更新ではない。この設定の2k結果から、判別器によるloss全般の無効性を結論しない。

## 継続と再開の確認

2kの全5条件で、G/optimizer/EMAと判別器/optimizerの更新回数と有限値を検証し、
推論用raw/EMAの全10重みがcheckpointとparameter単位で完全一致した。
全学習状態は通常の保持数制限とは別に `milestone-checkpoints/2000/` へhashを照合して保管した。

2k評価後、完全保護ケースのF1=`None`を継続判定の平均へ加算する集計バグで制御処理が停止した。
未定義のペアを除外し、左右不一致や全ケース未定義はエラーにする修正と3件の回帰テストを追加。
修正後の大幅崩壊判定は全条件で通過した。これは画質改善の判定ではない。

修正commitは `904d883a868da28a06ce6fe1bcbf5861e13ed30d`。
固定済みファイルの変更は制御スクリプトだけで、元の他127ファイルと全設定は不変。
学習・loss・評価計算は変更していない。元manifest/source archive、修正前後のscriptと
停止状態は `source-amendments/001-collapse-gate/` に保存し、manifestを明示的に更新した。
同じ2kの全状態から追加10kへ再開済み。

10kでも同じ傾向なら、背景抑制の係数だけを強める方針は採らない。
薄い芯の保持・線に沿う被覆を背景抑制と独立に扱う比較や、判別器の識別能力の検証が次の候補になる。
この中間結果に合わせた学習条件の変更は行わない。
