# DD: 入力の濃さと清書の線幅を切り離す比較

比較完了。2pxを最大筆幅とする清書スタイルは細線を濃くし、一部の灰色帯を減らした。
薄い入力の灰色、端点の毛羽、交点の不自然さは残り、製品採用には至らない。
元の教師幅に一致しないこと自体を失敗とは判定していない。

同一のDC source-only raw6000、16ch・15,809パラメータから各6,000更新。
originalは元幅の.8/1/1.2倍、canonicalは各画像の最大筆幅を2pxに揃えた候補を使う。
いずれも9位置候補から画像全体・全再帰段で一つを選ぶ。
経路、相対幅、入り抜きを保ち、白紙・黒・太い塗り対照は変更していない。
同一の512合成下描き、透明度・ぼかし・揺れの拡張、再帰1–6、各段loss、sqrt(batch)LR。
両条件の正規化を元の線量に揃え、両条件から入力線量のgeometry補助項を外した。
従ってgeometry除去単独の因果効果を示す比較ではない。

標準256例と6劣化×64例で9,216モデル出力を評価。標準8枚・劣化8枚を等倍確認した。
さらに事前宣言した512px複合図形8例、6段、全体/部分適用、float/uint8入力の128出力と
全6枚を確認した。表示の二値化・コントラスト補正はない。

- canonicalは細線・gap・taperを濃くし、old_train36の平行線の間の灰色を減らした。
  old_probe36も分離が明瞭になった。512pxのscene1/4/5にも濃さの改善がある。
- faintの細線はまだ灰色。soft/roughの平行線にも周辺の灰色が残る。
  512pxのscene1/5の長い曲線には灰色の側線が残り、scene7の交点近くに切れ目がある。
- new_probe30の交点と短い枝・端点は不安定。new_probe36の近接線は一本へ融合する。
  入力に本数の曖昧さがあるため、教師と本数が違うだけで清書失敗とは断定しない。
- faint/roughの黒対照は輪郭リングが残り、canonicalで内側の灰色が強くなる。
  一方base/dark/softの塗りはおおむね黒い。
- partialの保護画素は全条件で完全一致。保護側の灰色は入力そのものである。

共通の評価族として、元の27候補と2pxスタイル27候補を学習前に定義した。

これは量子化への安定性であり画質指標ではない。

入力の透明度も変わるため、これが曖昧さを増やす可能性がある。まだ原因とは確定していない。
