# ER: 固定したモデルの再帰深度1–6を比較する

EQのfresh18kでscene1の長いグレーの途切れは解消した。一方probe37の短い近接曲線、wide61/62の線片、scene7の弱い交差線の消失が残る。次の学習変更の前に、粗い段からの予測が誤りを増やすのか、最終段だけでも同じ誤りが生じるのかを切り分ける。

EQ最終rawのmerge/mixedと参照EI group6 raw18kを固定する。既知new_probe37/58/61/62（256px）とscene1/7（512px）、全域強度.5、float/uint8入力、深度1/2/3/4/5/6で計216出力を作る。成功例58とscene1も含める。既存と同じ入力/乱数キーを使い、probeのdepth3 floatとsceneのdepth6両精度、計24予測を保存済みEQと完全一致確認する。予約済み新規入力は使わない。

深度1はcoarse insertを零として最終段だけを実行し、深度を増やすとより粗い段から自己再帰する。学習済みパラメータ・入力前処理・最終出力のラスタライズは同じ。これは再帰全体を不要と証明する実験ではなく、これら既知例の深度依存を調べる診断である。Gaussian追加は従来どおり縮小後だが、モデルは追加Gaussianチャネルを使わないため、深度ごとの乱数分割差をノイズ耐性の結果とは呼ばない。

256pxは1例1入力精度につき6列の深度×3行のモデル、計8ページ。512pxは1例1モデル1精度につき3列×2行で深度1–6、計12ページ。合計20等倍ページをすべて見る。線の接続、濃さ、余分な平行線/点、既存改善の維持を判断する。隣接深度の全画像RMSは変化量の参考だけとし、画質順位や最適深度の選択に使わない。出力平均・閾値処理・contrast調整はしない。入力/モデル/コードのhash、有限値・範囲・モデル不変・終了コードを確認する。学習・製品変更・採用は行わない。
