# DO: 少数既知形状への学習可能性診断

DNでは清書ink正規化で太線の中央が濃くなったが、欠落・端の残骸・灰色側線が残った。
次はモデルを大きくする前に、同容量で既知の少数形状を描けるかを切り分ける。
製品候補の学習ではなく、training-onlyの診断である。

DN both raw18000から同じ重みを複製し、fixed/augmentedを各3,000更新。
Adam/EMAは新規、batch4、sqrt(batch)によるpeak1e-4、cosine最小1e-5、EMA .999。
16ch・3block・RF87・15,809パラメータ、Fourier縮小段情報、全解像度source正規化を維持する。
全段lossと深さ1–6の巡回を維持。linear Charbonnier+.25断面+.05範囲、全段で一つの許容候補を選ぶ。
分母は清書候補平均ink。容量・loss・初期値・学習率は群間で変えない。

既存の学習512形状からwide8・parallel4・crossing2・blank1・black1をインデックスで事前固定する。
選択は464,473,482,491,500,509,466,479,288,299,310,321,240,249,432,448。
両群の形状抽出はseed2026101404で同一。全域強度.5に限定する。

- fixed: 各形状の保存済み入力をそのまま繰り返す。
- augmented: DNと同じ25%base/75%透明度・ぼかし・滑らかな変位を変える。

差は入力の揺れだけ。候補・断面・正規化・強度・深さは同じ。
各形状は全6深さで学習することを事前のsampling-planで確認する。
Gaussianは各段縮小後に作るがsource-only構成では無視される。

最初6更新のmetricsを再現(atol1e-7/rtol1e-5)、全状態の再学習比較はatol5e-6/rtol1e-4。
0/6/1000/3000の完全状態を保存・復元し、
16 raw/EMA exportを照合する。CPUでバッチの差分が入力だけであることとbase一致を確認する。

評価は同じ16形状に対して保存済み入力/固定rough、全域/部分、深さ3/6。
initial/fixed/augmentedの384出力を保存し、深さ6の全条件16枚を等倍で確認する。
raw最終checkpointを固定して評価し、よい途中checkpointだけを選ばない。
固定roughは学習前に保存し、途中で差し替えない。これは未知形状の汎化確認ではない。
blank/black・交点を含め、灰色低下が線の消失によらないかを見る。
許容候補へのcostも記録するが、採用指標としてMSE最小化を復活させない。

fixedでのみ十分な線が描ければ入力の揺れとの整合を次に調べる。
両方で描ければ、広い形状集合での配分・競合が残る可能性を調べる。
どちらも描けなければ、この回数での不成功を容量不足の証明とせず、目的関数・勾配・描画表現を診断する。
いずれも少数例への適合を画質の汎化やKrita採用と主張しない。
DNの予約済み別seed512px16例は未使用のまま維持する。

## 再現照合の事前修正

最初の試行c0ec998は6更新の再学習照合で停止し、完了実験に数えない。
学習順を揃えた3回の独立再実行でも、augmentedのblock1 FiLM重みに最大2.615e-6の差を確認した。
