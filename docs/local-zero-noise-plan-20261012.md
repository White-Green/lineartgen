# CQ: 追加Gaussianなしの学習・推論を揃えた対照実験

CNではCM20000の推論だけGaussianを除くと粒状感が減ったが、濃度不足・肥大・誤接続は
残った。COの差分lossは小改善、CPの連続時刻学習は薄さが悪化した。今回はCNの分布外
介入だけでは答えられない、追加ノイズを除いて再学習した場合の復元性能を調べる。

CMの実際のraw20000/model/Adam/EMAから4,000更新し、完了したCO control24000と
比較する。両方が同じ16,000合成教師、source/mask、depthを同じ順で使う。
15,809パラメータ、batch4、2回自己rollout、最細段lossから全再帰への勾配を同一にする。
depthは3/4/5/6/1/2から循環。LRはbase5e-6×sqrt(4)=1e-5、minimum1e-5、warmup0。
optimizer countとmoment、EMAを引き継ぐ。データindex14000–17999、教師seed2026101111。
CO controlを再学習せず、その最初の6実更新を再計算して全状態一致を確認する。

変更点は学習・推論の初期状態を z=s+.25*t*Gaussian から z=s にすることだけ。
各解像度のsとtは従来どおり原画像・maskを先に縮小して作る。下描き劣化のblur、透明度、
重ね描き、部分編集maskは残す。画像loss・補助loss・2回rolloutの係数は変えない。
CPの教師補間経路・連続時刻学習・COの差分loss追加は使わない。
強度tは編集量の入力として残し、推論途中のremaining time uとは区別する。

これは決定論的復元の診断であり、最適輸送や多様な出力の学習を達成する実験ではない。
良い結果でも元のノイズ割り当て設計を置き換える根拠とせず、灰色・粒状感の原因切り分け
として解釈する。以前のU-Net低ノイズ実験BPとはモデル・loss・データが異なる。
CNの推論だけの変更とも区別する。学習更新数とデータを揃え、wall-clock同一とは主張しない。

CPUで教師・source・mask・元のGaussian入力hash一致、追加ノイズだけの除去、同じlossの
勾配、実更新・保存復元後の次更新、samplerの解析解と保護画素を検証する。
GPUでCMの76出力、E/R16出力に加え、CNのノイズなし76出力を完全再現する。
45batchの独立教師hash、全4,000batchのCO入力hash、実6更新再現、全保存復元を確認する。
保存20000/20006/22000/24000、8raw/EMA exports。最終raw24000のみ評価し、
中間checkpoint・EMA選別はしない。

2回（主）/32回（副）各1,566条件でE/R/CO control/CQを評価し、計12,528行。

同時に確認する。alpha<.1除去はしない。有限値と保護画素完全一致を必要とする。
