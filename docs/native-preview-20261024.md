# 線幅と筆圧を保つKrita試用版

runtime 0.4.0は、累計152,400更新の最終EMAを同梱する。
最後の6,000更新と保存重みの検証が完了したモデルを、Kritaで実際に試すための版。
Windows x64 / Python 3.13。Strength 0.5、Lineart passes 3を開始設定とする。
薄い細線、密集した輪郭、細線の強弱には課題が残る。

## 前の試用版からの変更

旧100,200更新版は主に約2pxに揃えた合成教師を使っていた。
今回は元画像891枚と1/2/4/8/16/32倍のデータ、幅が変化する合成曲線、
近接した太線と細線を学習している。描画時の旧8px線幅上限も外した。
最終段階では形状側を固定し、独立した幅CNNを6,000更新した。
45,846パラメータ、形状と幅の各CNNは22,923パラメータ。
累計更新数には親モデル・過去の構造と目的による学習を含む。
現在の構造を最初から152,400更新したという意味ではなく、収束の証明でもない。

下描きの局所正規化、描き途中の線画のcoverage、元の下描きの濃度を別々に渡す。
元の濃度の対数変換は各解像度への平均縮小の後にONNX内で行う。
再帰には形状の占有だけを渡し、幅は次段へ混ぜない。
不透明な可変幅線分を描き、線の縁にはアンチエイリアスが残る。
Kritaのレイヤー形式、BGRA入出力、Strength、Lineart passes、保護領域は従来どおり。
推論にJAXは同梱せず、6個のONNXとNumPyを使う。

## 選んだ重み

`native-width-calibration-20261023`のcontrol最終EMA。
SHA256: `34bf1c87a61cab5cece9b4168c562686be8dd28f5401d8e656dc95d8ff0a29fb`。
1,200更新だけの最新濃度ペアpilotや、描画幅lossを強めたrender16は選んでいない。
直近の比較で追加手法を不採用とした判断と、学習済み対照モデルを実利用で試す判断は区別する。
このモデルが研究上の全候補で最良、あるいは品質目標を達成したとは主張しない。
独立validation24元画像・final64元画像は、この試用版の選択に使っていない。

既使用の部分編集15条件で、最大線幅1.5/6/24pxごとの描画幅相対誤差は、
旧配布版.518/.425/.466に対し、今回.245/.200/.017。
幅の強弱と見た目も確認しており、画素MSEでの選択ではない。
細線の筆圧gain平均は.728で、理想の1より低く、強弱が圧縮される問題は残る。

濃度を変えると出力幅も変わる場合、細線が太る場合、真の切れ目が狭まる場合がある。

配布CIでhead・描画・実BGRA・保護領域を照合する。
