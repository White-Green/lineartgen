# EH: 初期値・学習率を修正した小型モデルの既知開発入力への転移

EFの16形状適合は+1/peakLR1e-3で大きく改善したが、rough近接曲線8の切れは残る。EGは同じ改善条件で通常16ch、group2、group6を各6,000更新する。この評価計画はEG学習中、出力を見る前に固定する。

EGのraw6000全3群とEF near_fast raw3000（履歴参照）を、DQで既に使った24開発入力（256px多様16形状、512px複合8場面）に適用する。新規形状を生成しない。単純形状への適合が広い入力でも維持されるかを評価する。参考のopaque geometryは一つの許容解として表示し、画素MSEで選ばない。綺麗な線の融合や端の閉じ方は許容する。

whole/partial.5、depth3/6、float/uint8往復、seed2026101439。全モデルとencodingで同じ入力・Gaussianを使う。768出力、指定32等倍ページをすべて確認する。256pxは4ケース/ページ、512pxは2ケース/ページ。列は入力、許容geometry、EF履歴、EG通常、EGgroup2、EGgroup6。途中checkpointや良い方向の選択はしない。

有限値・範囲・保護領域完全一致・モデル状態の不変・入力と重みのハッシュを検証。量子化感度を記録するが、元からuint8の512入力で差が0になることを新たな頑健性の証拠にしない。既存scene1の大きい斜線の切れとscene7の大きい縦・左上の切れは意図的。新しい局所欠落は別に評価する。

線の濃さ・滑らかさ・連続性、太さ、余分な灰色帯・断片・塗り穴を判定する。partialはこれらの16形状モデルでは未学習条件であり、wholeと分けて解釈する。汎化の主張や採用には、より広い学習と予約済み新規入力での確認が必要。reserved fresh、製品、Kritaは変更しない。

数値処理は検証済みgeometry inferenceと入力準備を再使用する。新規数値実装はなく、Ruffと実行時の全出力・artifact検証を使用する。
