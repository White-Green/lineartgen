# GZ: 少数例の反復と通常線・塗りの混合

GXの12学習例は1200更新で一本化したが、GW/GYの広い学習では十字が残る。GXと同じ12例・同じ1200バッチを再訪し、その各更新の後に通常線・塗りの1バッチを追加する。少数例の成功が混合学習の中でも成立するかを調べる限定診断であり、汎化の証明や本番候補の選択ではない。

初期値はGX/GW未変更21890パラメータ。適合済み重みは使わない。全2400更新はfocusとbackgroundの交互。focus1200はGXの全バッチを順番・教師・ノイズ・context dropoutまでdigest照合する。background1200はGWの先頭からambiguous家族を除いた1200バッチで、各入力・候補をGW記録と照合する。focusとbackgroundはそれぞれ全6段均等。focusではGX consistent objective、backgroundではGY consistent objectiveを用いる。開口項0、geometry.1、各段loss正規化を維持する。

B4、sqrt(batch)によるpeak2e-4、cosine2400から2e-5、warmup0、clip1、EMA.999。一つのoptimizerを共有し、focusの更新2iのLRはGXの更新iと同じ（atol2e-11/rtol1e-6を事前指定）。background更新でoptimizer履歴も変わる。したがってこれは反復回数とfocusのLRを揃えた混合可否の診断であり、総計算量を揃えた比較ではない。追加学習の順序・optimizerへの作用を別々に同定する試験でもない。

保存0/36/600/1200/1800/2400、raw/EMA12個と全状態。新条件自身の36更新・全状態と保存復元は完全一致。過去GX先頭18更新の指標はatol1e-6/rtol2e-5を指定し、失敗は記録する。比較画像は保存済みGX/GYをそのまま用い、再計算を繰り返してビット一致する出力を選ばない。GYの厳密参照検証不合格も参照記録に明記し、GYを検証合格した実験とは扱わない。

最終raw2400のみ品質評価。GX学習12・転移8・アンカー4を深さ1/3/6で評価し、深さ1/6の12原寸ページをすべて見る。GK8・GO2も深さ1/3/6で評価し、深さ1/6の6ページを見る。既存512pxシーン8例は全体/部分・float/uint8で評価し、全体8ページと部分1/3/5/7の4ページを確認する。新出力134、保存対照190、原寸計30ページ。通常線・塗り・意図した隙間・部分保護も同時に判定する。Gaussian値を使わないモデルなのでscene乱数の差は頑健性の主張に使わない。

教師はGXの確認済み5ページと既存GWの通常線・塗りを再利用し、新しい合成レシピは追加しない。focus学習例の一本化が残り、塗りと通常線も保てれば、混合下でもこの表現で適合可能と判断する。focus例が再び十字になる等なら混合干渉が疑われるが、容量不足は断定しない。転移例や大幅に太い入力の失敗は別に報告し、学習例への適合を一般化能力と混同しない。画像MSEは採否に使用しない。fresh16、Krita、本番exportは変更しない。
