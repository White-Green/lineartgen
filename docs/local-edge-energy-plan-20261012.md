# CO: 小型CNNの合成学習に画素差分の監督を加える

CMの2回推論には粒状の濃淡と薄い太線内部が残った。CNでは入力Gaussianを
取り除くと粒状感が減ったが、濃度不足や線幅は改善しきれず、ノイズを段間で共有する
だけではほとんど変わらなかった。今回は学習・推論のノイズは従来のままにする。

CM raw20000の実際のmodel/Adam/EMAからcontrolとedgeの2群を分岐し、
それぞれ4,000更新、最終24000まで学習する。15,809パラメータのlocal CNN、
2回rollout、全再帰への勾配、最細段loss、教師生成・劣化・mask分布を揃える。
BL/CL/CMに続くdata index14000–17999、16,000枚の合成教師を両群に同じ順で入力する。
教師乱数seed2026101111、Gaussian生成seed2026101093を維持する。
開始depthは3/4/5/6/1/2、以後同じ周期。原画像を縮小してからノイズを加える。

学習率はCM末尾の1e-5を両群で維持する。base5e-6×sqrt(batch4)=1e-5、
warmup0、minimum1e-5。optimizer count20000、Adam moment、EMAをリセットしない。
保存状態20000/20006/22000/24000、16raw/EMA exports。最終raw24000のみ評価し、
中間画像やEMAによる選別はしない。

controlはCMのlossをそのまま使う。edgeは既存のedge_energy_weightだけを0→1にする。
rolloutのimage loss全体に.1が掛かるため、追加の実係数は **0.1**。
追加項は2段目のclip前予測の濃度残差の隣接画素差を二乗し、教師の差分エネルギーで
正規化したもの。AA境界値を教師どおりに保ち、完全白・黒への正しい飽和には罰を与えず、
保護画素をまたぐ差分は使わない。定数残差はこの項だけでは直せないため既存lossを残す。
以前のAS（U-Net、固定少数ペア）では採用に至らなかったlossの、別モデル・広い合成分布
での対照実験である。新しい未試験のlossという位置づけではない。

数値実験前に45batchの教師を独立生成してハッシュを固定する。CPUで既存controlの
勾配完全一致、追加係数、両群の実更新と復元後の次更新を検証する。GPUでは初期の全状態、
CMの76パネルとE/R16出力、実6更新の全状態と指標の再現、全保存復元を確認する。

2回（主）/32回（副）各1,566開発条件でE/R/CM/control/edgeの5モデルを評価する。
合計15,660指標行。各回数CM/control/edgeに既存229基準を適用し、緩和しない。
E/R/CMの4,698行と114パネルを各回数で完全再現する。各6枚のraw比較画像を確認し、
粒状感の減少と、細線の消失、太線の肥大、切れ・誤接続を同時に見る。
alpha<.1の表示除去は使わない。finiteと保護画素完全一致を必要とする。
独立学習seed・封印確認・実BGRA/ONNX/Krita評価ではなく、配布設定を変更しない。
