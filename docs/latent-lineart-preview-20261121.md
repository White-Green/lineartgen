# 潜在拡散でラフを清書するKrita試用版

手描きのラフにある重ね書きから、画面の離れた場所の接続先を根拠に必要な線を選ぶ試用版。以下は実際の配布モデルによる合成ラフの結果。人が描いたラフでの評価はこれから行う。

Windows x64でPython 3.13を内蔵するKritaが対象。プラグインZIPをPythonプラグインインポーターで読み込み、Kritaを再起動する。下描きはカラーラベル1、描き途中の線画は2。最初はStrength 0.5、Lineart passes 6、Seed 0で試す。遠方の接続先だけ変えた場合と、候補の片方を少しなぞった場合を見比べると、二種類の入力がどこに効くか分かる。[試用版のビルド](https://github.com/White-Green/diffusion_drawing/actions?query=branch%3Arewrite%2Flatent-lineart-preview-20261121)

## 既存線画を空にした比較

比較対象は11月17日のKrita配布モデル。倍率違いを含む各72組は独立した24形状から作った。対成功には、同じ中央部を持つ二枚のラフの両方で正しい経路が一続きに90%以上残り、不要な経路の残存が20%以下であることが必要。いずれも固定seedの最初の一枚を採点した。

| 未見の合成ラフ | 両方で正しい経路を選んだ組、旧→今回 | 二本とも必要な場合の保持、旧→今回 |
|---|---:|---:|
| 遠方に手掛かりがある | 35 → **53** / 72 | 58 → **70** / 72 |
| 細部の分岐・交差 | 2 → 5 / 72 | 23 → 37 / 72 |
| 曲線の変形・交差が重なる | 17 → **28** / 72 | 31 → **25** / 72 |

遠方の対成功の差は+25ポイント（形状単位の対応付き95%区間 +9.7〜+38.9）。遠方課題で輪郭外に出たインクの量は正解線の0.086倍から0.166倍に増えた。細部の分岐では正解の経路を選び切れない例が多く、曲線が重なる条件には細い二本のうち一本を消す退行がある。下の画像は先頭の形状を固定し、左からラフ、旧版、今回、正解。行は必要な線が一方、もう一方、両方の場合を表す。[遠方の選択](latent-preview-20261121/context-000-1.png)・[細部の分岐](latent-preview-20261121/precision-000-0.5.png)・[変形と交差](latent-preview-20261121/transfer-000-0.5.png)

元画像を分割して取り置いた64枚に部分的ななぞり直しを加え、保存済みの1/2/4/8/16/32倍の画像を各々の原寸で評価した。1倍で迷い線の残存は80%→66%、白地で濃度0.1以上の汚れは9.3%→1.9%、細線の相対幅誤差は1.00→0.23。一方、正解線に濃度0.5以上のインクが載る割合は95%→72%。2倍の迷い線は80%→63%、8倍では45%→49%だった。薄い必要線が消えることがあり、全倍率での解像度非依存は確認できていない。

下描きの一部を完全に消すと、両端の接続と濃度を回復できたのは今回1/24、旧版0/24。線幅と余分なインクの基準も加えると両方0/24。手掛かりが等しい二択で、追加の一筆がなくても一方だけをきれいに仕上げたのは今回0/32、旧版1/32。改善は主に、観測できる線から意図を選ぶ場面で得られた。

## 既存線画を描き足した比較

同じ曖昧な二本のうち、ユーザーが片方だけを短くなぞる未見試験を行った。筆を反対側に移すと出力も正しく切り替わった組は、前段の生成案と既存線画をそのまま合成する場合の **0/24から14/24** に増えた。線に沿った既存の筆跡から得る特徴を無効にすると0/24だった。意図しない線の残存は平均95%→15%。1倍は11/12、0.5倍は3/12で、細く密集した線にはまだ弱い。図は左から一筆を重ねたラフ、固定合成、今回の後段あり、正解。同じ形状に逆の一筆を加えた二行を原寸で比較できる。[0.5倍の出力](latent-preview-20261121/painted-0.png)・[1倍の出力](latent-preview-20261121/painted-1.png)

取り置いた64元画像×保存済み6倍率×3種類の編集では、描き足した線の近くで接続が続いた正解画素は72.7%→98.9%。正解線近傍のインク量は正解の0.54倍→0.99倍。編集境界の白地に濃度0.12を超す余分なインクが残った割合は1.6%→2.6%に増えた。正しい閉路の片側をなぞった場合、離れた必要線の被覆率は99.3%→100.0%。一方、二本とも必要な分岐では、編集後に両方を一続きに保てた例が固定合成25/72→後段あり14/72、遠方の課題でも47/72→41/72。一本を選ぶ操作が、残してほしい側にも影響する例がある。

合計1,656件の編集で、保護を指定した223,647画素の不一致は0。黒・白・色付きの不透明画素、半透明を一度だけ合成する挙動を別途テストした。533×1,025のキャンバスで、部分的に保護した線がタイル境界をまたぐ場合のBGRAは全画面推論と完全一致した。JAX参照と配布用CPU推論は空間再帰1〜6段でアルファ最大1/255差だった。[測定値・凍結記録](latent-preview-20261121/confirmation.json)

## 学習と配布

元画像1,019枚を訓練891・開発64・最終64に分けた。保存済み各倍率の清書を等確率で選び、なぞり直しやぼかしは下描き側に加えた。倍率間の手製の一致損失は使っていない。採用VAEは1チャンネル入出力、一辺8倍圧縮・潜在32ch。16倍・32倍圧縮も学習して、近接二線と筆圧の復元、実際の条件付き清書を比較した。

VAEを10,000更新、清書の拡散事前学習を3,000更新、ラフ条件付きを6,000更新し、欠損を含む条件付き生成器をさらに30,000更新まで比較して20,000更新の重みを選んだ。空間再帰は1〜6段、各段に損失を置き、学習率はバッチ数の平方根に比例させた。モデルは各解像度へ縮小した後でノイズを加える。潜在CNNが出した案と、ラフから推定した線の採否・筆圧を合わせて復号する。線を選ぶ能力には、画面全体のつながりを参照する分類器も寄与する。最終読み出しは実際の生成軌跡で18,000更新した。

原寸の後段は、凍結した前段の実出力480枚から取った9,600箇所で12,000更新し、描き足した線に基づく経路の採否をさらに8,000更新した。ラフをたどった距離、二本の間の白地、両端が続くかを使い、筆と同じ白地を挟む反対側の候補を抑える。既存線の輝度とアルファを最後に原寸で一度合成する。[配布モデルと元の重みのSHA-256](../packages/lineartgen-runtime/src/lineartgen_runtime/assets/krita-latent.json)
