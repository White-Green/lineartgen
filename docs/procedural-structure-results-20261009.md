# 新規形状を毎更新生成した構造損失比較の結果

4,000更新を完了し、region / structure とも採用しない。灰色のにじみは
減ったが、細線の濃度・連続性を保つ条件を満たさなかった。全8枚の最終
等倍シートを確認した。強度0.1でも細線が薄く、0.5では太い灰色の帯が残る。
白紙に微細な架空の輪郭も見える。これは線画復元として十分な品質ではない。

| 指標 | pixel | region | structure |
| --- | ---: | ---: | ---: |
| TRAIN blur 平均halo | .073361 | .056084 | .056397 |
| PROBE blur 平均halo | .059425 | .044798 | .046010 |
| PROBE blur / 全体 / 強度.5 F1 | .739202 | .746233 | .741001 |
| 同条件 ink deficit | .214910 | .241915 | .248068 |
| PROBE細線 cut rate (8 draws) | .562500 | .687500 | .875000 |
| 固定比較基準の失敗数 | 対照 | 15 | 17 |

regionのhalo低減はTRAIN23.55%、PROBE24.61%。しかし主な問題は消えず、
細線の切断が増えた。structureの追加queryでgap中央濃度はregion比で
TRAIN26.87%低下、PROBE19.85%低下。後者は25%の基準を満たさず、切断も
増えるため接続損失の成功とは扱わない。4ケース×8ノイズのfitting基準は
全3モデルでTRAIN0/32、PROBE0/32。平均指標改善だけでは成功にしない。

毎更新4枚、計16,000例の新しい幾何形状を生成した共有モデル比較。
130,605パラメータ、再帰1–6、段loss0、sqrt(batch)学習率、縮小後ノイズ、
初期モデル・augmentation・乱数列を揃えた。TRAIN/PROBEという表示は既存の
開発評価セットの名称で、今回のオンライン生成学習の固定4例ではない。
損失以外を共通にした3arm比較から、region/connectionのこの係数では
にじみと細線保持を両立できないと分かる。容量不足の証明ではない。

57ペア×2split×2強度×全体/部分×3モデル=1,368条件を評価し、保護領域の
最大差は0。4ケース/8draw評価192条件は別途保存。初期出力の一致、6更新
完全再実行、1,000/4,000の全状態復元、両段階のraw/EMA計12exportとcheckpoint
の一致を確認。固定ソースも一致。中間1,000ではPROBE blur.5の1枚のみ目視
しており、最終8枚の目視と区別する。
