# EE: 小型D4モデルの新規学習はまだ適合不足

通常16ch（16,064重み）、D4の2×8特徴（2,022重み）、6×8特徴（16,402重み）を同じ既知16形状・D4/rough拡張で各6,000更新した。全6段の初期画像は一致。再実行、全状態復元、24 raw/EMA export、入力・教師・Gaussianの全更新一致を確認。CPUの独立7テストとGPU等変性4テストが通過した。512出力を保存し、指定16等倍ページをすべて確認した。

3群とも品質基準を満たさない。通常CNNは太い灰色帯・枠・二重線、group2は大幅な線の消失、group6は薄い二重線や断片を作る。近接曲線は灰色帯や欠落になり、交差線も切れる。黒塗りは通常CNNで白い格子状の穴、group2でほぼ消失、group6で灰色の枠になる。blankは維持。partialではマスク境界に黒い塊が出るが、この少数例試験ではpartialを学習していない。wholeにも同様に十分な失敗がある。

ECの履歴参照は多くの入力で強い中心線を残すが、事前学習量とデータが異なるため群間の因果比較には使えない。等変性の成立は線画品質の成功を意味しない。今回の結果からgroup2の表現力不足やgroup convolution自体の不適合を断定しない。

最後600更新の平均更新時間は通常0.1313秒、group2 0.1218秒、group6 0.2028秒（入力準備・保存を除く）。全学習3417.8秒、評価13.1秒。各形状×段数の提示数は201–296。パラメータ変化RMSは0.02395 / 0.02643 / 0.01443。全群でlossは下がったが、最後300更新のgeometry-gradient項は約0.45–0.47に残り、画像は依然灰色・欠落を含む。loss低下を採用条件にしない。

次は新規学習の最適化を切り分ける。現在の初期fieldは+8だが、遠い背景へのcensored制約は+1で満たせる。同じ初期白画像を保った+1初期値と、現在の10倍の学習率を因子として比較する。構造・lossを同時に変えず、既知少数例への適合を先に確認する。reserved fresh、製品モデル、Kritaは変更しない。
