# 現在のone-passでの段情報（検討のみ）

DIの学習条件は変更していない。以下はコードを読んだうえでの次候補で、未実装・未学習。

現在のsource-only one-passでは、各段のprogressはすべて1。
既存の9成分Fourier FiLMはtau=1-progressを使うため、全段でtau=0、sin=0、cos=1になっている。
パラメータは学習されるが、この入力から縮小段を区別することはできない。
一方、2pxスタイルの教師の正当な被覆率は、各段で縮小されて変わる。
入力濃度の違いだけから段や期待する被覆率が常に分かるとは限らない。ただし、これが
実際の灰色領域の原因だと確定したわけではない。

DEは128パラメータを追加したscalar FiLMを既存モデルへ6,000更新し、画質改善がなかった。
別案として、one-passで一定になっている既存の9成分を、tau=physical_level/5で使う余地がある。
最細段は従来どおりtau=0となり、他段ではsin/cos成分も変わる。追加パラメータは必要ない。
新しい初期値で学ぶ場合、DEのscalar追加変調とは学習条件も入力表現も異なる。
そのためDEの失敗だけで有効性は決まらないが、成功も仮定しない。

採用するなら同一初期値・入力・loss・予算の対照と、各段の保護・NumPy/JAX一致を確認する。
段を明示しても端点・交点の連続性を保証するわけではなく、実画像の比較が必要。
