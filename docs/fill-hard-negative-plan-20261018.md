# fill陰性上位lossの比較学習（IG）

IFの重み固定診断で80/87.5pxの枠と62pxの小片は最終fill描画に由来した。無条件のfill除去は正しい塗りを消すため不採用。現行lossの誤陽性勾配は存在するが、陰性上位1%平均で約11.4倍になる例を確認した。次に学習で誤塗りを抑えつつ塗りを保持できるか検証する。

両群の初期重みはIE expanded raw3000、同じ22,725パラメータ。controlは従来の陽性/陰性別平均fill BCE、hardnegativeは陰性上位1%の平均に変更し陽性平均を維持。頂点/辺のcount BCE、位置/幅Huberは完全に同じ。画像MSEは加えない。optimizerとEMAは新規初期化。

各1200更新、B4、再帰段数1–6を各200更新、全段lossの重み0.5^levelを正規化。base LR 1e-4にsqrt(4)を適用してピーク2e-4、cosineで2e-5まで低下、勾配clip 1。旧512例とIE追加1024例の25%混合を両群に同じ順序で与え、入力・教師のハッシュを毎更新照合する。データseed2026101816、D4・追加blur sigma0–1・opacity0.65–1・部分処理25%を維持。

実行前6更新（全深さ）を二重実行して同一デバイスの全状態を比較。学習の最初の6更新も事前比較とatol/rtol各1e-5で照合し非完全一致は記録する。0/6/300/600/1200更新でoptimizer/EMAを含む保存復元とraw/EMA重み復元を完全一致確認する。既存のIE教師12画像は同じファイル・教師なのでハッシュを照合して所見を継承し、新規目視と数えない。

最終raw1200で標準166条件・広範囲2360条件を評価し、標準31枚・広範囲57枚を等倍確認する。比較画像の初期値はIE expanded。さらに学習入力25/512/769/896をd1/3/6で両群評価する24条件・4枚も事前指定する。太い枠/小片が減り、通常線・塗り・部分適用・明示的な隙間が保持されるかを判定する。近接線の粗さや中間幅ループも記録するが、fillだけによる解決は期待しない。評価データは既知例であり独立評価ではない。品質基準を満たすまでDN独立確認用データは使用せず、Krita/本番重みも変更しない。
