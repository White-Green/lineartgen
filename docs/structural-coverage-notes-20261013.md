# 端点・交点の学習位置についての観察（未実装）

DIの学習条件は変更していない。次の改善を選ぶためのコード/既存データの読み取りのみ。

現在の経路断面は、各pathの弧長5%から95%の17点で測る。
合成junction/crossingは複数のpathの始点0%が共通の接合点なので、接合点そのものを
中心とする断面は明示的に置いていない。元配置で接合点に最も近い断面中心までの距離は、
old_train24で約1.00px、old_train30で約2.24px、new_probe30で約2.81pxだった。

これだけで交点の切れの原因とは断定できない。画像全体のfamily lossは交点も含み、
横断面の補間や許容する位置ずれによって接合点付近に勾配が入ることもある。
ただし、小さな接合部の不具合が長い線全体の平均に埋もれる可能性は残る。

DI後にも接合部が問題なら、真の端点・接合点・近接path間を中心とした局所領域を
明示的に評価するlossが候補になる。許容する全位置候補を領域内に含め、画像全体で一つの
清書候補を選ぶ原則は保つ。元教師に位置を固定する必要はない。
別途実装・事前計画・比較学習が必要であり、この観察だけで改善を確認したとは扱わない。
