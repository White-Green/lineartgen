# ぼかし・透明度と線幅の識別可能性の補助診断

4,983通りの人工的な水平線・blur・透明度の組を、既存のblur関数と実BGRA検証と同じ8bit丸めで調べた。**異なるclean線幅から、512×512全画素が完全に同じ8bit入力になる組が1つ見つかった。**

| | 元の描画線幅 | blur sigma | 不透明度倍率 |
| --- | ---: | ---: | ---: |
| A | 0.75px | 1.5 | .515 |
| B | 1.5px | 1.5 | .295 |

元の教師画像は異なる（正規化値の最大差.900784）が、量子化入力のSHA256は同じで、配列全体の厳密一致も確認した。4倍描画→Lanczos縮小、image_scale1.1、既存gaussian_blurを使用。全幅の水平線だけを使う限定的な診断であり、実線画全体の性能限界を推定したものではない。量子化前の連続値入力が同一とは主張しない。

この組に限れば、追加情報がない決定的モデルで両方の教師へ正しく復元することはできない。等確率ならMSEの最小期待値は教師間MSEの1/4=.000476488で、画素ごとの平均が最適になる。実データでの確率や誤差下限は未測定。選んだグリッドで一組見つかったことから頻度を推定してはいけない。

[実際の等倍比較](../runs/source-mixture-training-20261009/ambiguity/collision-reviewed-native.png)を確認した。0.75pxの教師にあるグレーは正当なアンチエイリアスであり、これを周辺のにじみと同一視しない。この結果だけでは、学習出力のにじみの原因が特定されたことにもならない。

今後のloss設計では、元線画との一致と、許容できるAAを持つ滑らかな線・一貫した幅であることを別に評価する必要がある。復元不能な情報をlossだけで回復できるとは考えない。今回の実行中のblur/mixed比較の学習条件・品質ゲートは変更していない。
