# 大目標への関係：清書候補をそのままKritaへ渡すための準備

このブランチは曲線モデルの推論実装だけを準備する。新モデル資産はまだ採用・同梱していない。
既存配布のgraph資産は維持し、curve-model.jsonを明示した場合に曲線モデルを選択する。
デフォルトも将来そのmanifestを同梱した場合だけ曲線へ切り替わる。

Kritaの既存BGRA API、透明度0の編集、保護された白/黒、strength0を保つ。JAX/Flaxを
runtimeへ持ち込まない。元画像を縮小せず256px入力を使い、256pxを超える辺は128pxの
中央領域を採用する。正規化は全canvasで一度だけ行い、縮小した各階層に独立Gaussianを
加える。重なるtileの入力・ノイズは同一。出力の重なりを透明度で平均しない。
NumPyの乱数列はJAXと異なる。同じGaussian分布だが、実モデルでの品質照合が別途必要。

幅の位置と形状の位置を統合し、可変幅のdisc sweepとして不透明な線を描画する。
旧graphの近似カプセルではなく、研究版と同じ式。太さを定数に置換しない。
manifestは深さごとのONNXとsha256、入出力shape、前処理・描画方式を明示する。
現在は検証用の一部深さも表せるが、配布までにはUIで選択可能な1〜6段を揃える。

9件の契約テストは、縮小後ノイズの分散、重複tile入力の一致、可変幅、不透明な中心、
既存BGRA、strength0、部分保護、非正方形、合成直線を使った境界、入力検証を確認した。
直線のONNX fixtureはテスト用定数であり、学習済みモデルの清書や境界品質を証明しない。
本物の未知形状での品質、太い拡大線、曲がった線が跨ぐ境界、DirectML、CI artifactと
Krita GUIは未確認。研究候補がcopy以上に有用な段階で実際の重みと接続して検証する。

既存graph runtimeの17件も通過し、現在の配布資産のdispatch・前処理・描画を維持している。
