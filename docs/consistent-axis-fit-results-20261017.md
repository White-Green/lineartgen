# GX: 許容軸を一貫して選ぶ小規模比較

同じ21890パラメータ・同じ初期値・同じ12学習例で、許容される一本線の方向を一貫させると、48px正方形4例の余分な直交線が消えた。ただし未学習の太さ・角度への転移は不十分であり、採用しない。

条件はeaa3dea固定。どちらもGWの未変更の初期choice重みから開始し、1200更新、全6段、各段loss、sqrt(batch)を維持した。18候補のfield costと正規化は同一。winnerは全候補から最小costを選び、consistentは水平に近い許容軸の9位置候補に絞る。45度の同率では画像座標で正の傾きを選ぶ。方向への好みを明示した方針であり、回転不変性や確率的サンプルではない。

学習12例・転移8例の教師5枚、最終raw1200の学習・転移・4アンカーの出力12枚を、拡大縮小や閾値処理なしで実際に確認した。深さ1/3/6の216出力を保存したが、画像確認は事前固定した深さ1/6である。

- 学習例ではconsistentが12例すべてで一本の暗い連続線になった。72pxの一部に太さの小さな不均一はある。winnerの48pxの4例には薄い直交片が残る。
- 転移例では両者とも途切れ・小片・塊が多い。consistentの40pxの1例は連続するが波打つ。64px群は解決しない。
- 未学習の正方形48はconsistentで一本化したが、短く太いprobe62×2は断片のまま。今回の適合データに含まれない長い62px線と192px塗りは大きく悪化した。
- どちらの条件でも、同じ例・深さを再訪したときの軸切替は4728機会中0回だった。したがって「時間方向に正解が揺れるのを防いだから改善した」とは説明できない。近い例の間で方向を共通にする効果は候補だが、因果は確定していない。

画像確認前に固定した記述的な判定は「どちらか一つの軸の中央90%でalpha0.8到達率95%以上、3px支持領域外のインク量が教師インクの5%以下」。滑らかさ・太さ・端を保証しないため採用基準ではない。
