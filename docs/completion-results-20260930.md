# 小型モデル実験の最終結果（2026-09-30）

予定した比較を完了した。共同S/M/L・独立S・元Burnと同じ大きさの基準UNetを、
3組の初期化／データseedで各100,000更新まで学習し、開発用評価、選定固定後の
未使用final test、匿名画像確認、推論・ONNX・保存結果の監査を実施した。
基準UNetも含め、事前の品質条件を全て満たした候補はない。**採用モデルなし、最小十分サイズは未確定**。
10万更新は事前の上限であり、収束や実用品質の達成を意味しない。

小型化の可能性は残る。17,893パラメータの共同Lは一部の復元指標で126,765の基準に近い。
しかし、全サイズに薄い細線の欠落・誤接続・線幅の変化が残り、滑らかさや背景の除去には
基準モデルの優位も見られた。容量だけを原因にする結果でも、5,933で十分とする結果でもない。

全数値・seed別結果・対応区間・速度・匿名観察を
[集計JSON](benchmarks/completion-results-20260930.json)に保存した。
実行条件・途中結果は[実行記録](completion-campaign-20260919.md)、
以前の学習法比較は[実験計画と履歴](small-model-experiment-plan.md)を参照。

## 比較条件

S/M/Lのchannelsは`[4,6,8]`／`[6,8,12]`／`[8,12,16]`、各block 2 conv。
基準は`[4,10,20,40]`、3 convの通常UNet。**今回の全モデルはJAXで学習した**。
基準はBurn由来の構造・サイズを使った対照であり、今回Burnの学習を再実行したものではない。
独立Sと共同Sの初期重みを揃え、各seed内の3学習runに同じ入力・強度・mask・生成線画系列を与えた。

合成strokes下描き50%、幾何線画20%、独立Gaussian、一様強度とmask、補助lossなし。
元データはtrain891／development64／final64を元画像単位で分離。
FP32、512px、microbatch4×蓄積4、LRは`1e-4×sqrt(16)=4e-4`。
学習再帰1〜6段、段ごとのlossの既存式と係数0、再帰を通る勾配を維持した。
主評価は縮小後のノイズ付加、runtime再帰3段、denoise1回、EMA。
rawは感度確認として全て評価し、都合の良い重み種別への切り替えは行っていない。

### 白紙・低inkの影響

finalは64元画像から無作為位置のcropを保持し、うち22枚が全体ink比率.001未満だった。
実線画の各256編集条件では、編集領域にinkがある160例と低inkの96例に分かれる。
開発用とは元画像・crop・条件の構成が異なるため、両集合のF1差をそのまま過学習量としない。

finalの強いstrokesを分けると、次のようになる。これは記述用で、採否規則の変更ではない。

| モデル | 全例F1 | inkありF1 | 低ink F1 |
| --- | ---: | ---: | ---: |
| 共同S | .6153 | .6915 | .4884 |
| 共同L | .6447 | .7029 | .5476 |
| 独立S | .6257 | .6956 | .5091 |
| 基準UNet | .7255 | .7012 | .7662 |

基準の全例平均の優位には、低ink入力の不要な線を抑える効果が大きく寄与する。
inkありのblurでもL .6920、基準 .6903と近い。一方、線が存在する例だけでも
目安の.80に届いていない。白紙のF1は微小な残留inkで大きく変わるため、
背景MAE・観察画像も併用する。集計JSONには全例／inkあり／低inkのF1・MAE・背景MAEを併記した。

### 共同学習と独立学習、学習量

同じ5,933パラメータの独立Sは共同SよりF1・幅誤差で少し良く、共同Sは強い幾何入力の
切断・誤接続で良い傾向がある。finalのF1は独立S .5120対共同S .5097、切断は28.37%対27.73%。
独立Sでも品質条件を通らず、共有学習だけを失敗原因とする証拠はない。
入れ子Sは大きいサイズの出力を使わないが、共同学習では大サイズのlossも共有重みを更新する。

seed42の60k→100kでは全モデルの幾何F1改善が.01未満だったが、切断や消失には
継続判定の閾値を上回る改善も残った。基準の誤接続は72.92%→79.17%に悪化し、
実線画由来strokesのF1も.8210→.7968に低下した。長く学習すれば全指標が改善するわけではない。
100kで収束したとは断定せず、事前の上限で比較を終えた。

rawに切り替えた場合のfinal幾何strokes F1の平均変化は、小型4候補で+.0003〜+.0008、
基準で−.0028程度。raw/EMAの選択だけで今回の大きな品質不足が解消する結果ではない。

## 速度と利用形式

Radeon 8060S、ROCm 7.2.1、JAX 0.11.1、FP32。
保存済みseed42 EMAを使う512×512、runtime3段、denoise1回のJAX推論。
初回を分離し、続く30回の中央値。入力準備・画像読み込み・Krita通信は含めない。

| モデル | パラメータ数 | 推論中央値 | 初回呼び出し |
| --- | ---: | ---: | ---: |
| 切り出した共同S | 5,933 | 3.731 ms | .551秒 |
| 共同M prefix | 10,206 | 4.360 ms | .420秒 |
| 共同L prefix | 17,893 | 5.774 ms | .519秒 |

Lは約14.1%のパラメータ数で、速度差は約1.08倍だった。
S同士の僅かな時間差は別測定であり、品質差による高速化とは主張しない。
初回は既存コンパイルcacheを使い得るため、完全に新しい環境のコンパイル時間ではない。

同じ学習設定・使い捨て重み・固定入力の更新時間も測定した。
5回warmup後の10回中央値、実効batch16、入出力・ノイズ準備・評価を除く。

| 学習方式 | 再帰1段／更新 | 再帰6段／更新 |
| --- | ---: | ---: |
| S/M/L共同更新 | .853秒 | 1.152秒 |
| 独立S | .503秒 | .693秒 |
| 基準UNet | .778秒 | 1.056秒 |

3 seedの実学習中央値は共同更新1.146〜1.154秒、独立S .673〜.677秒、
基準1.037〜1.044秒。A2/A3を含む全92万更新の更新部分は合計235.9時間だった。
この合計にも画像準備・評価・停止期間は含まれない。
全候補が目標品質に未達なので、「同等品質に達するまでの時間」の倍率は未測定。
Burnとの以前の速度比較は[別記録](training-speed.md)にある。

全3seed・raw/EMAの共同S・独立S・基準をONNXに出力し、JAXとの最大誤差は
4.709e−6。33×17／512×512、denoise1／5回のBGRA確認ではidentity・保護領域・決定性が
完全一致した。全サイズのJAX prefixと全体計算も検査点で誤差0。
現在のscalar insert APIはM/Lの複数prefix状態に対応しないため、M/LはJAXでの利用範囲。
Krita pluginへの変更・採用モデルの配布は行っていない。

## 保存場所・再現

実験rootは`runs/completion-20260919-cached`。元のPNG runは
`runs/completion-20260919`に停止時の状態を保存している。
最終重みは`arms/<arm>/snapshots/step-100000/model/{raw,ema}`、学習再開用stateは
`arms/<arm>/training/model`。共同・独立S・基準のarm名は`cohorts.json`にある。
各armの`config.json`・`variants.json`と元画像splitを保持した。

`selection-seal.json`に選定と依存する設定・重み・評価のhash、`final/input-sha256.json`に
最終入力、`evidence-sha256.json`に数値監査時点の保存ファイルhashを記録した。
`integrity.json`は全更新と元画像分割・固定予測の監査結果、`cache-integrity.json`は
全5,730組のPNG/TIFFの保存時hashとの照合結果。
PNGとTIFFの画素一致は作成時に17,190か所のcropで確認したもので、全画素の総当たり比較ではない。
最終監査は92万更新、419,154件の固定予測（うちfinal 48,960件）、13,197保存ファイルを対象とした。
全学習seedで共同・独立S・基準の入力対応hashが一致し、分割・有限値・保護領域・
設定／評価／保存重みの照合も通過した。報告生成スクリプトのlintと保存結果からの実行も通過した。

学習の数値コードは`cc40408`、cache移行は`f129b58`。
学習・依存ソースと後段評価のarchiveはrootの`training-source.json`、
`cache-migration-source.json`、`final-stage-source-v5.json`から辿れる。

今回の範囲はここで終了する。次の新規比較を行うなら、薄線保持・近接線の分離・意図した隙間・
白背景の抑制をそれぞれ切り分け、強い劣化で入力情報が失われる条件も分けるのが妥当。
小型のLと基準を対照に保ち、学習信号と入力劣化の改善を検討する余地がある。
これは今回の結果からの考察であり、新しい比較を実施済みとするものではない。
