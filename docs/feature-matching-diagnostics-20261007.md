# 教師との特徴差によるlossの診断

判別器のスカラー点数を上げる方法は、[欠陥を修復する勾配の検査](critic-defect-probe-20261007.md)
で不採用とした。次は、同じ条件画像の下で予測と教師を判別器に通し、中間特徴の差を測る。
[pix2pixHDのfeature matching](https://openaccess.thecvf.com/content_cvpr_2018/papers/Wang_High-Resolution_Image_Synthesis_CVPR_2018_paper.pdf)
を参考にしたが、ここでは小さな固定判別器の3層を使い、L1を滑らかにした距離を使う。
元論文のモデルや学習全体の再現ではない。

**狙った方向の勾配と、灰色の平均像より鮮明な候補を選ぶ性質を確認した。生成器での改善は未検証。**

## 欠陥の修復方向

新しい幾何variant136〜143で、halo・濃度低下・切断・誤接続を測った。
通常の画素loss、未学習判別器の3層、負例学習済み判別器の3層、WGAN-GPで学習した3層は、
clean/強い重ね描きの両入力で、全欠陥の修復方向が有利だった。
各入力でhalo/切断/濃度は128条件、誤接続32条件。深い1層だけでは誤接続の修復が
30/32（93.75%）で、事前に置いた95%の予備基準を満たさなかった。

これはlossの明らかな逆向きの勾配を除く検査。画素lossと未学習特徴も通るため、
学習済み特徴の画質上の優位性を、この結果だけでは主張できない。
正しい連続グレースケール教師でloss・勾配が0になること、保護画素への変更がlossに
混入せず勾配も0になることを2種類の距離でテストした。

## 灰色の平均像を選ぶか

位置が異なる2枚の線画A/Bを、等確率の正解候補と仮定する小さな診断を作った。
同じ条件画像に対し、鮮明なAを出す場合と、(A+B)/2を出す場合の期待lossを比較した。
これらは構成した画像であり、学習済み生成器の出力ではない。
5形状×8variant×3移動量×2strengthから、教師2枚が完全一致する18条件をloss計算前に除外。
残る222条件を全方式で共通に使用した。小さい移動では正しいサブピクセルAAに相当する
場合もあり、全ての平均像を画質不良と定義した検査ではない。

以下は縦方向±2px（A/B間4px）の74条件。値は、平均像のlossが鮮明な候補より高い割合の中央値。
正なら鮮明な候補を低lossにする。

| loss | 平均像の相対的なloss増加 |
| --- | ---: |
| 画素MSE | −50.0% |
| 画素L1 | 0.0% |
| 未学習特徴・3層・smooth L1 | +4.2% |
| 負例学習済み特徴・3層・smooth L1 | +40.0% |
| 負例学習済み特徴・深い1層・smooth L1 | +80.8% |
| 負例学習済み特徴・3層・L2 | +12.8% |
| WGAN-GP特徴・3層・smooth L1 | +3.5% |

画素MSEが平均像を選び、画素L1が同点になることは解析式とも一致した。
学習済み3層のsmooth L1は、±1/±2/±4pxで平均像のlossが中央値30.2%/40.0%/27.1%高かった。
深い1層には強い選好があるが、前述の誤接続への勾配検査で不合格なので優先しない。
L2では±1/±4pxの中央値が負になり、距離の選択も重要だった。

固定5形状の図を目視し、平均像に薄い二重線や太線周辺の灰色ができることを確認した。
この診断は、実入力の不確実性が必ずこの2候補分布になるという主張ではない。
生成器に加える係数、細線の保持、実線画由来の複雑な形での効果は、別途比較が必要。
次の生成器用候補は学習済み3層smooth L1とし、未学習特徴との対照を残す。

runは `runs/feature-matching-probe-20261007` と
`runs/line-ambiguity-probe-20261007-v2`。前者に全方向微分、後者に全期待lossと
`toy-mixtures.png` を保存。最初のambiguity実行は、直線に沿った移動でA=Bとなるケースの
0除算チェックで停止した。失敗記録と元ソースを残し、モデルに依存しない同一画像の除外を
加えたv2を新しく実行した。いずれの診断でも生成器の重みは変更していない。
