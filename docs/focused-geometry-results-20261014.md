# DV: 幾何モデルの16例集中学習 — 中心線は学べるが、全条件は両立できていない

既知の学習例16個（太線8・近接線4・交差2・白紙1・黒ベタ1）に絞り、入力固定とデータ拡張ありを各3,000更新した。初期値はDU control raw6000。16,064パラメータとDTの符号マージンlossを維持した。数値実装`4beb74e`、10テストとRuff通過。

太い入力から細い中心線を出す能力は、同じモデルサイズで確認できた。初期値の黒い帯や断片が、固定・拡張の両条件で細い線に変わった。ただし先端の切れ・点状の残骸・太さの不均一は残る。近接線には途切れや輪状の不自然な結合が残り、黒ベタの角の白い穴はむしろ大きくなった。入力を固定しても、16例の全条件を満たすには至っていない。

粗い入力では、拡張ありの方が一部の細線・近接線をよく保持した。したがって、データ拡張を外すことも解決にはならない。既知形状の学習可能性を調べた結果であり、未知入力への性能や製品への採用を示すものではない。

384出力を保存し、事前指定の16ページを等倍確認した。学習は全体マスクのみ、評価は全体/部分・元入力/粗い入力・再帰3/6段。16例すべてを6種類の段数で学習した。初期関数の6段数一致、先頭6更新の完全再現、完全状態復元と16 raw/EMA export、保護領域の完全一致を確認した。学習901.28秒、評価7.73秒。lossは固定0.1366→0.08185、拡張0.1432→0.09562（各先頭/末尾300更新平均）だが、この減少を画質合格とは扱わない。

さらに、保存済みの初期・固定・拡張モデルを変更せず、同じ16入力で勾配を調べた。6種類の再帰段数の平均勾配は互いに正の向きで、今回の診断は段数間の競合を支持しない。一方、太線の細線化と黒ベタ保持の勾配cosineは初期-0.571、固定-0.407、拡張-0.412だった。

固定モデルに太線改善方向へ小さな仮の変化を加えると（パラメータ全体のL2変化0.0001）、太線lossは0.100009→0.099853に下がり、黒ベタlossは0.100059→0.100317に上がった。10倍の変化では両lossが悪化したため、これは小さな近傍での競合の確認に限る。モデルの保存値は変更していない。大きなモデルが必要という証明でも、問題が数学的に両立不能という証明でもない。

現時点では、容量を増やす前に、線の細線化・接続・塗り保持を同じ共有パラメータで学習する際の重み付けと、描画結果には不要な距離値まで合わせている制約を切り分ける根拠が得られた。再帰段数・各段loss・sqrt(batch)学習率を変える根拠は今回得られていない。製品品質の改善は未完了であり、Kritaと予約済み新規確認データは変更していない。
