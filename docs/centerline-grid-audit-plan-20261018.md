# HQ: 一セル一頂点の中心線graph表現を学習前に監査する

HPは太線周辺を改善したが、曲線の薄い断片と曖昧な形の十字を解決しなかった。次の候補は、線の有無と接続を離散的に、頂点座標と線幅を連続量として予測する局所graphである。この実験は正しいpathを与える表現監査だけであり、CNNの学習や推論品質の検証ではない。DQの不透明な描画器から先へ進むため、固定gridに圧縮したときの情報欠落を先に調べる。

一セル一頂点、8近傍への無向接続（保存時4方向）、頂点の存在・xy座標・幅を想定する。各pathをgrid境界で分割し、通過するセル内の長さ加重平均位置/幅を頂点とする。セル内の真の端点が一つならそれを保持する。セル間の連続した通過を辺に変換し、孤立点も不透明な円として残す。別pathの同じセルへの衝突は平均されるため、偽の接続が起こる可能性を隠さず記録する。塗りは既存の長方形経路をそのまま渡し、graphで表現できたと主張しない。

grid幅.5/1/2/4 native pxを事前に固定。DQの既知16probe+8sceneのpath/幅/塗りをhashで照合して使用し、教師を見て出力を選ばない。加えて16個の解析的fixture（線、曲線、近接線、交差、T接続、短い線、gap、孤立点、taper、塗り・空）を固定する。nativeページはDQ8ページ、fixture4ページの計12ページ、全条件を確認する。fresh16には触れない。

描画は不透明な可変幅capsuleの和、4倍subpixel coverage、最後にbox平均。存在確率をopacityにしない。数値指標は元path描画との差、ink量、中心線graphの連結成分、別pathが同セル内で実際には接触しない衝突、複数端点衝突を記録する。灰色画素数単独を成功条件にはしない。解析fixtureで分離すべき線がつながるか、短い端やgapが失われるかを確認する。DQの過去JAX描画との小さい丸め差はatol/rtol1e−5以内を実行前に宣言する。

CPUで直線の再構成、セル境界/角の通過、孤立点/空、線幅と端点、近接線の衝突検出、連結成分を確認してからcode/planを凍結する。入力/出力/レビューのhash、実行時刻、終了statusを保存する。結果次第で一セル複数頂点か別表現が必要と判断する。grid幅を選んでも、それだけでlearned predictorが成功するとはしない。将来の学習では深さ1〜6・各段loss・sqrt(batch)を維持するが、この監査には学習更新はない。
