# EM: 入力幅の空白域を埋める第三の比較群

ELでは既知形状の幅だけを変えると約8–15pxで二重枠・灰色・消失が起きた。通常訓練線は最大5px、太線は16–32pxに分離している。モデルやlossを変更せず、既存訓練用太線48形状の入力幅だけを連続化する。

EI group6 raw18000からwidth群を6,000更新する。比較対象は既に事前固定して進行中のEK controlで、同じ訓練を再計算しない。EKの出力を見てから条件を選ばず、この計画を第三群の学習前に固定する。初期重み・optimizer reset・設定ファイル・sampling seed2026101502・各stepの一次形状・rough設定・D4・mask・段数・Gaussianキー・LR曲線をEK controlと揃える。batch4、基準LR1e-4×sqrt4=peak2e-4、cosine最小2e-5、warmup0、段数1–6、全段loss.5^levelを維持。複合拡張は入れない。

index464–511の太線だけを対象に、確率.25で元の幅を保持、.75で元幅とは独立に4–32pxの対数一様幅を選ぶ。幅の乱数は独立キーなのでsamplingをずらさない。元geometry・位置・方向・長さは変えず、±2pxの2描画を混ぜて既存rough処理へ渡す。field教師の許容2pxスタイルと9平行移動候補は一切変えない。partialの保護領域は各条件の入力画像を保持するため、そこだけprepared targetが異なるのは意図通り。

訓練は3,000更新ずつの2区間、全状態復元、0/6/3000/6000のraw/EMA8export。各stepでfield・方向・maskハッシュがEK controlと同じこと、幅を変更しないbatchでは入力全体が完全一致することを確認する。6step再現・全状態復元・export一致を監査。評価は最終rawのみ。

追加テストは元幅の入力完全再現、配列・metadata不変、全6段のfield/active target/mask一致、非変更サンプル一致、同一Gaussian残差、独立幅乱数と5–16px域のsampling。最初のテストでは保護領域もcontrol入力と同一にすべきという誤ったassertが失敗した。各条件の保護入力を保持する期待値に訂正してから学習する。

標準4,608・stress4,608・512場面192、EKと同じ28等倍ページ。さらにELの固定36入力を初期/control/widthで全て評価し108出力・6等倍ページ、計9,516出力・34ページ。初期とcontrolの予測はEK保存物と完全一致を確認する。ELのCPU初期予測はROCmとatol/rtol1e-4で比較する。6評価形状を訓練には使わず、既知開発摂動として扱う。40px以上の極端な摂動は新規訓練範囲の外であり、短く幅広い形を必ず細い線へ変換すべきとは仮定しない。

灰色・途切れ・不自然な二重縁と既存線の退行を重視し、MSE減少だけでは選ばない。滑らかな太い黒線・融合・端の接続を許容する。幅群のみの効果を確認してから複合拡張との組合せを判断する。予約済み新規確認・製品更新は行わない。
