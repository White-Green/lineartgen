# EN: 一本の清書候補は有効だが8bit入力で途切れが残る

EI group6 raw18,000から6,000更新した。EMと全stepの入力・元geometry・samplingを完全一致させ、入力支持のある近接parallelにだけ一本のgeometry候補を追加した。16,402パラメータ、LR、幅拡張、rough/D4、1–6再帰と全段lossは同じ。

候補を許可した1,244例中278例（22.35%）でmerged familyが選ばれ、最後1,000更新でも47例で選ばれた。候補が全く作用しない実験ではなかった。scene1の近接線は二重縁から一本の暗い線へ整理され、float入力では下側の連続性が改善した。ただし濃度が弱い部分は残り、8bit入力では明確な途切れが残る。scene7の下側交点付近の細い縦線の消失も未解消。全体の目視基準は未通過、製品未採用。

EMで得たwide58と中間幅の改善は維持した。wide59の約13px入力では中央の灰色が減ったが、端の塊は残る。通常の直線・曲線・分岐・交差、soft短parallel、黒ベタ、部分編集は維持した。close pairの一部で融合範囲が広がるが、滑らかな黒線の別解として許容した。40px以上の極端な入力幅の断片は残る。MSEによる順位づけはしていない。

学習は1,069.287秒と1,057.198秒、計2,126.484秒で正常終了。最後600更新の平均0.276897秒。6step再現は数値完全一致、全状態復元と8export照合も完全一致。CPU3テスト4.00秒、Ruff、全6段の入力照合、実GPU更新・保存復元を通過。GPUで非許可lossの勾配差は最大5.59e-9。最初のCPUテストはJIT/eager比較の1.49e-8差で失敗し、双方をJITに揃えて完全一致を確認した。閾値緩和はしていない。

評価9,516出力は全phase正常終了。事前固定34ページ、scene1/7の追加2ページ、訓練教師のoracle1ページを実画像で確認した。初期とEM controlの標準/stress各1,536予測ファイルと512px出力は保存値と完全一致。保護領域・有限値・範囲・hash照合を通過。512pxのfloat対8bit出力RMSは平均.001505、最大.005129だが、平均値が小さくても局所的な途切れは見える。

証跡は`runs/merge-geometry-20261015/completion.json`と`diagnostics/`。固定ソース`27c0489`。これらは既知の合成開発入力で、実際のKritaや未見確認の成績ではない。予約済み新規確認は未使用。
