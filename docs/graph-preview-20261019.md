# Krita graph試用版

累計100,200更新のEMAを使うruntime 0.3.0。合成下描きから線を起こすKrita試用版。
Windows x64 / Python 3.13のZIPは[プラグインのActions](https://github.com/White-Green/diffusion_drawing/actions?query=branch%3Arewrite%2Fgraph-preview-20261019)から取得する。
まずStrength 0.5、Lineart passes 3で試す。ベタ塗りの復元には大きな失敗が残る。

## モデル

22,725パラメータのD4 group CNN。6チャンネル×8方向の主枝、
粗い解像度の枝、局所平均とdilationによる広い文脈を使う。
9出力は頂点の有無、中心線への2次元offset、対数線幅、4方向の辺、塗り。
各ピクセルの灰色値を二乗誤差で直接合わせる方式ではない。
予測した中心線を不透明な可変幅線分のunionとして描き、縁は4倍supersamplingで処理する。

正規化した下描きとStrengthを各解像度へ平均縮小し、最も粗い段から再帰する。
直前の段の頂点・塗りのsoftな占有予測を次の段へ渡す。
重みは段間で共有し、段別のFiLMと物理スケールに合わせたdilationを使う。
配布時は6段へ定数を展開したONNXにするため、ファイル合計はパラメータ数より大きい。

## 学習と選定

研究branch `rewrite/graph-krita-20261019` の `scripts/graph_long_training.py`。
IJ controlの16,200更新から84,000更新を追加し、累計100,200を完了した。
追加学習は約7時間39分。深さ1〜6は各14,000更新、全記録と最終raw/EMAの有限性を監査した。
合成512例と幅を広げた合成1,024例を使い、後者の抽選率は25%。
batch4、深さ1〜6を均等循環、全段lossは0.5^levelを正規化して重み付け。
ピーク学習率は1e-4×sqrt(4)、600更新warmup、cosineで2e-6まで減衰。
回転・反転、blur、不透明度、部分適用の拡張を維持する。
頂点・接続・位置・幅・塗りのlossを使い、塗りの陰性上位1%も学習する。

途中と末尾の原寸画像で、終盤の形状変化は小さかったため今回の追加学習はここで区切った。
raw/EMAの25例×1/3/6段と8部分条件を30ページで見比べ、見た目の差は小さかった。
EMAを最終試用重みとしたが、rawに対する明確な品質優位は主張しない。
既知の527例・1,180条件を実行し、あらかじめ定めた57ページをすべて目視した。
1,180条件すべてを個別に目視したわけではない。
画素MSE最小や閉ループ数で選定していない。

選定を固定してから、新しい16合成例をBGRA入力で1/3/6段と部分適用の計64条件で実行した。
全32ページを目視し、部分適用の保護領域がbyte単位で一致することを確認した。
この最終評価を使った重みの選び直しや追加調整はしていない。
学習回数は十分な試用期間を設けるための区切りで、品質目標達成や収束の証明ではない。

## 推論と検証

BGRA入出力は従来と同じ。下描きはalphaだけ、既存線画はRGB輝度とalphaを使う。
Strength0は入力を保ち、既存線画の不透明な部分は生成の対象外。
Lineart passesは1〜6、既定3。Seedは受理するが生成結果に影響しない。
矩形・奇数サイズに対応し、各辺16px以上。画像サイズが大きい場合は計算量も増える。

ネットワークは512px coreと192px halo、描画は256px tileを使い、
線分をまとめて計算してPythonの反復コストを抑える。
CPUは既定で最大4threadを使う。初期16,200重みの1024px/3段は、
1threadで約7.5秒、4threadで約3.9秒、peak RSS約1.0GiB。両出力の画素は一致した。
これは開発機での測定で、Windows GPUの速度を示すものではない。

最終EMAの20条件をONNX Runtime 1.24.4と1.29.0の双方で照合した。
JAX/ONNXの最終画像最大誤差2.93e-6未満、1byte超差・分類反転とも0。
headは絶対/相対許容誤差2e-4以内、tile有無の最大差0、保護領域は完全一致。
同じcheckpointから独立したJAX参照fixtureを6段分再生成し、配布する実装でも照合する。
ORT 1.24.4のpadding付きAveragePoolで境界値がずれるため、局所平均は固定Convの和と固定除数で表す。
Padを別演算にするだけでは最適化時の融合で再発することを確認した。重み・参照値・許容誤差は変更していない。
[数値照合の全記録](benchmarks/graph-runtime-20261019.json)を参照。

## 品質上の制約

合成データのみで、実際の手描き下描きでの品質は試用が必要。
広い線の端や曖昧な重ね描きで二重線・閉ループ・余分な点が残る場合がある。
強いblurの一部やscene5では局所的な太りがあり、初期16,200重みより悪化した例もある。
新しい寸法のベタ塗りは穴だらけになる、または中心線だけになる重大な失敗がある。
明示的な切れ目を残す一方、下描きの途切れを自動でつなぐことはできていない。
線の強弱や細部の保持も未解決で、手描き全般に使える完成モデルとはしていない。
最終重みでは33×17pxの幅1px線が非空（最大alpha255、48画素）になり、
145×129・16×300の細線も保持した。これはすべての小画像での保持を保証する検査ではない。
不透明線分の描画でも、細い線や縁にはアンチエイリアスによる中間alphaがある。
これは旧モデルの広い灰色のにじみと区別して評価する。
