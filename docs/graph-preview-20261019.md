# Krita graph試用版

配布準備中。長期学習後の選択した重み・検証結果を確定してからZIPを公開する。

## モデル

22,725パラメータのD4 group CNN。6チャンネル×8方向の主枝、
粗い解像度の枝、局所平均とdilationによる広い文脈を使う。
9出力は頂点の有無、中心線への2次元offset、対数線幅、4方向の辺、塗り。
各ピクセルの灰色値を二乗誤差で直接合わせる方式ではない。
予測した中心線を不透明な可変幅線分のunionとして描き、縁は4倍supersamplingで処理する。

正規化した下描きとStrengthを各解像度へ平均縮小し、最も粗い段から再帰する。
直前の段の頂点・塗りのsoftな占有予測を次の段へ渡す。
重みは段間で共有し、段別のFiLMと物理スケールに合わせたdilationを使う。
配布時は6段へ定数を展開したONNXにするため、ファイル合計はパラメータ数より大きい。

## 学習と選定

研究branch `rewrite/graph-krita-20261019` の `scripts/graph_long_training.py`。
IJ controlの16,200更新から84,000更新追加、累計100,200をまず完了する計画。
合成512例と幅を広げた合成1,024例を使い、後者の抽選率は25%。
batch4、深さ1〜6を均等循環、全段lossは0.5^levelを正規化して重み付け。
ピーク学習率は1e-4×sqrt(4)、600更新warmup、cosineで2e-6まで減衰。
回転・反転、blur、不透明度、部分適用の拡張を維持する。
頂点・接続・位置・幅・塗りのlossを使い、塗りの陰性上位1%も学習する。

学習回数だけで品質を判断しない。途中と末尾の原寸画像、raw/EMA、
既知の幅・劣化・シーン、選択後の未使用16合成例を確認して配布重みを決める。
画素MSE最小や閉ループ数だけで選ばない。

## 推論と検証

BGRA入出力は従来と同じ。下描きはalphaだけ、既存線画はRGB輝度とalphaを使う。
Strength0は入力を保ち、既存線画の不透明な部分は生成の対象外。
Lineart passesは1〜6、既定3。Seedは受理するが生成結果に影響しない。
矩形・奇数サイズに対応し、各辺16px以上。画像サイズが大きい場合は計算量も増える。

ネットワークは512px coreと192px halo、描画は256px tileを使い、
線分をまとめて計算してPythonの反復コストを抑える。
CPUは既定で最大4threadを使う。初期16,200重みの1024px/3段は、
1threadで約7.5秒、4threadで約3.9秒、peak RSS約1.0GiB。両出力の画素は一致した。
これは開発機での測定で、Windows GPUの速度を示すものではない。

初期書き出しの20条件でJAX/ONNXの最終画像最大誤差2.09e-6、1byte超差なし。
独立したJAX参照fixtureを6段分保存し、配布するCPU/DirectML実装でも照合する。
最終重みへの差し替え後に同じ検査を再実施する。

## 品質上の制約

合成データのみで、実際の手描き下描きでの品質は試用が必要。
広い線の端や曖昧な重ね描きで二重線・閉ループが残る場合がある。
初期重みでは33×17pxの短い幅1〜2px線が消える。長期学習後に改めて確認する。
不透明線分の描画でも、細い線や縁にはアンチエイリアスによる中間alphaがある。
これは旧モデルの広い灰色のにじみと区別して評価する。
