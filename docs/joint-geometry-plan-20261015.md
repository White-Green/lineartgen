# EQ: 幅・幾何候補・異なる濃さの合成を初期化から学習する

EPの短い追加学習は近接線/弱い交差線を部分改善したがwide周辺の点・線片を増やした。最適化途中の旧分布への適応制約か、持続する画質トレードオフかを確認するため、2群を同じ初期化から完全に学習する。

merge群はENの連続width拡張とmerged geometry候補、mixed群は同じ条件にEPの独立した濃さ/blur/warpの透明度合成を追加する。合成方式、対象288形状、追加確率.5、主/相手それぞれのrough・widthキー、opaque教師和集合、候補選択lossを変更しない。入力8bit拡張は加えない。

両群はEIのfresh group6初期値(seed2026101432、16,402 params、head kernel0/bias.125、physical field+1)を使い、同一パラメータ・optimizer/EMA新規状態で開始する。各18,000更新、batch4、seed2026101440、基準LR5e-4×sqrt4=peak1e-3、cosine最小1e-4、warmup0、clip1、EMA.999。再帰1–6段、全段loss .5^levelを維持する。4,500更新ずつ4区間、区間境界で状態・LRをresetしない。0/6/4500/9000/13500/18000 raw/EMA計24exportsを照合する。

既存512合成形状とD4/3種maskを利用する。主形状・rough・D4・maskはEIの全18k抽選に一致する。widthの独立乱数キーは同じseedの既存関数、合成の有無・相手は独立キーを使用する。両群でmerged許可は全更新一致、合成しないbatchは入力/教師/payload完全一致を確認する。全6段で非合成例一致、教師和集合、保護領域、縮小後Gaussianを事前検証する。共通モデル/lossはソースhash一致で既存試験を継承し、fresh初期化同一・white関数・6step再現・全状態復元を実学習でも検証する。

最終raw2群と既存EI group6 raw18kを、同じ標準/stress/512px/幅掃引の9,516出力・固定34ページ、scene1/7追加等倍で比較する。参照EIは学習開始値ではなく旧18k学習モデル。既存EN評価との参照予測一致も確認する。混合あり/なしの比較はmatchedであり、EIとの比較は幅拡張と候補も異なる。

線の不透明さ、滑らかさ、連続性、余分な点/線片、fill/部分編集を直接確認する。MSEや全画像RMSの大小で採用しない。学習時間と全終了コード、既存のROCm再現許容幅atol5e-6/rtol1e-4を記録する。予約済み新規確認と製品には触れない。
