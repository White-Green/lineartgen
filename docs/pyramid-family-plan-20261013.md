# DE: 共有CNNに物理的な縮小段を伝える

DDの2pxスタイルは薄い入力を改善したが、薄い線・側線の灰色・交点の不安定さが残る。
共有CNNにはピラミッドの段番号がなく、入力透明度と縮小による濃度低下を区別しにくい可能性がある。
これは原因と確定していない。モデルへの条件の不足を比較し、教師MSEを成功基準にしない。

DD canonical raw6000を共通初期値としてconstant/levelを各6,000更新する。
16ch・3残差blockは同じ。stemと各blockのFiLMへ1→32のbiasなし1x1畳み込みを加える。
追加128パラメータをゼロ初期化し、両armは15,937パラメータ。同じ親の全6段出力と完全一致して開始する。

- constant: 各段へ1を与える。追加係数は学習可能で既存biasと冗長な対照。
- level: 最細段を0として1+level/5を与える。最細段は常に1、5回縮小した段は2。
  実行順序や総再帰深さではなく、元画像から何回2倍縮小したかを使う。
  残りdenoise progressとは別の条件であり、progressは従来通り1。

同じ512合成下描き、DDと同じ2px候補・共通元線量normalizer、opacity/blur/warp拡張。
lossはlinear Charbonnier+.25path+.05range、global一候補、全段.5**level。
batch4、sqrt(batch)でLR1e-4→cosine1e-5、深さ1–6、fresh Adam/EMA。
seed2026101325、評価2026101326。両armの入力・教師・乱数hashを全6,000更新で一致確認する。
縮小後の追加Gaussianはsource-onlyなので消費しない。元の入力画像は保持する。

CPUでゼロ初期化、既存出力一致、段情報による非自明な出力差、保存復元、実勾配・更新、
全1–6段の番号伝播、NumPy/JAX one-passの一致、保護画素を確認する。
旧local/source/styleの関連テストとRuffも実行する。
GPU最初6更新は事前固定atol1e-7/rtol1e-5で再実行、6/6000全状態復元、12raw/EMA exportは完全一致。
研究用保存はJAX inference形式。段入力を持たない既存ONNX exportは明示的に拒否し、誤った段0固定を避ける。

評価はDDと同じ標準4split×64例×3mask×2draw×3モデルと、6劣化×64例×2mask×2draw×3モデル。
9,216行、同じ事前指定16枚を等倍で確認する。元＋2pxスタイルの共通54候補で評価する。
灰色帯・芯の明瞭さ・滑らかさ・接続/分離・端点・塗り・保護を確認し、原教師幅の再現は要求しない。
追加512px/uint8画面も別途宣言して記録する。改善しても単一seedの開発実験である。

合成のみ。Krita・配布は変更しない。独立確認seedと封印データは使わない。
