## clipによる勾配の遮断を追加診断

最終profileモデル、old_train/new_probe各60非定数例、whole .5、同じ評価draw0で、
モデルが選んだ許容候補のopacity>.25なのに予測opacity<.1の画素を調べた。
旧train 956画素中644(67.4%)、new_probe 1305中944(72.3%)は物理出力が白上限1を越え、
clipを経由するfamily lossの直接勾配が0になる領域だった。
old_train24の欠損候補32画素中27、新規probe36の余分な黒133画素中120でも飽和を確認。
同じ画素には別途rangeguardの力があるため、全loss勾配が0という意味ではない。
また位置ずれもこの画素診断に入るので、上記を人間評価の欠損数とは解釈しない。

diagnostics/saturation.py/jsonに条件・モデルhash・raw例を保存。観測だけでは因果は未確定。
以前の単一教師実験にもinterval lossがあったため、今回は有限許容候補の目的でも
誤った飽和に勾配を流すinterval Charbonnierを対照付きで検証する。
推論のclipや再帰feedbackを変えず、正しい白/黒への範囲外出力は追加で罰しない。
