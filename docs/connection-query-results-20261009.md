# 接続を直接監督するloss：2,000更新の結果

**灰色の橋を消す効果は確認したが、別形状での線幅・欠損が残り、採用しない。**
2モデルの2,000更新、128条件ずつの初期/600/最終評価、固定4枚の最終等倍比較、
重み・optimizer・EMAの照合まで完了した。配布モデルとKritaは変更していない。

[固定計画](connection-query-plan-20261009.md)。各モデルが同じ4図形を毎回batch4で
学習し、Gaussian noiseは毎回生成した。従来の4個の専用モデルと異なり、今回は
一つのモデルが4図形を共有する。因果比較は今回のpixel対照との比較に限定する。
モデルは130,605 parameters、共通preclip-opacity.3 raw1200起点、
base LR1e-4×sqrt(4)、再帰1–6段、最上位への直接loss重み0、縮小後ノイズを維持した。

追加項は、既知の二点をつなぐ経路の「最も弱い箇所」の不透明度を測る。
つなぐべき線には教師の実際のAA不透明度を下限として与え、教師が離れている場合は
接続量を抑える。64px局所グラフの離散探索で選んだボトルネックに勾配を流す。
全画像のトポロジー保証や原MALISの再現とは主張しない。

隙間中央の平均不透明度はTRAINで.078964→.019506（75.30%減）、PROBEで
.017869→.007369（58.76%減）。全画像で測るmaximin接続量もTRAIN
.154976→0、PROBE.002806→0になった。最終8drawとも接続項側は接続量0。
画像でも学習した隙間に白い開口を確認した。一方、端点は教師より先細りになる。

数値fitting screen（F1≥.95、ink不足≤.05、halo≤.02）はTRAINで対照18/32、
接続loss20/32、PROBEは両方0/32。接続lossの事前固定した相対条件は4項で失敗：
PROBE角の幅、PROBE隙間のF1・幅・切断率。隙間の切断率は.479167→.500000。
影響は隙間の白さだけでは判断できない。

最終native4枚を実際に確認した。学習形状は600時点よりかなり細く明瞭になったが、
細線はまだ太い。別形状の細い角・隙間では、両モデルとも幅のあるグレーの線と
不均一な濃さが残る。これらは160px切り出しの観察で、全画像の目視完了を意味しない。
600時点の中間nativeは代表2枚のみ確認した。

## 検証と次の比較

独立した最短経路系oracleとの容量一致、勾配、AA線、切断、淡い橋、迂回路、
同値点、空query、保護画素を検証した。関連29テスト成功。実画像の64px queryも
36件で独立oracleと完全一致した。最初のCPU回帰テストはsandboxのIPCで待機したため
中断し、同じテストをローカルIPCが利用できる環境で実行して29件成功した。

GPU全6段preflightと実学習先頭6更新の全状態が一致し、最終2,000更新の全状態を
保存復元できた。最終raw/EMAの4exportも学習checkpointの各parameterと完全一致。
数値固定commitは865cc450bfdc40f10ce43424339aef75f3581746。
`runs/connection-queries-20261009/`の`final-audit.json`、`paired-gate.json`、
`visual-review/review.json`に数値・重み・画像hashを記録した。

この結果は「接続lossが橋を検出して学習に使える」ことの証拠であり、少数形状から
十分に汎化した証拠ではない。次は別worktreeの
[毎回生成する合成図形の比較](../../jax-procedural-structure-20261009/docs/procedural-structure-plan-20261009.md)
で、従来loss / 領域loss / 領域＋接続lossを比較する。前の失敗した係数をそのまま
採用へ進める実験ではなく、多様な幅・向きと背景抑制を含む新しい仮説を検証する。
独立学習seedと封印した新規確認条件はまだ未実施・未開封。
