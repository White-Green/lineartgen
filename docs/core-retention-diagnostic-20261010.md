# 元の線の芯を残す拡張の予備診断

膨張したinkと元のinkを半分ずつ混ぜ、その後に従来通りの変位・重ね合わせ・blur・透明度を適用した。以前、異なる正解から完全に同じ下描きになった固定2組で、今回の入力差がfloat32と8bitの両方に残ることを確認した。

| 固定反例 | 下描きの最大差（正規化値） | 8bit最大差 | 8bitで異なる画素数 |
|---|---:|---:|---:|
| 幅1pxと幅5px | .116861 | 15階調 | 6,823 |
| 平行な1px線2本と9pxの帯 | .116728 | 15階調 | 8,870 |

旧実装の出力は保存済み配列と完全一致。今回も膨張なしの側は変わらない。sigma1.5、opacity.3、変位2、乱数は旧診断と同じ。[計画と数値](../runs/core-retention-diagnostic-20261010/result.json)。

[等倍画像](../runs/core-retention-diagnostic-20261010/native-comparison.png)の全12クロップを確認した。新しい細線側は太い正解側より薄く細い。一方、blur後の平行線はまだ1本の柔らかい帯に見える。**この2組が区別可能になったことは、一般に一意な復元ができる証明でも、モデル画質の改善でもない。**

変更は`sketch.dilation_blend=.5`。既定値1では旧経路を保持し、他の拡張種別・無効例・膨張半径0・白紙・乱数キーを保つ。既存拡張テストと合わせ18件、実更新と全状態復元・評価判定2件の計20テストを通過した。Sの学習比較はRの最終結果が不採用の場合だけ実施し、評価には旧拡張で作成した入力をそのまま使用する。[比較計画](core-retention-data-plan-20261010.md)。
