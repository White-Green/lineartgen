係数2は、一部の平均指標を下げても、残る灰色側線・交点の欠陥を解消しなかった。
薄い/粗い黒ベタでは輪郭リングが明るくなり、内部も灰色化した。両条件とも製品未採用。

DF prior raw6000のGと学習済みDを共通初期値とし、moderate(.2)/strong(2)を各6,000更新。
G/DのoptimizerとEMAは新規、500step ramp。Gは同じ15,809パラメータ、Dは15,497。

strongではfaint/roughの黒ベタの明るい輪郭リングが強まり、内部も明るくなった。
