# GZ: 反復する少数例と通常線・塗りの混合

少数例を以前と同じ回数学習し、その間に通常線・塗りを挟むと、主線の多くと黒い塗りは保てたが、余分な直交線が一部で再発した。未学習の太さ・角度への改善も不十分で、採用しない。

9e36cc1固定、同じ21890パラメータ・未変更初期値。全2400更新はGXのfocus1200とGW由来background1200の交互。背景は通常858、長線・塗り342。focusの入力・候補・contextと更新時LRはGXに完全一致（LR最大差0）。全6段、各段loss、sqrt(batch)、opening0、geometry.1を保持した。学習例ごとの訪問は396または402回で平均400回。追加した背景更新とoptimizer履歴の影響をまとめて比較しており、総計算量や背景への学習量をGYと揃えた比較ではない。

新出力134＋保存済み対照190、固定30原寸ページをすべて確認した。

- 学習12例すべての主線は暗く連続するが、0/1/5/6/10などで薄い直交片が戻った。特に6/10の余分な線が目立つ。正方形48の主方向は水平に保てるが中心の太りや薄い縦片がある。
- 転移40pxは十字・塊・不均一、64pxは途切れた平行片・塊のまま。GXを超える転移は確認できない。
- 塗り192/160/208は不透明に保て、GX特化時の大きな崩れを防げた。ただし構成例の塗り外側に小さな点が出る。
- 長線62には細い平行線と端の模様が残り、80/87.5pxは大きな黒い枠・塊になる。GYより悪いが背景更新は1200対6000なので、この差だけで忘却や容量不足とは言えない。
- 通常シーンの曲線・隙間・部分保護は概ね維持。scene1の接続部の黒い塊と曲線端の小片は増え、scene2の灰色の肩は残る。scene7の短い縦片はやや濃くなるが端が膨らむ。

画像確認前に固定した記述的指標（どちらか一軸の中央90%でalpha.8到達率95%以上、支持域3px外インク/教師インク5%以下）では、学習12例はGX12/12からGZ10/12、転移8例はGX1/8からGZ0/8になった。深さ1/3/6で同じ件数。これは微細な小片や端の滑らかさを保証せず、採用基準ではない。中心線の全消失という主張はしていない。
