# EK: 複合形状の不足と追加学習を分ける

EJでEMAとdepth6は残存欠陥を解消しなかった。既存学習集合の48太線は幅16.0669–31.6150px、長さ43.4352–158.6372px、長さ/幅1.6397–9.1633。標準probe58は幅16.0675、長さ66.2931、比4.1259で、それぞれの範囲内。これだけで高次元の分布内とは断定しないが、単純な幅不足ではない。

512形状は全て一種類のprimitive群で、独立な異種形状の重なりがない。48 crossingは一群内で同じ幅を共有する。一方、既知512場面7はgap/straight/gap/bezierの混合で、元の最大幅1.0307–4.5555pxが同居する。場面1もparallel/parallel/corner/gapの混合。複合場面の相互干渉を学習していない可能性を調べる。

同じEI group6 raw18000（16,402重み）からcontrol/composedを各6,000更新。両方でoptimizerを同じ条件にリセットしEMAも初期重みから開始する。batch4、peakLR2e-4（基準1e-4×sqrt4）、cosine最小2e-5、warmup0。段数1–6循環、全段lossと重み.5^level、regional censored field/gradient/RMS signは変更しない。seed2026101502、評価2026101503。3,000更新ずつの2区間、optimizer・schedule・EMAの全状態を復元。保存0/6/3000/6000 raw/EMA、品質比較は最終rawのみ。

controlは従来512形状、3mask、D4、25%base/75%rough。composedは同じ一次形状・mask・D4・rough設定・Gaussianキーを使い、通常432形状の入力に確率.5で別の通常形状を重ねる（全体約42.2%）。blank/fill/wideはそのまま残す。相手は0–431から独立に選び、primitive9×9の組合せをカバーする。

入力は同じrough設定を適用した2画像のmin、目標は既存canonical fieldのminによる不透明形状の和集合。2枚の灰色平均ではない。各元形状の許容2pxスタイルを保ち、全体を一次形状の法線方向に9候補だけ平行移動する。個別位置の厳密復元を要求しない。合成は既存形状の新しい組合せであり、独立な新規形状の生成や未見確認とは呼ばない。source-only構造のため後付けGaussianを無視する性質も継承する。

新規検証は、不透明な交差の解析的unionとfield minの一致、D4との可換性、元配列不変、全6段の非合成サンプル一致・mask一致・Gaussian残差の一致、sampling分布。モデルとlossの既存テストは同じソースハッシュを確認して継承する。6更新replay、保存復元、16exportも確認。

評価はEIと同じ標準256形状×3mask×2draw×3モデル=4,608出力、stress4,608、512場面192の計9,408。指定等倍ページは標準12・stress10・512の6、計28。source、許容形状、EI初期、control、composedを比較する。大きな512ページは必要なら分割して等倍で確認する。旧MSEは選択に使わず、灰色・連続性・余分な線・保護領域で判断。滑らかな融合や端の接続は許容し、意図的gapと追加欠落を区別する。

controlも改善するなら追加学習の効果、composedだけ複合交点で改善するならデータ不足の寄与とする。wide58は組合せ拡張の直接対象ではなく、改善を事前に仮定しない。既知開発入力での診断であり、予約済み新規確認・製品採用・Krita更新は行わない。
