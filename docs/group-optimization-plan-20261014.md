# EF: 新規D4学習の初期fieldと学習率

EEの既知16形状では、D4 group6も通常CNNも十分な濃さ・連続性を学べなかった。構造の失敗とは断定できない。ここではgroup6（16,402重み）の同一初期重みを使い、出力headの初期field +8 / +1 と peak LR 1e-4 / 1e-3 の2×2比較を行う。+1はcensored背景制約を満たす最小値。初期描画は4群とも完全な白だが、fieldと再帰内部状態はnear/farで異なる。学習率因子の対は初期パラメータも完全一致させる。初期bias以外の重みは4群共通。

各3,000更新、初期seed2026101432、入力seed2026101435、評価1436。EEと同じ16形状、25%base/75%rough、D4、whole.5、batch4、再帰1–6巡回・全段loss。regional geometry loss、モデル、描画は変更しない。baseLR5e-5/5e-4をsqrt(batch4)で拡大し、cosine終端1e-5/1e-4、EMA.999、Adam新規、gradient clip1。保存0/6/1000/3000。途中画像を見ずraw3000を比較する。EE group6 raw6000は履歴参照で、同条件対照とは扱わない。

全更新の入力・教師・Gaussian一致、6更新再実行、全状態復元、32 raw/EMA exportを監査する。追加テストで初期bias以外の重み一致、全6段の初期field/画像、LRのsqrt(batch)、形状×段数×方向の提示、4群の同じ入力を確認する。既存EEの層・再帰等変性と更新テストは同じ数値コードに適用される。

評価は元入力/rough×whole.5×depth3/6×16形状×5モデル=320出力、depth6の指定8等倍ページ。partialは今回の学習可能性判定から外す。黒く連続した中心線、滑らかな近接曲線（綺麗な融合を許容）、交差、塗り内部、白地を確認する。lossや画素MSEだけで勝者を決めない。

線が消えず灰色帯が減る条件があれば、別計画で延長と通常CNNとの比較を行う。4群とも不十分なら単純な同一入力への適合と各段の勾配・損失寄与を測り、追加の長時間学習に進む前に原因を絞る。既知の診断例であり汎化性能の主張はしない。reserved fresh、製品、Kritaは変更しない。
