# 塗りの誤判定を切り分ける診断（IF）

IE expanded raw3000（22,725パラメータ）を固定し、太い枠がfill headに由来するか調べる。追加学習も製品変更も行わない。IEの結果を見て選んだ既知例であり、汎化評価ではない。

事前指定12例は追加学習入力25/512/769/896と、既知の評価extra-bar-center / extra-bar-wide / extra-wide87 / extra-fill160 / width-58-0.5 / width-61-0.25 / stress-41-rough / stress-36-rough。全例d3で実行し、同一headから通常描画・fillなし・fillのみを描く。これは最終描画だけの介入で、再帰途中のfill情報は除かない。12枚の等倍画像を確認する。学習入力4例はd6でも実行し各段fill lossを診断（計16モデル推論、各3描画で48出力）。既存通常出力との一致atol/rtol各1e-5、重み不変、全値有限を検証。

正しいfillラベルを持つ学習4例の全段で、現在の陽性/陰性別平均BCEと、陰性の損失上位1%だけを平均する候補を比較する。陽性側は変更しない。Kは各段の全画素数×1%を切り上げ、陰性数がKより少なければ実数で割る。誤陽性画素数、logitの分布、loss、誤陽性/他の陰性/陽性へのlogit勾配L1を保存。モデル重みに対する勾配と混同しない。全陽性・全陰性・陽性除外・陰性数不足・通常lossとの同値性をテストする。

枠がfill除去で消え、誤陽性への反応が全陰性平均で薄まっているなら、次に同じデータ・初期重みの比較学習を別途凍結して行う。塗りの削除自体は本当の塗りを壊すため採用しない。fillのない中間幅ループと近接線の問題が残れば別問題として扱う。独立確認用DNは未使用のまま保つ。
