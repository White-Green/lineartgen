# HD: 支持域内の部分適用を通常学習へ戻す

HCで、対象全体が適用内にあるwhole/partial対の相反する方向制約を直すと、同じ21890パラメータで十字を一本化できた。位置・マスク境界への転移は不十分だった。本比較はその変更を通常線・塗り・多様な曖昧形状の学習に入れる。合成データのみ、MSEによる採用やモデルの大型化は行わない。

初期値は未変更GW choice。HC/GXのfit済み重みは使わない。GY/GWと同じ6000バッチ、3750従来例・1500GL長線と塗り・750GV曖昧形状。入力、全候補field、context dropout、sample順、再帰段数、ノイズはdigestで旧GWと完全一致を照合する。変更を許すのはGVの許可boolだけ。新規に許す部分適用例は、原軸・別軸の全18候補にinkが存在し、その4px支持域全体がt>0内にある場合に限る。data側とloss側の両方で検査する。全体適用は旧条件を保持し、候補が用意されていないlegacy部分例とGLは変更しない。この範囲の限定を一般的な部分マスク修正とは呼ばない。

許された場合は近水平の一つの軸、45度同率は正の傾き、±2pxの9位置候補から全段共通で選ぶ。禁止例の複製候補を実際の別軸候補に置換するため、新規許可例では候補集合に応じた共通ROIも変わる。HCの最終maskだけの比較とは異なり、旧GYとの比較は許容条件の修正全体を評価する。

21890パラメータ、全6段、各段loss.5^level正規化、B4acc1、基本LR1e−4√4=2e−4、minimum2e−5、cos6000、warmup0、clip1、EMA.999、context dropout.5、opening0、geometry.1、sign.25/global L4を固定。0/6/36/1000/2000/3000/4000/5000/6000の全stateとraw/EMA18個を保存・復元一致検証。最初36更新の自己再演はmetric・全state厳密一致。各更新の旧payload照合・変更bool・選択bitを記録する。

対照は保存済みGY consistent raw6000。再学習したとは言わない。ファイルschemaのwinnerキーがGY対照、consistentキーがHD新条件で、ページには実名を表示する。GY自体は初期参照のビット一致が不合格だった試験で、その事実を変えない。HDの参照再計算は開始前にatol1e−5/rtol1e−5を固定する（GYで観測した初期参照差2.80e−6を考慮）。比較数・ビット非一致数・最大差を全て記録し、ビット一致と呼ばない。入力digest、自己再演、保存state、保護画素にはこの許容誤差を使わない。失敗したら記録を保全し、事後に閾値を広げたり出力を選び直したりしない。

学習前に、全family×全6段の初期出力一致・有限勾配を検査する。固定順で最初の8件の「部分適用で実際に別軸を選べるようになる例」を原寸2ページにして確認し、空候補や支持域外への逃げがないことを記録する。

最終raw6000のみを評価。既存GYと同じ標準・強劣化・512px・太さ掃引9516出力、FU/GK/GO/全8成分206出力・原寸58ページに加え、HCのtrain2＋mask/位置transfer4を深さ1/3/6、GY対照とHDで36出力・原寸6ページ。合計9758出力・原寸64ページと教師2ページを実際に確認する。全成分は診断だけで選び直さない。途中checkpointは品質選択に使わない。

短く太い例の一本化と、普通の曲線・交差・隙間・細線・塗り・部分適用の保持を実画像で判定する。長い80/87.5pxの枠、scene2の灰色の肩、scene7の短い縦線、probe36/37の小片も確認する。幅・位置への転移が残れば明記する。記述的なcoverage等は従来の方法で補助測定し、後から採用閾値にしない。広い条件を通過した後にのみ独立確認計画へ進む。fresh16、Krita、本番exportは本比較では触らない。
