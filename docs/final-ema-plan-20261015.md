# EJ: 同じ最終group6のraw/EMAによる残存欠陥の診断

EIのfull512・18,000更新は線画品質を大きく改善した。残る標準wide58の灰色・切れ、512場面1の非常に近い曲線群の不均一さ、場面7の下側交点における縦線の余分な欠落が、最終更新のばらつきと関係するかを安価に調べる。

EI group6の同じstep18000に保存されたrawとEMA（decay.999）のみを固定比較する。EMAは重みの指数平均であり、複数出力画像の平均ではない。学習もcheckpoint探索もしない。EIで他構成より良好だったgroup6を対象にする開発診断で、事前独立な検証とは呼ばない。

DQ/EHで使用済みの24入力（多様な256px16形状、512px8場面）をそのまま使用。whole/partial.5、depth3/6、float/uint8往復、seed2026101501。全384出力と32等倍ページ。列は入力・一つの許容geometry・raw・EMA。全ページを確認し、改善例だけを選ばない。滑らかな融合や端の接続は許容する。場面7の意図的なgapと下側交点の追加欠落を区別する。

有限値・出力範囲・保護領域完全一致・モデル状態不変・全入力と重みのハッシュを検証。数値推論実装はEI/EHから変更せず再使用。新規数値処理はなく、Ruffと全artifact検証を用いる。評価の量子化RMSは画質判定に使わない。既にuint8の入力で出力差0となる条件は新たな頑健性の証拠ではない。

両者の欠陥が同じなら、EMA選択だけでは足りないと判断する。EMAで改善しても、他の既知入力での退行を確認する。広い開発評価を通過するまで予約済み新規入力を開かず、製品・Kritaは変更しない。
