# 追加データの提示回数比較（IJ、2026-10-19）

IGで太い枠が改善し、IHで残るループは主に頂点の存在と座標に関係すると分かった。一方、追加1024例の提示はIE+IG合計で平均約4.2回しかない。構造やlossをさらに変える前に、このデータを十分提示した場合を調べる。

IG hardnegative raw1200を共通初期値に、同じ22,725パラメータ、R1、同じ陰性上位1%のfill lossを使う。controlは追加データ25%、expandedは50%。新しい形状や評価例を学習に加えず、既存の旧512例と追加1024例だけを使う。各6000更新、B4、再帰1–6を各1000更新、全段lossの重み0.5^level正規化、base LR1e-4×sqrt(4)=2e-4、cosineで2e-5まで下げる。optimizer/EMAは新規初期化し、D4・追加blur0–1・opacity0.65–1・部分処理25%を保つ。

seed2026101901の共通一様乱数を使い、25%群の追加例は必ず50%群にも同じ例として入る。残る共通の旧例も入力・教師・拡張・ノイズを一致させ、毎更新の共通項目の完全一致を検証する。置換される約25%だけが群間差。確率だけでなく全サンプルID・提示数・未出現数・各種別の回数を保存する。

実行前6更新を二重に行い全状態一致を検証。同じROCm GPUの別プロセスで本学習先頭6更新とatol/rtol各1e-5を照合し、ビット不一致も記録する。0/6/1200/3000/6000で全状態・raw/EMA保存復元を照合。途中の画像で条件を変更せず、最終raw6000を評価する。

評価はIGと同じ標準166＋広範囲2360＋学習入力24=2550予測、新規等倍92ページ。教師12ページは同じデータなので所見を継承し新規目視に数えない。ループ・端の結合/小片・塗り角と、通常線・明示的隙間・保護画素の保持を確認する。両群に共通する改善は追加学習の結果、群間差だけを混合率の結果として扱う。幅広い塗りの改善だけで採用せず、近接線の忘却にも注意する。画素MSEで順位付けしない。
