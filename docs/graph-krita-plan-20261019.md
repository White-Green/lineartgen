# 長期学習とKrita試用版

利用者の依頼は、最新の成果を十分に学習してからKritaで試せるようにすること。
IJ control（追加幅データ25%、累計16,200更新）から84,000更新を追加し、累計100,200更新をまず完了する。
25%群は直前までのデータ比率を維持し、95px線の端が比較的まとまっていたため選ぶ。
50%群の穴数だけによる選択はしない。ICの1,200更新モデルは使わない。

22,725パラメータ、R1 graph、fill陰性上位1%、合成512+1024例のみ。
B4、再帰1〜6を均等循環、全段lossの正規化0.5^level、base LR1e-4×sqrt(4)。
新しいoptimizer/EMAで開始。600更新warmup、84,000更新cosine、終端LR2e-6。
入力のD4、blur0〜1、opacity0.65〜1、部分適用25%を維持。
新しい抽選seedを使い、過去実験や既存チェックポイントは変更しない。

追加0/6/2,000/12,000/36,000/60,000/84,000で重みを保存し、2,000更新ごとに再開可能な全状態を保存。
標準25例×深さ1/3/6と部分適用8例を途中で比較。最終は既存の幅・劣化・512pxシーン評価も行う。
MSEを選別基準にせず、線の連続性、余分な線・閉ループ、線幅、塗り、保護領域を原寸で確認。
末尾の比較でまだ改善が続くなら延長を検討。100kという数だけで収束・品質合格を宣言しない。
学習に使っていない合成例でも最終確認し、既知の開発例と分けて記録する。

Kritaにはgraph headのONNXとNumPyの前処理・再帰・描画を実装。
JAXの参照出力との照合、縦横比・奇数サイズ・空白・部分適用・BGRA往復を検査。
Python3.13、DirectML/CPU、既存LineartModel.infer形式を維持し、Windows CI artifactを提供する。
既知の欠点は試用版の説明に含める。Windows実機/Kritaの目視操作は利用者の試用で確認する。
