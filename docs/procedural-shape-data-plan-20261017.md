# GL: procedural bar/fill teacher audit before any new training

GJ showed known-pair learnability with the existing model/objective; GK exposed poor transfer to widths, angles and endpoints. Audit a balanced procedural family whose geometry is sampled afresh for each selected batch, instead of only changing width on48 fixed wide-stroke templates. This is a data-only stage. It changes neither the running GH experiment nor any model weights.

For a possible future6000-update comparison, select every fourth six-depth cycle: step//6%4==3. This gives1500 batches/6000 images, exactly250 batches at each depth1–6. EachB4 batch has two bars and two fills. Unselected4500 steps would retain the original full training mixture, but a separate plan must specify actual models, objectives, controls and training before it begins.

Bars: source width24–88px, length max(128,2*width)–208px, clean rectangular line width2px. Fills: rectangular width128–208px, height128–208px with aspect ratio0.8–1.25, clean matching filled rectangle. These unambiguous aspect-ratio bands deliberately do not address the short-wide axis ambiguity from GH. For either type, orientation proposal is25% exact D4 axes,25% within±3degrees of an axis,50% arbitrary; reject oriented boxes that cannot fit with8px margins, then sample the center uniformly in the feasible region. Report rejection counts and accepted geometry statistics; rejection changes the effective angle distribution, especially for large fills. No clipping or truncation of shapes.

Source alpha is4x analytic rectangular coverage averaged to256px, then Gaussian blur and opacity. One quarter of recipes use sigma1.2/opacity0.4; others draw sigma0.6–2.4/opacity0.2–0.8. Targets are uncapped signed rectangular fields on the inherited padded4x grid, storedfloat16; clean coverage is rendered from those same quantized fields. Bar translations may later use the existing nine shifts along the normal; fills use zero direction, repeating the same target. No alternative target family or per-pixel candidate selection.
